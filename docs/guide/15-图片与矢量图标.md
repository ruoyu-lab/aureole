# 15. 图片与矢量图标

## 图片

```rust
pub fn photo() -> Element {
    let state = signal(ImageState::Loading);
    column()
        .gap(8)
        .child(
            image("assets/cover.jpg")
                .size(240, 160)
                .fit(ImageFit::Cover) // 等比铺满，裁掉多出来的部分
                .image_position(0.5, 0.3) // 裁的时候偏上
                .radius(12)
                .background(FILL) // 解码好之前的占位
                .image_fade(Tween::new(ms(250)))
                .report_load_state(state)
                .accessibility_name("封面"),
        )
        .child(text(move || match state.get() {
            ImageState::Loading => "加载中…".to_string(),
            ImageState::Ready { width, height } => format!("原始大小 {width} x {height}"),
            ImageState::Error(e) => format!("出错了：{e}"),
        }))
}
```

- 来源：路径（`&str`、`String`、`PathBuf`）、`ImageSource::file(..)`、`ImageSource::bytes(..)`（内存里的文件数据）、`ImageSource::from_static(include_bytes!(..))`、`ImageSource::rgba(宽, 高, 像素)`。支持 PNG、JPEG、GIF、WebP（GIF 和动态 WebP 会动，见下面），按 EXIF 方向转正；打开 `svg` 特性时还有 SVG 文件，见[后面](#svg-文件)。
- **后台解码**，不卡主线程；同一个来源只解码一次，多个元素共用。解码好的图按最近使用留在缓存里（默认 64MB）。
- 摆放 `ImageFit`：`Stretch`（默认，拉伸）、`Contain`、`Cover`、`None`、`ScaleDown`；`.image_position(x, y)` 是对齐（0 靠左上，0.5 居中，1 靠右下）。`.radius(..)` 圆角裁剪图片。
- `.image_fade(曲线)` 解码好后淡入（合成层动画）；已经在缓存里的图直接显示。`.report_load_state(信号)` 拿到加载状态和原始大小。

```rust
pub fn generated() -> Element {
    let (w, h) = (64u32, 64u32);
    let pixels: Vec<u8> = (0..w * h).flat_map(|i| [(i % w * 4) as u8, (i / w * 4) as u8, 200, 255]).collect();
    image(ImageSource::rgba(w, h, pixels)).size(64, 64).radius(8)
}

pub fn viewer(photos: Vec<ImageSource>) -> Element {
    let index = signal(0usize);
    let count = photos.len();
    image(move || photos[index.get()].clone()) // 绑定信号换图：新图解码好之前继续显示旧图
        .size(320, 200)
        .fit(ImageFit::Contain)
        .on_click(move || index.update(|i| *i = (*i + 1) % count))
}

pub fn cache() {
    let thumb = ImageSource::file("photos/1.jpg").max_size(512); // 解码时缩小：缩略图省内存，还能放进图集
    let _wall = image(thumb.clone()).size(120, 80).fit(ImageFit::Cover);
    aureole::set_image_cache_budget(128 * 1024 * 1024); // 不用的图留在缓存里的上限（默认 64MB）
    let stats = aureole::image_cache_stats();
    println!("在用 {} 张，{} 字节，累计解码 {:?}", stats.images, stats.bytes, stats.decode_time);
}
```

**动图**：GIF 和动态 WebP 自己会动，按文件里每一帧的延迟和循环次数播：

```rust
/// 动图：默认就播；指针放上去才播；只播一遍、按按钮重播
pub fn animated() -> Element {
    let hovered = signal(false);
    let player = PlaybackHandle::new();
    row()
        .gap(12)
        .align(Align::Center)
        .child(image("assets/loading.gif").size(48, 48)) // 系统打开"减少动态效果"时停在第一帧
        .child(image("assets/preview.webp").size(160, 90).playing(hovered).on_hover(move |inside| hovered.set(inside)))
        .child(image("assets/done.webp").size(48, 48).playback_handle(player))
        .child(button("重播").on_click(move || player.restart()))
        .child(text(move || if player.is_finished() { "播完了" } else { "" }.to_string()))
}
```

- 换帧时只把新的一帧传给 GPU，**不重新布局、不重建图元**。元素滚到视口外、被裁掉、完全透明、窗口被挡住时不换帧，露出来以后接着播。
- `.playing(绑定)` 播不播（停下时停在当前帧）；`PlaybackHandle` 句柄可以 `play`、`pause`、`toggle`、`restart`，读 `is_playing()`、`is_finished()`（按循环次数播完了，停在最后一帧）。都不设时跟着系统：没打开"减少动态效果"时播，打开时停在第一帧；用户自己点了播放（`play()` 或 `.playing(true)`）就播。
- 同一个来源的帧只解码一次，所有元素共用；每个元素有自己的播放进度。一张动图的所有帧（含 mip）不超过缓存预算的一半（默认 32MB），放不下时自动缩小；大动图配 `max_size` 更省。延迟写成 0 或 10 毫秒的帧按 100 毫秒放。

## SVG 文件

打开 `svg` 特性（默认关，要解析 SVG 文件的应用才带上解析库）：

```toml
[dependencies]
aureole = { version = "0.0.1-beta.1", features = ["svg"] }
```

`image()` 就认得 SVG 文件了，来源、大小、摆放方式、圆角、边框、淡入、加载状态都和图片一样。按内容认，不看扩展名，换图时 PNG 和 SVG 可以互换：

```rust
/// SVG 文件和图片用同一个元素：来源、大小、摆放方式、圆角、加载状态都一样
pub fn logo() -> Element {
    let state = signal(ImageState::Loading);
    column()
        .gap(8)
        .child(image("assets/logo.svg").width(160).report_load_state(state)) // 只给宽：高按文件的比例
        .child(image(ImageSource::from_static(include_bytes!("assets/mark.svg"))).size(64, 64).fit(ImageFit::Contain)) // 编进程序里
        .child(text(move || match state.get() {
            ImageState::Loading => "解析中…".to_string(),
            ImageState::Ready { width, height } => format!("文件写的大小 {width} x {height}"),
            ImageState::Error(e) => format!("出错了：{e}"),
        }))
}
```

- **大小**：没给大小时用文件写的大小（`width`、`height`，没写时按 `viewBox`），只给一边时按比例。
- **始终清晰**：按显示的大小和窗口缩放画成矢量路径，变大、换到高分屏时重新栅格化，不是把一张图放大。
- **后台解析**，不卡主线程；同一个文件只解析一次，两百个一样的图标也只栅格化一次，解析结果和图片在同一个缓存里。
- **出错**：文件读不到、不是 SVG、写坏了都进入 `ImageState::Error`，不会崩溃。没打开 `svg` 特性时也是，原因里写明要打开它。

单色图标要改色，用 `.tint(颜色)`：所有颜色都换成它，只留形状。改色不重新栅格化，可以绑定信号（位图也一样）：

```rust
/// 单色图标改色：悬停时换颜色，只换颜色、不重新栅格化
pub fn toolbar_icon() -> Element {
    let hovered = signal(false);
    image(ImageSource::from_static(include_bytes!("assets/mark.svg")))
        .size(24, 24)
        .tint(move || if hovered.get() { ACCENT } else { MUTED })
        .on_hover(move |inside| hovered.set(inside))
        .accessibility_name("设置")
}
```

文件里填充、描边写成"当前颜色"关键字的路径（很多图标库这样写），跟着元素继承的文字颜色走，和路径图标一样，用 `.color(..)` 或者在父元素上设。

文件里的文字转成路径，字体来自系统和 `font::load` 加载过的；要文字在哪台机器上都一样，用 `font::load` 带上字体。滤镜、混合模式、图案填充还不支持：记一条警告、跳过这一项，别的照画。

只有一条路径、路径是代码算出来的、要做描线和变形动画的，用下面的矢量路径。

## 矢量路径

```rust
pub fn vector_icons() -> Element {
    let check = VectorPath::svg("M5 12.5 L10 17.5 L19 7").view_box(0.0, 0.0, 24.0, 24.0);
    let heart = VectorPath::svg("M12 20 C5 14 3 11 3 8 A4.5 4.5 0 0 1 12 6 A4.5 4.5 0 0 1 21 8 C21 11 19 14 12 20 Z").view_box(0.0, 0.0, 24.0, 24.0);
    let ring = VectorPath::svg("M12 2 A10 10 0 1 1 12 22 A10 10 0 1 1 12 2 Z M12 7 A5 5 0 1 1 12 17 A5 5 0 1 1 12 7 Z").view_box(0.0, 0.0, 24.0, 24.0).even_odd(true);
    let triangle = VectorPath::builder().move_to(4.0, 20.0).line_to(12.0, 4.0).line_to(20.0, 20.0).close().build().view_box(0.0, 0.0, 24.0, 24.0);
    row()
        .gap(16)
        .align(Align::Center)
        .color(TEXT) // 路径默认用文字颜色，会继承
        .child(path(check).size(24, 24).stroke(Stroke::new(2.0).round())) // 描边
        .child(path(heart).size(32, 32).color(Color::hex(0xff375f))) // 填充
        .child(path(ring).size(32, 32)) // 奇偶规则：中间挖空
        .child(path(triangle).size(32, 32).stroke(Stroke::new(1.5).join(LineJoin::Round)))
        .child(path(VectorPath::circle(16.0, 16.0, 14.0)).size(32, 32).stroke(Stroke::new(3.0).cap(LineCap::Round))) // 没有画布：坐标就是逻辑像素
}
```

- 框架不带图标集：图标就是一条路径，24 的画布、1.5 的描边、跟着文字颜色走，和别的元素一样放进按钮里（`button(path(..).size(16, 16))`）。
- `VectorPath::svg(d)` 解析 SVG 路径语法（全部命令，包括圆弧）；`VectorPath::builder()` 逐段构造；`VectorPath::polyline(点)`、`VectorPath::circle(cx, cy, r)`。`VectorPath` 克隆便宜。
- `.view_box(x, y, w, h)` 是画布：等比缩放、居中放进元素。没有画布时，路径坐标就是元素内容区里的逻辑像素。`path(..)` 没指定大小时用画布大小。
- 默认用**文字颜色**填充，颜色会继承，所以图标跟着周围文字的颜色走；`.stroke(Stroke::new(宽).round())` 改成描边（线宽在路径坐标里），`.cap(..)`、`.join(..)` 改端点和拐角；`.even_odd(true)` 奇偶填充规则。
- 按物理像素栅格化并缓存：只改颜色、位置、透明度不重新栅格化。

**描线动画和图表**：`.stroke_range(起点, 终点)` 只画每条子路径的一段（长度比例），对 `Property::StrokeEnd` 做动画就是"描出来"的效果；路径可以绑定数据：

```rust
pub fn chart() -> Element {
    let points = signal(vec![[0.0, 80.0], [60.0, 40.0], [120.0, 60.0], [180.0, 10.0], [240.0, 30.0]]);
    let drawn = signal(false);
    column()
        .gap(8)
        .align(Align::Start)
        .child(
            path(move || VectorPath::polyline(points.get())) // 路径绑定数据
                .size(240, 100)
                .stroke(Stroke::new(2.0).round())
                .color(Color::hex(0x0a84ff))
                .stroke_range(0.0, move || if drawn.get() { 1.0 } else { 0.0 })
                .transition(Property::StrokeEnd, Spring::new(ms(600), 1.0))
                .on_mount(move || drawn.set(true)),
        )
        .child(button("换数据").on_click(move || {
            aureole::without_animation(|| {
                points.update(|p| p.iter_mut().for_each(|pt| pt[1] = 100.0 - pt[1]));
                drawn.set(false); // 先回到没描的状态
            });
            drawn.set(true); // 再描一遍
        }))
}
```

## 坑

- **图片解码好之前大小是 0**（没指定大小时），界面会在解码好后跳一下：尽量给图片固定大小，再给个背景色当占位。
- `max_size` 只影响纹理（省内存、能进图集），不影响布局。
- 内存里的数据按地址区分：要让几个元素共用一份，克隆同一个 `ImageSource`，不要每次重新 `ImageSource::bytes(..)`。
- 动图（GIF、动态 WebP）和灰度、CMYK 的色彩配置按 sRGB；PNG 只认 cICP 和 iCCP，gAMA、cHRM 不管。
- 动图的每一帧都按整张画布解码、留在内存里：帧多、画布大的动图很占内存（480x270、100 帧约 70MB），给它 `max_size`，或者让它自动缩小。
- 同一个路径元素不能同时填充和描边，叠两个元素。

## 路径变形

路径绑定了信号、又声明了 `.transition(Property::Path, 曲线)` 时，换路径不是一下子跳过去，而是从旧的形状变成新的：

```rust
pub fn menu_toggle() -> Element {
    let open = signal(false);
    let menu = VectorPath::svg("M4 6.5 H20 M4 12 H20 M4 17.5 H20").view_box(0.0, 0.0, 24.0, 24.0);
    let close = VectorPath::svg("M6 6 L18 18 M18 6 L6 18").view_box(0.0, 0.0, 24.0, 24.0);
    path(move || if open.get() { close.clone() } else { menu.clone() })
        .size(24, 24)
        .stroke(Stroke::new(1.8).round())
        .transition(Property::Path, Spring::new(ms(340), 1.0)) // 三条线变成叉；中途再点沿原路回去
        .on_click(move || open.update(|o| *o = !*o))
}
```

```rust
pub fn play_pause() -> Element {
    let playing = signal(false);
    let play = VectorPath::svg("M8 5 L19 12 L8 19 Z").view_box(0.0, 0.0, 24.0, 24.0);
    let pause = VectorPath::svg("M6.5 5 H10.5 V19 H6.5 Z M13.5 5 H17.5 V19 H13.5 Z").view_box(0.0, 0.0, 24.0, 24.0);
    path(move || if playing.get() { pause.clone() } else { play.clone() })
        .size(32, 32)
        .color(ACCENT)
        .transition(Property::Path, Tween::new(ms(200)).ease_in_out()) // 填充也行：一个三角形变成两根竖条
        .on_click(move || playing.update(|p| *p = !*p))
}
```

- 两条路径的命令、段数、子路径数可以不一样：都先规整成三次贝塞尔，段少的一边把长的段拆开，子路径按"每个点走的路最短"配对，闭合的子路径换起点和方向；多出来的子路径从对面最近的一条长出来（奇偶规则的填充从一点长出来）。
- 弹簧、补间都行。变形途中再换路径时从此刻的样子接着变，换回原来的路径时沿原路返回，弹簧的速度连续。
- 描边、填充、`stroke_range`、颜色继承照常。变形期间每帧重新栅格化（写进图集里为它留的同一块），停下后用缓存。
- 两条路径的画布（`view_box`）最好一样；不一样时画布也跟着插值。

## 色彩配置和 HDR 图片

```rust
pub fn color_managed() -> Element {
    // 线性浮点的像素（sRGB 原色，1.0 是 SDR 白）：从 1 倍到 4 倍亮的暖色
    let (w, h) = (256u32, 16u32);
    let pixels: Vec<f32> = (0..w * h)
        .flat_map(|i| {
            let v = 1.0 + 3.0 * (i % w) as f32 / (w - 1) as f32;
            [v, v * 0.85, v * 0.6, 1.0]
        })
        .collect();
    column()
        .gap(8)
        .child(image("photos/sunset-p3.jpg").size(240, 160).fit(ImageFit::Cover)) // 嵌了 Display P3 配置的照片
        .child(image("photos/night-hdr.png").size(240, 160).fit(ImageFit::Cover)) // 16 位、PQ 的 HDR 图片
        .child(image(ImageSource::rgba_f32(w, h, pixels)).size(256, 16))
}
```

- 解码时（后台线程）按图片的色彩配置换到工作空间：PNG、JPEG、WebP 里嵌的 ICC（Display P3、Adobe RGB 这类矩阵加曲线的配置自己算，查表的配置交给 moxcms），PNG 的 cICP（BT.709 / Display P3 / BT.2020 原色，sRGB、PQ、HLG 曲线）。没有配置的、配置就是 sRGB 的原样不动。
- 换完以后在 sRGB 色域里的照常是 8 位（能进图集）；超出 sRGB 或比白亮的存成半精度浮点（每像素 8 字节，单独一张纹理，多一次绘制调用），在广色域、HDR 显示器上原样显示。
- HDR 图片按自己最亮的地方和显示器此刻的余量做色调映射（膝点以下不动，以上平滑压缩），普通显示器上压到 SDR 白。PQ、HLG 按参考白 203 尼特换成 SDR 白的倍数。`ImageSource::rgba_f32(宽, 高, 像素)` 直接给线性浮点的像素。
- 测试里生成带配置的图片：`aureole::testing::encode_with_profile(格式, 宽, 高, 像素, ColorProfile::DisplayP3)`、`encode_hdr_png`；`Harness::extended_screenshot(余量)` 截扩展范围的图（线性浮点），检查广色域、HDR 的像素。

## 画布：大量图形和图表

`canvas(闭包)` 是一个元素，闭包拿到画笔 `Canvas`，在元素自己的坐标里（左上角是原点，`cx.size()` 是元素大小）画形状、线、路径和文字：

```rust
/// 小折线图：数据变了才重画
pub fn sparkline() -> Element {
    let data = signal(vec![3.0f32, 5.0, 4.0, 7.0, 6.0, 9.0, 8.0, 11.0]);
    canvas(move |cx| {
        let [w, h] = cx.size();
        let values = data.get();
        let max = values.iter().copied().fold(1.0, f32::max);
        let step = w / (values.len() - 1) as f32;
        let points: Vec<[f32; 2]> = values.iter().enumerate().map(|(i, v)| [i as f32 * step, h - 4.0 - (h - 8.0) * v / max]).collect();
        cx.polyline(&points, Stroke::new(2.0).round(), ACCENT);
        let [x, y] = points[points.len() - 1];
        cx.fill_circle(x, y, 3.0, ACCENT);
    })
    .size(160, 40)
    .on_click(move || data.update(|d| d.push(d[d.len() - 2])))
}
```

- **只在需要时重画**：闭包读到的信号（`.get()`、`.with()`）变了，或者画布大小变了，下一帧开始时重新执行一次（一帧里信号改多少次都只画一次）；界面别处变了只把记下的图元拷进显示列表，不执行闭包。
- **形状**：`fill_rect`、`fill_round_rect`、`stroke_rect`、`stroke_round_rect`、`fill_circle`、`stroke_circle`、`line`、`polyline`、`fill_path`、`stroke_path`，颜色都接受渐变（铺满这个图形的外接矩形）。描边以边为中心。
- **线**：`Stroke` 的端点（`cap`）、转角（`join`）、虚线 `.dash(画, 空)` 和 `.dash_offset(偏移)`（路径元素的描边也能用虚线）。

```rust
/// 坐标轴、虚线网格、面积和文字：平移到绘图区，刻度用等宽数字
pub fn axes() -> Element {
    let values = [12.0f32, 18.0, 15.0, 26.0, 22.0, 31.0];
    canvas(move |cx| {
        let [w, h] = cx.size();
        let (plot_w, plot_h) = (w - 48.0, h - 32.0);
        cx.save();
        cx.translate(40.0, 8.0); // 绘图区的左上角
        let label = CanvasTextStyle::new(11.0).color(MUTED).tabular_numbers(true);
        for k in 0..=3 {
            let y = plot_h * k as f32 / 3.0;
            cx.line([0.0, y], [plot_w, y], Stroke::new(1.0).dash(2.0, 4.0), LINE);
            cx.text(-8.0, y, format!("{}", 30 - k * 10), &label.clone().align(Align::End, Align::Center));
        }
        let x = |i: usize| plot_w * i as f32 / (values.len() - 1) as f32;
        let y = |v: f32| plot_h * (1.0 - v / 30.0);
        let mut area = VectorPath::builder().move_to(0.0, plot_h);
        for (i, &v) in values.iter().enumerate() {
            area = area.line_to(x(i), y(v));
        }
        let fade = Gradient::linear(deg(180.0), [(0.0, ACCENT.with_alpha(0.2)), (1.0, ACCENT.with_alpha(0.0))]);
        cx.fill_path(&area.line_to(plot_w, plot_h).close().build(), fade); // 面积：渐变铺满路径的外接矩形
        let points: Vec<[f32; 2]> = values.iter().enumerate().map(|(i, &v)| [x(i), y(v)]).collect();
        cx.polyline(&points, Stroke::new(2.0).round(), ACCENT);
        cx.restore();
    })
    .size(360, 180)
}
```

- **状态**：`save()` / `restore()` 成对使用，中间的 `translate`、`scale`、`rotate`、`clip_rect`、`clip_round_rect`、`opacity` 只对后面画的东西有效；裁剪和外面的裁剪取交集，边缘抗锯齿。
- **文字**：`cx.text(x, y, 内容, &CanvasTextStyle::new(字号).color(..).align(水平, 竖直))`：竖直方向默认按基线对齐，`.tabular_numbers(true)` 等宽数字；没设的字号、颜色、字体用画布元素继承的文字样式。`cx.text_metrics(内容, &样式)` 量出它画出来的宽、高和基线（和 `text` 排得一样），一行里接着画几段读数、给标签量好宽度再画底色都靠它，不用按字数估。

```rust
/// 一万个点，指针下离得最近的那个高亮
pub fn scatter_hover() -> Element {
    let points: Vec<[f32; 2]> = (0..10_000)
        .map(|i| {
            let a = i as f32 * 0.618;
            [180.0 + a.cos() * (i % 160) as f32, 100.0 + a.sin() * (i % 90) as f32]
        })
        .collect();
    let (hits, hovered) = (CanvasHits::new(), signal(None::<usize>));
    canvas(move |cx| {
        cx.clip_rect(0.0, 0.0, 360.0, 200.0);
        for (i, p) in points.iter().enumerate() {
            cx.fill_circle(p[0], p[1], 1.5, ACCENT.with_alpha(0.5));
            cx.hit_circle(i, p[0], p[1], 5.0); // 比点大一些，好指
        }
        if let Some(i) = hovered.get() {
            cx.stroke_circle(points[i][0], points[i][1], 4.0, 2.0, ACCENT);
        }
    })
    .size(360, 200)
    .canvas_hits(hits)
    .on_pointer_move(move |e: &PointerEvent| hovered.set(hits.at(e.position)))
}
```

- **命中**：`hit_circle(id, ..)`、`hit_rect(id, ..)` 登记能点中的区域（经过当前的变换），`.canvas_hits(CanvasHits)` 把它们交给句柄，事件里 `hits.at(e.position)` 查指针下是哪一个（在几个区域里时取中心最近的）。几万个区域也只查一个格子。`hit_accessibility_name(id, 名字)` 给区域起名字，读屏软件把它当成画布里的一个子节点。
- **开销**：矩形、圆、线段、圆角连接的不透明折线都是距离场图元，每个一个实例，和界面其他部分在同一次绘制调用里；x 单调、比物理像素还密的折线先按像素列抽稀。尖角、半透明、渐变、虚线的折线和任意路径栅格化进画布自己预留的那块路径图集，内容不变时不重新栅格化；很长的折线分段栅格化，每帧都换数据时尽量用圆角连接。
- **画布就是一种自定义元素**：`canvas()` 只是用公开的元素种类接口实现的一个元素。要一种有自己的大小、能接输入、能按名字创建的元素（仪表盘、波形、编辑器里的小块）时，见第 [25](25-自定义元素.md) 章。

## 坑（画布）

- 闭包里不要改信号，也不要读 `CanvasHits`（每次画完都会更新它，读了会一直重画）。用 `get_untracked` 读的信号变了不会重画。
- 画布不裁剪自己画的东西：画到元素外面的部分照样显示，需要时 `.clip(true)` 或者 `cx.clip_rect(..)`。
- 路径的画布（`view_box`）在画布里不起作用，路径坐标就是画布坐标。有旋转、不等比缩放时，路径栅格化后整体变换（会略软）；距离场图形不受影响。
- 半透明的折线按路径栅格化（距离场线段在连接处会叠出深色）：点很多又要半透明时，把整个画布 `.opacity(..)`。
