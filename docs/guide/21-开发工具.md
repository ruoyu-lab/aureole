# 21. 开发工具

这一章的东西都在 `devtools` 特性后面，开发时打开，发布的应用不开（不带文件监视的库，也没有 `App::restarts_on_rebuild`）：

```toml
[features]
dev = ["aureole/devtools"]
```

`cargo run --features dev` 时才有热加载。

迭代速度靠两样东西：监视文件热加载（调颜色、间距、文案、图片，保存即生效）、重新编译后原地重启（改代码后回到原来的窗口和状态）。两样一起装是插件 `aureole::devtools::HotReloadPlugin`（`App::new(app).plugin(HotReloadPlugin::new())`）。调动画用动画的时钟（第 [8](08-动画.md) 章）。本章的导入：

```rust
use std::collections::HashMap;

use aureole::prelude::*;
```

```rust
pub fn main() {
    App::new(app)
        .restarts_on_rebuild(true) // cargo build 换掉可执行文件后，原地换成新程序
        .run();
}

fn app() -> Element {
    let page = signal(0usize);
    aureole::devtools::persist("page", page); // 重启成新程序后还停在原来的那一页
    aureole::set_image_watching(true); // 图片文件改了重新解码
    let copy = aureole::watch_file("assets/copy.txt"); // 文件内容变成信号，保存后界面跟着变
    column()
        .gap(12)
        .child(text(move || copy.get()))
        .child(row().gap(4).child(button("一").on_click(move || page.set(0))).child(button("二").on_click(move || page.set(1))))
        .child_when(move || page.get() == 0, || text("第一页"))
        .child_when(move || page.get() == 1, || text("第二页"))
}
```

## 监视文件热加载

```rust
/// 每行一个"名字 = 数值"，改了保存马上看到效果
pub fn tweaks() -> Element {
    let tweaks = aureole::watch_file_with("tweaks.txt", |bytes| {
        String::from_utf8_lossy(bytes)
            .lines()
            .filter_map(|line| line.split_once('='))
            .filter_map(|(k, v)| Some((k.trim().to_string(), v.trim().parse::<f32>().ok()?)))
            .collect::<HashMap<_, _>>()
    });
    let value = move |key: &'static str, default: f32| move || tweaks.with(|t| t.get(key).copied().unwrap_or(default));
    rect().size(120, 80).radius(value("radius", 12.0)).padding(value("padding", 8.0)).background(Color::hex(0x0a84ff))
}
```

- `aureole::watch_file(路径)` 返回内容是文件文字的信号；`aureole::watch_file_with(路径, 解析)` 在后台线程上解析成你的类型。第一次同步读（界面一开始就有值），之后文件保存后下一帧更新；内容没变（只是"保存"了一下）时信号不更新。不轮询，没有事件时监视线程一直睡。
- 监视归调用时的作用域所有，元素卸载、窗口关闭时停止。
- `aureole::set_image_watching(true)`：`image(..)` 用到的图片文件改了以后自动重新解码（解码好之前继续显示旧图）。默认关闭，关闭时没有开销。

## 重新编译后原地重启

`App::restarts_on_rebuild(true)` 监视自己的可执行文件：在另一个终端里 `cargo build` 换掉它之后，保存主窗口的位置大小和 `aureole::devtools::persist(名字, 信号)` 登记的信号，用同样的参数把进程换成新程序；新程序的主窗口回到原来的位置，`persist` 读回原来的值。改代码到回到原来的界面大约 0.6 秒，另加增量编译的时间。

`persist` 的值用 `ToString` / `FromStr` 存取（读回失败时保持原值），所以适合页码、输入框的文字、开关这些简单状态。

## 坑

- 重启只恢复主窗口的位置大小和登记过的信号；其他窗口、滚动位置、焦点不恢复。
- 监视很大的文件时，每次保存都要整个读一遍再比较。
