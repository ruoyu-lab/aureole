# 25. 自定义元素

大多数界面用 `rect`、`text`、`path`、`canvas` 就够了。什么时候要自己定义一种元素：

- 要**自己的大小规则**（仪表盘的高是宽的 3/4），`canvas()` 给不了；
- 要**像输入框那样接输入**：拿焦点、接按键、拖着选字、接输入法（代码编辑器、终端）；
- 要**让读屏软件读到内容**，又不是一组元素（波形、评分、图表里的区域）；
- 要**能按名字找到、创建**：登记到种类表里，`kind_spec(名字)` 按名字做出一个。

内置的文字、输入框、路径、图片、字符网格、画布都是这样做的，走的是同一个接口。

本章的导入：


## 最小的一个

实现 `ElementKind`，只有 `name` 和 `paint` 必须写，别的方法都有默认实现。`Element::from_kind(种类)` 做成元素，之后和别的元素一样设大小、背景、事件：

```rust
/// 最小的自定义元素：只写名字和 `paint`，大小由样式给。读数是信号，所以声明 `UPDATE`：
/// 在树外的 `update` 里读信号、记下要画的东西，信号变了自动再更新一次
struct Bar {
    value: Signal<f32>,
    drawing: Drawing,
}

impl ElementKind for Bar {
    fn name(&self) -> &'static str {
        "bar"
    }

    fn hooks(&self) -> KindHooks {
        KindHooks::UPDATE
    }

    fn update(&mut self, cx: &mut UpdateContext) {
        let value = self.value.get().clamp(0.0, 1.0);
        let [w, h] = cx.size();
        self.drawing.record_in(cx, |c| {
            c.fill_round_rect(0.0, 0.0, w, h, h * 0.5, LINE);
            c.fill_round_rect(0.0, 0.0, w * value, h, h * 0.5, ACCENT);
        });
    }

    fn paint(&mut self, cx: &mut PaintContext) {
        self.drawing.paint(cx);
    }

    fn unmount(&mut self, cx: &mut UnmountContext) {
        self.drawing.release(cx); // 还回路径图集的块
    }
}

/// 工厂函数：和 `text`、`canvas` 一样返回 `Element`，之后照常设大小、背景、事件
pub fn bar(value: Signal<f32>) -> Element {
    Element::from_kind(Bar { value, drawing: Drawing::new() })
}
```

- **内容读信号就声明 `KindHooks::UPDATE`**：元素有了大小以后调用一次 `update`；之后这次读过的信号变了、或者元素的大小变了，下一帧开始时再调用。信号变了只做标记，一帧里改多少次都只更新一次。`update` 在元素树之外执行，读信号、跑用户代码都安全。
- **画用 `Drawing`**：和画布是同一支画笔（`Canvas`，第 [15](15-图片与矢量图标.md) 章）。在 `update` 里用 `record_in(cx, ..)` 记下要画的（画的时候能用 `text_metrics` 量文字；别处画用 `record(大小, 缩放, ..)`，量不了），`paint` 放进显示列表（经过元素的变换和裁剪），`release` 在卸载时还回路径图集的块。
- 不写 `measure` 时样式给多大就多大（`.size(200, 8)`）。

## 接口里的其余方法

一个完整的例子是仪表盘：没给大小时 160 x 120，只给宽时高是宽的 3/4，中间的数字用继承的字体。`cargo run -p aureole --example custom_element` 能跑：

```rust
/// 仪表盘：一段 270° 的弧，按比例画亮一截，中间写百分比
pub struct Gauge {
    /// 读数，0..1
    value: Signal<f32>,
    /// 上次更新时读到的（快照里显示）
    shown: f32,
    /// 画好的一幅：在 `update` 里画，在 `paint` 里放进显示列表
    drawing: Drawing,
}

/// 弧从左下（135°）开始，顺时针转 270°
const START: f32 = std::f32::consts::PI * 0.75;
const SWEEP: f32 = std::f32::consts::PI * 1.5;
const TRACK: Color = Color::hex(0xe3e8eb);
const ACCENT: Color = Color::hex(0x138a84);

impl ElementKind for Gauge {
    fn name(&self) -> &'static str {
        "gauge"
    }

    /// 读数是信号：在树外的 `update` 里读，信号变了自动再更新
    fn hooks(&self) -> KindHooks {
        KindHooks::UPDATE
    }

    /// 没给大小时 160 x 120；只给了宽时高是宽的 3/4
    fn measure(&mut self, _: &mut MeasureContext, known: [Option<f32>; 2], _: [AvailableSpace; 2]) -> [f32; 2] {
        match known {
            [Some(w), Some(h)] => [w, h],
            [Some(w), None] => [w, w * 0.75],
            [None, Some(h)] => [h / 0.75, h],
            [None, None] => [160.0, 120.0],
        }
    }

    /// 中间的数字用继承的字体：样式变了重画
    fn restyle(&mut self, cx: &StyleContext) -> Dirty {
        if self.drawing.restyle(cx) { Dirty::PAINT } else { Dirty::empty() }
    }

    fn update(&mut self, cx: &mut UpdateContext) {
        self.shown = self.value.get().clamp(0.0, 1.0);
        let value = self.shown;
        let [w, h] = cx.size();
        self.drawing.record_in(cx, |c| {
            let (center, r) = ([w * 0.5, h * 0.56], (w * 0.5).min(h * 0.62) - 10.0);
            let arc = |to: f32| -> Vec<[f32; 2]> {
                let steps = 48;
                (0..=steps)
                    .map(|i| {
                        let a = START + to * SWEEP * i as f32 / steps as f32;
                        [center[0] + r * a.cos(), center[1] + r * a.sin()]
                    })
                    .collect()
            };
            c.polyline(&arc(1.0), Stroke::new(10.0).round(), TRACK);
            if value > 0.0 {
                c.polyline(&arc(value), Stroke::new(10.0).round(), ACCENT);
            }
            let tip = START + value * SWEEP;
            c.line(center, [center[0] + (r - 18.0) * tip.cos(), center[1] + (r - 18.0) * tip.sin()], Stroke::new(3.0).round(), ACCENT);
            c.fill_circle(center[0], center[1], 5.0, ACCENT);
            let label = CanvasTextStyle::new(20.0).font_weight(600.0).align(Align::Center, Align::Center).tabular_numbers(true);
            c.text(center[0], center[1] + r * 0.55, format!("{:.0}%", value * 100.0), &label);
        });
    }

    fn paint(&mut self, cx: &mut PaintContext) {
        self.drawing.paint(cx);
    }

    fn unmount(&mut self, cx: &mut UnmountContext) {
        self.drawing.release(cx);
    }

    fn describe(&self, info: &mut KindInfo) {
        info.summary = Some(format!("{:.0}%", self.shown * 100.0));
    }
}

/// 仪表盘元素：读数是 0..1 的信号
pub fn gauge(value: Signal<f32>) -> Element {
    Element::from_kind(Gauge { value, shown: 0.0, drawing: Drawing::new() })
}
```

| 方法 | 什么时候调用 | 不写时 |
|---|---|---|
| `name` | 快照、种类的登记表按它认元素，和工厂函数同名 | 必须写 |
| `paint` | 生成显示列表时 | 必须写 |
| `kind_mask` | 属性的 `applies_to` 按它判断适不适用 | `KindMask::CUSTOM`：只收任何元素都适用的属性，设了不适用的属性调试构建里提示一次 |
| `hooks` | 挂载时读一次，要参与哪些每帧步骤：`UPDATE`、`TICK`、`SCALE_FACTOR`（窗口缩放变了重新量） | 都不参与 |
| `measure`、`baselines` | 布局：已知的宽高和父元素给的空间 → 内容区的大小；按基线对齐时的基线 | 样式给多大就多大；没有基线 |
| `restyle`、`refresh_fonts` | 继承的文字样式变了、加载了新字体，返回要重做什么（`Dirty`） | 什么都不做 |
| `update` | 声明了 `UPDATE`：在树外读信号、更新内容 | 什么都不做 |
| `tick`、`next_frame` | 声明了 `TICK`：每帧推进自己的时钟；下一帧什么时候要 | 不要帧 |
| `unmount` | 卸载时还回占着的资源 | 什么都不做 |
| `describe` | 测试工具读快照时：说明、显示的文字 | 空的 |

**按时刻要帧**：自己带时钟的元素（闪烁的插入点、走表）从 `next_frame` 返回 `NextFrame::At(时刻)`，窗口在那之前睡着，帧时钟暂停、事件循环不醒，到点出一帧；只有真的每帧都在变才返回 `NextFrame::Continuous`，什么都不等时返回 `NextFrame::Idle`（第 [22](22-性能指南.md) 章）。

**改设置**：工厂函数之后要改种类对象上的设置，用 `Element::kind_mut::<K>()` 取回；`Element::kind::<K>()` 只读。自定义元素不能往属性表里加属性：设置放在自己的字段里（工厂函数的参数、`kind_mut`）。

## 接输入：`InputTarget`

实现 `InputTarget`，在 `ElementKind` 上把两个挂点指向自己。**查询走只读的挂点**（能不能拿焦点、指针形状），**改走可变的挂点**（按键、指针）：

```rust
/// 输入目标：能拿焦点（Tab 也走得到），按左半边减、右半边加，↑ ↓ 也行
struct Stepper {
    value: Signal<i32>,
    drawing: Drawing,
}

impl ElementKind for Stepper {
    fn name(&self) -> &'static str {
        "stepper"
    }

    fn hooks(&self) -> KindHooks {
        KindHooks::UPDATE
    }

    /// 没给大小时 120 x 32
    fn measure(&mut self, _: &mut MeasureContext, known: [Option<f32>; 2], _: [AvailableSpace; 2]) -> [f32; 2] {
        [known[0].unwrap_or(120.0), known[1].unwrap_or(32.0)]
    }

    /// 中间的数字用继承的字体
    fn restyle(&mut self, cx: &StyleContext) -> Dirty {
        if self.drawing.restyle(cx) { Dirty::PAINT } else { Dirty::empty() }
    }

    fn update(&mut self, cx: &mut UpdateContext) {
        let value = self.value.get();
        let [w, h] = cx.size();
        self.drawing.record_in(cx, |c| {
            c.stroke_round_rect(0.5, 0.5, w - 1.0, h - 1.0, 4.0, 1.0, LINE);
            let style = CanvasTextStyle::new(14.0).align(Align::Center, Align::Center);
            c.text(16.0, h * 0.5, "−", &style);
            c.text(w * 0.5, h * 0.5, value.to_string(), &style.clone().tabular_numbers(true));
            c.text(w - 16.0, h * 0.5, "+", &style);
        });
    }

    fn paint(&mut self, cx: &mut PaintContext) {
        self.drawing.paint(cx);
    }

    fn unmount(&mut self, cx: &mut UnmountContext) {
        self.drawing.release(cx);
    }

    fn describe(&self, info: &mut KindInfo) {
        info.summary = Some(self.value.get_untracked().to_string());
    }

    // 两个挂点：查询走只读的，改走可变的
    fn input_target(&self) -> Option<&dyn InputTarget> {
        Some(self)
    }

    fn input_target_mut(&mut self) -> Option<&mut dyn InputTarget> {
        Some(self)
    }
}

impl InputTarget for Stepper {
    fn focusable(&self) -> Focusable {
        Focusable::Keyboard
    }

    fn on_pointer(&mut self, event: &PointerEvent, cx: &mut TargetContext) -> Handled {
        if event.kind == PointerEventKind::Down {
            let step = if event.position[0] < cx.size()[0] * 0.5 { -1 } else { 1 };
            self.value.update(|v| *v += step);
        }
        Handled::Yes
    }

    fn on_key_down(&mut self, event: &KeyEvent, _: &mut TargetContext) -> Handled {
        let step = match event.key {
            Key::Named(NamedKey::ArrowUp) => 1,
            Key::Named(NamedKey::ArrowDown) => -1,
            _ => return Handled::No, // 别的键照常往外传：Tab、快捷键
        };
        self.value.update(|v| *v += step);
        Handled::Yes
    }

    fn cursor(&self, _: [f32; 2], _: Rect) -> Option<Cursor> {
        Some(Cursor::Pointer)
    }
}

pub fn stepper(value: Signal<i32>) -> Element {
    Element::from_kind(Stepper { value, drawing: Drawing::new() })
}
```

| 方法 | 元素树什么时候调用 | 取消它的内置行为 |
|---|---|---|
| `hit(位置, 内容区)` | 指针按下找拿焦点的元素：`None` 表示这一点不归它，`SubTarget::Part(n)` 是里面的第几部分 | `Builtin::FOCUS` |
| `focusable()` | `Focusable::No`、`Pointer`（只有按下）、`Keyboard`（Tab 也走到） | |
| `on_pointer(事件, cx)` | 拿到焦点的那次按下，之后的移动、松开；按下返回 `Handled::Yes` 时指针移出元素也继续交给它 | `Builtin::TEXT_SELECT` |
| `on_key_down(事件, cx)` | 焦点在它上面时，目标阶段、用户的处理器之后；返回 `Handled::Yes` 时停止传播 | `Builtin::EDIT` |
| `on_focus(是否, cx)` | 得到、失去焦点 | |
| `cursor(位置, 内容区)` | 指针形状；`None` 时按元素的 `.cursor(..)` | |
| `wants_text_input()` | 有焦点时开不开输入法；也表示它自己处理点击和方向键（点击不往外传，方向键不滚外面的视口） | |

- 坐标都是元素自己的：左上角是原点，逻辑像素。
- `TargetContext` 给 `size()`、`content_rect()`、`now()`、`scale_factor()`、`is_focused()`；要求重做用 `request_paint()`、`request_layout()`、`request_accessibility()`，交出焦点用 `unfocus()`。内容来自信号时写信号就够了，下一帧 `update` 会再调用。
- 元素上用户的 `on_key_down` 排在 `InputTarget::on_key_down` 前面，能用 `prevent_builtin(Builtin::EDIT)` 取消它，能在捕获阶段截下来，和输入框一样。

## 接输入法：`TextInputClient`

要打字的元素（编辑器、终端）再实现 `TextInputClient`，`wants_text_input` 返回 `true`。输入法、听写、辅助技术改文字都走这几个方法：

```rust
/// 文字输入客户端：一行能接输入法的编辑区（插入点总在末尾，只为说明接口）
struct CodeLine {
    text: Signal<String>,
    preedit: Signal<String>,
    drawing: Drawing,
}

impl ElementKind for CodeLine {
    fn name(&self) -> &'static str {
        "code_line"
    }

    fn hooks(&self) -> KindHooks {
        KindHooks::UPDATE
    }

    fn restyle(&mut self, cx: &StyleContext) -> Dirty {
        if self.drawing.restyle(cx) { Dirty::PAINT } else { Dirty::empty() }
    }

    fn update(&mut self, cx: &mut UpdateContext) {
        let shown = format!("{}{}", self.text.get(), self.preedit.get()); // 预编辑跟在后面，不算内容
        let [_, h] = cx.size();
        self.drawing.record_in(cx, |c| {
            c.text(4.0, h * 0.5, shown, &CanvasTextStyle::new(14.0).align(Align::Start, Align::Center));
        });
    }

    fn paint(&mut self, cx: &mut PaintContext) {
        self.drawing.paint(cx);
    }

    fn unmount(&mut self, cx: &mut UnmountContext) {
        self.drawing.release(cx);
    }

    fn input_target(&self) -> Option<&dyn InputTarget> {
        Some(self)
    }

    fn input_target_mut(&mut self) -> Option<&mut dyn InputTarget> {
        Some(self)
    }

    fn text_input_client(&self) -> Option<&dyn TextInputClient> {
        Some(self)
    }

    fn text_input_client_mut(&mut self) -> Option<&mut dyn TextInputClient> {
        Some(self)
    }
}

impl InputTarget for CodeLine {
    fn focusable(&self) -> Focusable {
        Focusable::Keyboard
    }

    /// 打字：用按键管线定好的规则，组合键、组字中、控制字符时没有文字，留给快捷键
    fn on_key_down(&mut self, event: &KeyEvent, _: &mut TargetContext) -> Handled {
        match event.typed_text() {
            Some(typed) => {
                self.text.update(|t| t.push_str(typed));
                Handled::Yes
            }
            None => Handled::No,
        }
    }

    /// 有焦点时打开输入法，文字交给下面的客户端
    fn wants_text_input(&self) -> bool {
        true
    }

    fn cursor(&self, _: [f32; 2], _: Rect) -> Option<Cursor> {
        Some(Cursor::Text)
    }
}

impl TextInputClient for CodeLine {
    fn purpose(&self) -> ImePurpose {
        ImePurpose::Terminal
    }

    /// 候选框避开这块区域，元素坐标
    fn caret_area(&self) -> Rect {
        Rect { x: 4.0, y: 4.0, width: 2.0, height: 16.0 }
    }

    fn set_preedit(&mut self, text: &str, _: Option<std::ops::Range<usize>>, _: &mut TargetContext) {
        self.preedit.set(text.to_owned());
    }

    /// 提交：自己先清掉预编辑，不依赖平台先送一个空的
    fn commit(&mut self, text: &str, _: &mut TargetContext) {
        self.preedit.set(String::new());
        self.text.update(|t| t.push_str(text));
    }

    /// 焦点换走、在别处按下、窗口失去焦点时元素树调用：放弃没确定的字
    fn cancel_composition(&mut self, _: &mut TargetContext) {
        self.preedit.set(String::new());
    }
}

pub fn code_line(text: Signal<String>) -> Element {
    Element::from_kind(CodeLine { text, preedit: signal(String::new()), drawing: Drawing::new() })
}
```

| 方法 | 做什么 |
|---|---|
| `purpose()` | 用途：`ImePurpose::Normal`、`Password`（不开输入法，请求系统的安全输入）、`Terminal`、`Number` |
| `caret_area()` | 插入点（组字时是预编辑文字）的区域，元素坐标：候选框避开它 |
| `set_preedit(文字, 区间, cx)` | 预编辑：可能来好几次，空文字表示清掉；不算内容改了 |
| `commit(文字, cx)` | 提交：**自己先清掉预编辑**再插入，不依赖平台先送一个空的预编辑 |
| `cancel_composition(cx)` | 放弃正在组的字 |
| `surrounding()`、`delete_surrounding(前, 后, cx)` | 插入点周围的文字、删掉周围的字：联想和听写用；偏移都是字节 |
| `replace_range(范围, 文字, cx)` | 把一段字节范围换成文字：辅助技术改值、替换选中的文字 |

**组字的生命周期归元素树管**：焦点换走、在别处按下、元素或祖先被禁用、窗口失去焦点、元素卸载时，元素树调用 `cancel_composition`，并让平台的输入法重置，之后的提交不会落到别的元素上。组字期间的按键标上 `KeyEvent::composing`，`on_key_down` 不调用。

**打字还是快捷键**由按键管线定一次，所有输入目标共用：`e.typed_text()` 是这个键要打出的字，组合键（`e.is_chord()`）、组字中、控制字符时是 `None`，别自己看修饰键（AltGr 打的字别漏了）。

## 给辅助技术：`AccessibilityProvider`

```rust
/// 无障碍提供者：一排星星的评分，辅助技术看到一个滑块，每颗星是一个虚拟子节点，能直接改值
struct Rating {
    stars: Signal<u32>,
}

impl ElementKind for Rating {
    fn name(&self) -> &'static str {
        "rating"
    }

    fn hooks(&self) -> KindHooks {
        KindHooks::UPDATE
    }

    /// 读信号成为依赖：代码里改了星数，下一帧再调用，无障碍节点跟着更新
    fn update(&mut self, cx: &mut UpdateContext) {
        let _ = self.stars.get();
        cx.request_accessibility();
    }

    fn paint(&mut self, _: &mut PaintContext) {} // 画法和上面一样，这里省掉

    fn accessibility_provider(&self) -> Option<&dyn AccessibilityProvider> {
        Some(self)
    }

    fn accessibility_provider_mut(&mut self) -> Option<&mut dyn AccessibilityProvider> {
        Some(self)
    }
}

impl AccessibilityProvider for Rating {
    fn role(&self) -> Option<Role> {
        Some(Role::Slider)
    }

    fn write_node(&self, node: &mut accesskit::Node, cx: &AccessibilityContext) {
        node.set_numeric_value(self.stars.get_untracked() as f64);
        node.set_min_numeric_value(0.0);
        node.set_max_numeric_value(5.0);
        if !cx.is_disabled() {
            node.add_action(Action::SetValue);
        }
    }

    /// 版本（第二个参数）没变的星不重建、不重发
    fn virtual_children(&self, cx: &mut AccessibilityContext) {
        for i in 0..5u32 {
            let lit = i < self.stars.get_untracked();
            cx.push_child(i, lit as u64, || {
                let mut star = accesskit::Node::new(Role::Image);
                star.set_label(if lit { "亮着的星" } else { "暗着的星" });
                star.set_bounds(accesskit::Rect::new(i as f64 * 20.0, 0.0, i as f64 * 20.0 + 20.0, 20.0));
                star
            });
        }
    }

    fn action(&mut self, action: &AccessibilityAction, cx: &mut TargetContext) -> Handled {
        match (action.action, action.data) {
            (Action::SetValue, Some(ActionData::NumericValue(v))) => {
                self.stars.set(v.clamp(0.0, 5.0) as u32);
                cx.request_accessibility(); // 描述变了：重建这个元素的节点
                Handled::Yes
            }
            _ => Handled::No,
        }
    }
}

pub fn rating(stars: Signal<u32>) -> Element {
    Element::from_kind(Rating { stars })
}
```

- **元素树负责元素自己的那一部分**：编号、边界和变换、名字（`.accessibility_name(..)`）、描述、禁用、能获得焦点、滚动；元素上声明的无障碍属性优先。提供者补上内容。
- `role()`：元素上没声明角色时的角色，`None` 按元素推断。
- `write_node(节点, cx)`：值、选区、占位文字、能做的编辑动作；被禁用时（`cx.is_disabled()`）不要加动作。
- `virtual_children(cx)`：不是元素的子节点：按行的文字片段、链接、画布里的区域。`cx.push_child(编号, 版本, 建节点)`，版本和上次一样时不调用建节点的闭包，只重发变了的。
- `action(动作, cx)`：辅助技术发来的动作；返回 `Handled::No` 时元素树照通用的办（点击、聚焦、滚动、有文字输入客户端的元素整段改值）。

只有辅助技术打开时才调用，没开时没有开销。内容变了要告诉元素树重建节点：输入目标、动作里改了内容时在 `TargetContext` 里 `request_accessibility()`；值来自信号时在 `update` 里读它，再调 `UpdateContext::request_accessibility()`，代码里改了信号节点也跟着更新。怎么检查见第 [19](19-无障碍.md) 章。

## 按名字创建

```rust
/// 登记到种类表里：之后能按名字（`kind_spec("stepper")`）找到并做出一个
pub fn register() {
    register_kind(KindSpec { name: "stepper", kind_mask: KindMask::CUSTOM, create: || stepper(signal(0)) });
}
```

`kind_spec(名字)`、`kind_specs()` 查找，`KindSpec::properties()` 列出适用的属性，`(spec.create)()` 做出一个。内置的种类都在表里。

## 坑

- **`update` 之外读的信号不算依赖**：`paint`、`measure`、`on_key_down` 里读信号不会让元素更新。要跟着信号变的内容都放进 `update`。
- 只声明了 `UPDATE` 没读任何信号时，`update` 只在大小变了时调用：内容是常量时这样正好。
- 忘了 `input_target` / `input_target_mut` 两个挂点，元素拿不到焦点也收不到按键，不会报错；两个都要写。
- 没写 `Focusable::Keyboard` 时 Tab 走不到；只想按下时拿焦点用 `Focusable::Pointer`，元素上再设 `.focusable(true)` 时 Tab 也走得到。
- 卸载时不 `release`，路径图集的块还不回去。
- 文字输入客户端的偏移是**字节**，不是字符。
- 自定义元素不能自己滚：多行输入框的滚动范围是内置的特例。要滚就把元素放进滚动视口。
