# 6. 文字与字体

## 文字样式和继承

```rust
const ARTICLE: &str = "本框架用纯 Rust 写桌面应用。文字按元素的宽度自动换行，中文按字断行，English words break between words，emoji 🎉 由系统字体回退。";

pub fn basics() -> Element {
    column()
        .gap(8)
        .font_size(15) // 字号、字重、行高、颜色设在容器上，里面的文字都继承
        .color(TEXT)
        .child(text("标题").font_size(24).font_weight(700)) // 自己设的优先
        .child(text(ARTICLE).line_height(1.6))
        .child(text("已完成").strikethrough(true).color(MUTED))
        .child(text("链接").underline(true).color(ACCENT))
        .child(text("Note 斜体").italic(true).letter_spacing(1.5))
}
```

- 字号（默认 14）、字重（100～900，默认 400）、行高（字号的倍数，默认 1.4）、颜色、字体族、斜体、字距、对齐、等宽数字、选区颜色都可以设在任何元素上，子孙里的文字继承，自己设的优先。下划线、删除线、`max_lines`、`selectable` 只对自己。
- 中英混排、emoji 由系统字体自动回退；没有斜体字形的字体（比如中文字体）会把字形倾斜着画出来。
- 改文字颜色只重画；改内容、字号、字重、行高才重新排版。

## 对齐、截断、等宽数字

```rust
pub fn layout() -> Element {
    let elapsed = signal(12.5f32);
    column()
        .width(320)
        .gap(12)
        .child(text("居中").text_align(TextAlign::Center))
        .child(text(ARTICLE).text_align(TextAlign::Justify)) // 两端对齐
        .child(text(ARTICLE).max_lines(2)) // 超过两行截断，末尾加省略号
        .child(text(move || format!("{:>8.2} 秒", elapsed.get())).tabular_numbers(true)) // 等宽数字：跳动时不左右晃
}
```

`TextAlign` 有 `Start`、`Center`、`End`、`Justify`，在文字元素自己的宽度里对齐。`max_lines(n)` 截断时中文按字截，不会切开半个字，高度正好是 n 行。

## 可选中的文字

```rust
pub fn selectable() -> Element {
    text(ARTICLE)
        .selectable(true) // 拖选、双击选词、三击选段、⌘C、⌘A、Shift+方向键
        .selection_color(ACCENT.with_alpha(0.3))
}
```

## 自定义字体

```rust
pub fn custom_font() -> Element {
    // 加载后返回字体族名；文件不在时退回系统字体
    let family = aureole::font::load_file("assets/LXGWWenKai.ttf").ok().and_then(|names| names.into_iter().next());
    let title = text("落霞与孤鹜齐飞").font_size(28);
    match family {
        Some(name) => title.font_family(name),
        None => title.font_family("PingFang SC"), // 系统里装的字体直接用名字
    }
}
```

- `aureole::font::load_file(路径)` / `aureole::font::load(字节)` 支持 TTF、OTF、TTC 和压缩过的 WOFF2、WOFF，返回其中的字体族名。WOFF2、WOFF 要打开 `woff2` 特性（默认关，release 二进制大约多 260 KB）：在 `Cargo.toml` 的依赖上加 `features = ["woff2"]`（`aureole = { path = "…", features = ["woff2"] }`），加载时先解压再登记。不是字体（包括没打开 `woff2` 时的 WOFF2、WOFF）时返回 `InvalidData` 错误。可以在任何线程加载（比如在 `spawn_blocking` 里读文件；几千个汉字的 WOFF2 子集解压要二三十毫秒）。
- 先显示、后加载也没关系：加载后下一帧已经排好的文字会重新排版。
- `.font_family(名字)` 里没有的字（比如英文字体里的中文）从系统字体回退。

## 富文本和链接

```rust
pub fn rich() -> Element {
    let unread = signal(3);
    rich_text()
        .span("用 ")
        .code("rich_text()") // 行内代码：等宽字体、淡淡的底色
        .span(" 在一段里混排")
        .span(span("加粗").font_weight(600))
        .span("、")
        .span(span("大字").font_size(20))
        .span("、")
        .span(span(move || format!("{} 条未读", unread.get())).color(DANGER)) // 文字、颜色可以绑定
        .span("和")
        .link("链接", "https://example.com/docs") // 点击用系统打开；Tab 走到、回车也行
        .span("。")
        .on_link_click(|url| println!("打开 {url}")) // 设了就交给它，不再用系统打开
        .font_size(15) // 整段的样式设在元素上，每段只设不同的
        .selectable(true)
}
```

- 整段一次排版：跨段换行、对齐、`max_lines` 截断、`selectable` 选中复制都和 `text()` 一样，不同字号的字落在同一条基线上。`text("…").span(…)` 也行，原来的文字成为第一段。
- `span(文字)` 可以设 `font_size`、`font_weight`、`color`、`italic`、`underline`、`strikethrough`、`code`、`font_family`、`letter_spacing`；文字、字号、字重、颜色可以绑定信号。改颜色只重画，改文字、字号、字重才重新排版。
- 链接是强调色（`#2563eb`），指针放上去变成手指、出现下划线；Tab 能走到（焦点环画在链接上），回车、空格打开；读屏软件读出"链接"。`span("设置").on_click(…)` 做成调用处理器的链接。链接和行内代码尽量不在中间断行。
- 测试里点链接不真的打开网址，`Harness::opened_urls()` 读打开过的网址，`Harness::link_bounds(名字, 第几个)` 给出链接的位置。

## 行内元素

一段字里可以放图片、按钮，或者任何元素：

```rust
pub fn inline_elements() -> Element {
    let done = signal(false);
    let logo = rect().size(16, 16).radius(4).background(ACCENT_SOFT);
    rich_text()
        .span("点 ")
        .inline(button("开始").on_click(move || done.set(true))) // 放任何元素：点击、悬停、Tab 都照常
        .span(" 跑一遍，徽标 ")
        .inline(logo.inline_align(InlineAlign::Center).accessibility_name("徽标")) // 默认基线对齐；复制时算成这个名字
        .span(" 放在字中间，状态：")
        .inline(move || if done.get() { text("完成").color(SUCCESS) } else { text("没开始") }) // 闭包：信号变了换一个新的
        .span("。")
        .link("链接", "https://example.com/docs") // Tab 按文字里的先后走过链接和按钮
        .selectable(true) // 选区能跨过元素
        .line_height(1.6)
}
```

- 放进去的是元素树里真的元素：自己的布局、绘制、动画、悬停、点击、Tab、无障碍都照常，继承段落的文字样式，段落的变换、合成层、滚动带着它走。
- 占的地方就是它的大小（算上外边距）。大小变了（图片加载完、绑定变了）文字重新断行，不重新整形；放不下时整个挪到下一行。百分比的大小按段落内容区的宽度算。
- `.inline_align(..)` 设在元素上，选这一行里怎么放：`InlineAlign::Baseline`（默认：有字的元素按它的第一行字，别的是底边）、`Center`（图标放在字中间）、`TextTop`、`TextBottom`、`Top`、`Bottom`。元素比行高时行高被它撑开。
- `.inline(闭包)` 读到的信号变了就换一个新的元素。元素的属性能绑定的不用这样：闭包是用来换元素本身的；要变的只是大小、颜色时绑定它们，元素和它的状态都留着。
- `max_lines` 截掉的元素不显示、不响应，放得下了再回来。居中、右对齐、从右到左的文字、`flow()` 绕排都带着它。
- 选区能跨过元素，盖住时元素上面盖一层选区的颜色；按在不响应指针的元素（图片）上和按在字上一样开始选字，双击选中它。**复制时**换成它的 `accessibility_name`，没有时是它里面的文字，都没有时什么都不留。
- Tab 按文字里的先后走过链接和元素里能拿焦点的东西。

## 跨段落选择

```rust
pub fn scoped_selection() -> Element {
    column()
        .selection_root(true) // 里面的文字连成一串：从一段拖到另一段，⌘C 复制时段落之间换行
        .gap(8)
        .child(text("第一段：不用逐个写 selectable()"))
        .child(text(ARTICLE))
        .child(rich_text().span("富文本也是一段，").span(span("加粗").font_weight(600)))
        .child(row().gap(8).child(text("梨茶").font_weight(500)).child(text("并排的两段复制时用制表符隔开")))
        .child(button("按钮里的字不参加"))
}
```

- 范围里的文字（子孙里的 `text`、`rich_text`）都能选，Shift+点击扩展，双击、三击之后拖动按词、按段跨段扩展，⌘A 选中范围里的全部。可点击、能获得焦点的元素（按钮）里的字和输入框不参加；范围里再套一个范围时各选各的。
- 选区画法和单段文字一样：有焦点时是半透明的强调色，点别处之后画成淡淡的灰。
- 键盘：点一下或者拖完之后，Shift+方向键从活动端（后动的那一头）接着扩展、收缩，到段尾接下一段；上下移动保持横向位置，能跨过高度不同的段，跳过空段和按钮。活动端移出滚动视口时滚到看得见。单独一段 `selectable(true)` 的文字也一样。修饰键按平台惯例：

  | 动作 | macOS | Windows、Linux |
  |---|---|---|
  | 按词 | Shift+Option+← → | Shift+Ctrl+← → |
  | 行首行尾 | Shift+⌘+← →，Shift+Home / End | Shift+Home / End |
  | 整个范围的开头结尾 | Shift+⌘+↑ ↓ | Shift+Ctrl+Home / End |

- 没点过时这些键照常往外传；不带 Shift 的方向键不动选区，照常滚动。
- 虚拟列表放进范围里也行，但只有挂载着的行能选；选区一端所在的行滚出去卸载后（用键盘一直往下扩展、起点的行滚远了也算），整个选区清空。

## 绕排

```rust
pub fn wrapped_article() -> Element {
    flow()
        .width(480)
        .flow_left(rect().size(120, 90).radius(8).background(ACCENT_SOFT)) // 图片、卡片都行
        .child(text(ARTICLE).selectable(true)) // 挨着它的行从它右边开始，过了它的底边回到整行宽
        .flow_right(text("引文卡片").padding(8).radius(6).background(FILL))
        .child(text(ARTICLE))
        .flow_gap(12) // 元素和字之间的距离，默认 12
}
```

- `flow()` 是纵向容器；`flow_left` / `flow_right` 放进去的元素顶和下一段对齐、贴着左边或右边，后面的段落绕着它排，选中、富文本、链接、对齐、截断都照常。
- 只有直接放在 `flow()` 里的文字绕排；绕排的元素比最后一段还高时，最后一段延长到它的底边，容器把它包住。

## 字符网格

在 `char-grid` 特性后面，默认开。

```rust
pub fn terminal() -> Element {
    let grid = CharGrid::new(80, 24);
    grid.write(0, 0, "$ cargo run", CharCellStyle::default());
    grid.write(1, 0, "   Compiling", CharCellStyle::default().foreground(SUCCESS).bold(true));
    grid.write(1, 13, "终端里的汉字、emoji 占两格", CharCellStyle::default());
    grid.write(1, 40, "e\u{301} 👩\u{200D}💻 🇨🇳", CharCellStyle::default()); // 组合的字素簇在一格或两格里
    grid.write(1, 50, "过时的", CharCellStyle::default().strikethrough(true));
    grid.set_caret(CharGridCaret::at(2, 0)); // 方块插入点，闪烁；.shape(CaretShape::Bar) 换成竖线
    let g = grid.clone();
    let type_in = move |typed: &str| {
        let caret = g.caret();
        let column = g.write(caret.row, caret.column, typed, CharCellStyle::default());
        g.set_caret(CharGridCaret { column, ..caret });
    };
    let on_key = type_in.clone();
    char_grid(&grid)
        .font_size(13)
        .line_height(1.2)
        .on_key_down(move |e: &KeyEvent| {
            // 这个键打出的字；组合键、组字中没有
            if let Some(typed) = e.typed_text() {
                on_key(typed);
                e.stop_propagation();
            }
        })
        .on_text_insert(move |typed| type_in(&typed)) // 输入法提交的字；设了它，网格有焦点时开输入法
}
```

- `CharGrid` 是数据（克隆出来的是同一个），往里写字、清行、`scroll_up` 滚屏、放插入点、设选区；`char_grid(&grid)` 显示它。每格一个字（汉字、emoji 占两格）、前景色、底色、粗体、斜体、下划线、删除线、反色。
- **一格放一整个字素簇**：带变音符号的字（`e` + U+0301）一格，组合的 emoji（👩‍💻、👍🏽、🇨🇳、1️⃣、❤️）两格，不拆开。`write` 按簇切开；终端逐字符写时用 `col = grid.set(row, col, ch, style)`，变音符号这类组合字符接到前一格上（样式还是前一格的），`col` 不前进，结果和一次写一样。程序的输出分段到来、断在组合序列中间也一样。
- 写过的行下一帧才重新生成图元，其他行用缓存。`grid.stats().rows_built` 数生成过几行，`shapes_built` 数整形过几段。
- **连字**：`.ligated(true)` 打开，同样式连续的格子一起整形，编程字体的 `->`、`!=` 连起来画，字形还在各自的格子上，插入点、选区、复制都还是一格一格的。默认关：终端一般要程序输出什么就画什么，开着时改一行要多整形这一行没见过的词。
- 指针拖动选择、双击选词、三击选行，⌘C 复制、⌘A 全选；点一下获得焦点，按键交给 `on_key_down`。没有焦点时方块插入点是空心的。
- **输入法**：设了 `.on_text_insert(|文字| ..)` 时网格有焦点就开输入法，预编辑画在插入点处，提交的文字交给它。`e.typed_text()` 是单个键打出的字，`on_text_insert` 收输入法提交的。

## 坑

- 文字按**元素的宽度**换行。横排里没给宽度、也没有 `grow` 的文字按内容宽度排，放不下时会被压窄、换行；需要占满剩余宽度时给它 `.grow(1)`。
- `max_lines`、`text_align` 要有确定的宽度才有意义。
- 双击选词、Option+方向键在中文、日文里按词典分的词走（ICU4X 的中日文词典，`cjk-words` 特性，默认打开，二进制多 2 MB）；`default-features = false` 关掉时按字走。
- 点别处之后选区还在，画成淡淡的灰，⌘C 只在有焦点时复制；再点这段文字时重新选。
- 跨元素选择要放在 `selection_root(true)` 里；没有范围时每段文字各选各的。加载过的字体不能卸载。
- 字符网格默认的行高是继承来的 1.4，终端一般用 `.line_height(1.2)`。
- 字符网格的光标列要用 `set`、`write` 返回的列：组合字符不前进，`❤` 后面接 U+FE0F 变宽时前进一格。行首的组合字符没有前一格可接，丢掉。
