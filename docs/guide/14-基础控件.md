# 14. 基础控件

框架只带最基础的一套控件，像系统自带的表单控件那样：按钮、输入框（单行、多行，单行有密码模式）、复选框（含半选）、单选组、开关、下拉选择、滑块、进度条、数字输入、标签，以及表格、日历、日期选择、时间选择、颜色选择、文件选择。

- **行为是完整的**：点击、键盘、焦点和焦点环、禁用、拖动、弹出的列表、无障碍（角色、状态、数值、操作）都在控件里，用的时候不用自己写处理器。控件处理完自己的点击、按键都停止传播，外面的元素收不到（第 [11](11-交互.md) 章）。
- **样子朴素**：浅色、深色两套（跟着应用的外观，默认跟着系统，深色只换底色、表面、文字和描边），中性的灰加一个偏蓝的强调色，1 像素细线、小圆角；**没有内置动画**，状态一变立即换成新的样子。
- **改样子**用链式方法和样式对象（第 [13](13-样式对象.md) 章）。控件默认的样子就是先用上的样式对象，所以自己给的样式对象按状态合进去，链式方法盖过它。


## 一览

```rust
pub fn controls() -> Element {
    #[derive(Clone, Copy, PartialEq)]
    enum Plan {
        Free,
        Pro,
    }
    let (name, agree, wifi, plan) = (signal(String::new()), signal(false), signal(true), signal(Plan::Free));
    let (city, volume, copies) = (signal("hz"), signal(0.6f32), signal(1.0f64));
    column()
        .gap(12)
        .child(row().gap(8).child(button("取消")).child(button("保存").on_click(|| println!("保存"))))
        .child(text_field(name).placeholder("名字"))
        .child(checkbox(agree).label("同意条款"))
        .child(switch(wifi).label("无线局域网"))
        .child(radio_group(plan, [(Plan::Free, "免费版"), (Plan::Pro, "专业版")]).direction(Direction::Row))
        .child(select(city, [("bj", "北京"), ("sh", "上海"), ("hz", "杭州")]))
        .child(row().gap(12).align(Align::Center).child(slider(volume)).child(text(move || format!("{:.0}%", volume.get() * 100.0))))
        .child(progress_bar(move || volume.get()))
        .child(number_field(copies).range(1.0, 99.0))
}
```

- 按钮、输入框本身就是元素（`button(..)`、`text_field(..)`、`text_area(..)` 返回 `Element`），接着用元素的链式方法：`.on_click(..)`、`.disabled(..)`、`.width(..)`、`.tooltip(..)`、`.style(&s)`。按钮里放任何 `View`：文字、图标、几样排在一起（后面还能 `.child(..)` 接着加，横着排、间距 6）。
- 别的控件有几个部位，是构建器：直接放进 `.child(..)`，元素的方法照样能接着用：`slider(v).width(240)`、`select(..).name("city")`、`checkbox(v).on_click(..)`。点击、悬停、拖动、按键这些事件和普通元素一样，控件自己的功能也还在。函数要返回 `Element` 时再 `.build()`。
- 控件默认按内容的宽度，不会被竖排容器拉宽；没有内容宽度的有默认宽度（输入框 200、多行 320、滑块 200、进度条 200）。要占满时 `.full_width(true)`。
- 有值的控件都绑定一个信号，用户改了写回信号，代码里改信号时控件跟着变。

| 控件 | 写法 | 部位 | 状态 |
|---|---|---|---|
| 按钮 | `button(内容)` | 本身（`.style`） | 悬停、按下、焦点、禁用 |
| 输入框 | `text_field(信号)`、`text_area(信号)`，`.password(..)`（第 [7](07-输入框和多行编辑.md) 章） | 本身 | 悬停、焦点（有焦点就算）、禁用 |
| 复选框 | `checkbox(Signal<bool>)`：`.label(..)`、`.indeterminate(..)` 半选 | `.style` 整行、`.indicator_style` 方框、`.mark_style` 勾和横线 | 悬停、按下、焦点、禁用；勾选（勾上或半选） |
| 开关 | `switch(Signal<bool>)`：`.label(..)` | `.style` 整行、`.track_style` 轨道、`.thumb_style` 圆钮 | 悬停、按下、焦点、禁用；勾选（打开着） |
| 单选组 | `radio_group(信号, [(值, 文字)..])` 或 `RadioGroup::new(信号).option(值, 文字)`：`.direction(Direction::Row)` 横排 | `.style` 整组、`.item_style` 每一项、`.indicator_style` 圆、`.mark_style` 圆点 | 每一项的悬停、按下，整组的焦点、禁用；勾选（这一项选中） |
| 下拉选择 | `select(信号, [(值, 文字)..])` 或 `Select::new(信号).option(值, 文字)`：`.placeholder(..)` | `.style` 按钮、`.arrow_style` 箭头、`.list_style` 弹出的列表、`.option_style` 每个选项、`.mark_style` 选中项的勾 | 按钮：悬停、按下、焦点、禁用、打开；选项：悬停、按下、焦点（键盘或指针所在）、选中（当前的值） |
| 滑块 | `slider(Signal<f32>)`（0..1）或 `Slider::new(信号).range(a, b).step(s)`，`.vertical(true)` 竖着放（上面是大的） | `.style` 外壳、`.track_style` 轨道、`.fill_style` 已填的部分、`.thumb_style` 圆钮 | 悬停、按下（拖动中）、焦点、禁用，各部位都是整个滑块的 |
| 进度条 | `progress_bar(0..1 的值)`、`ProgressBar::indeterminate()` | `.style` 轨道、`.fill_style` 填充 | 没有 |
| 数字输入 | `number_field(Signal<f64>)` 或 `NumberField::new(信号).range(a, b).step(s).precision(小数位)` | `.style` 外框、`.field_style` 中间的输入框、`.button_style` 两边的按钮 | 外框：悬停、焦点（中间的输入框有焦点）、禁用；按钮：悬停、按下、禁用（到头了） |
| 标签 | `label(文字).target(焦点句柄)` | `.style` | 没有 |
| 日历 | `calendar(信号)` 或 `Calendar::new(信号)`：`.range(a, b)`、`.disabled_dates(判断)`、`.first_weekday(..)` | `.style` 面板、`.header_style` 标题、`.nav_style` 翻页按钮、`.weekday_style` 星期、`.day_style` 一天、`.action_style` "今天""清除"、`.footer_style` 它们那一行；`.day_content(..)` 自己决定一天里放什么 | 一天：悬停、按下、焦点、选中（当前的值）、勾选（今天）、禁用（别的月的、不能选的） |
| 日期选择 | `date_picker(信号)` 或 `DatePicker::new(信号)`，还有日历的那些设置，`.placeholder(..)`、`.format(..)`、`.parse(..)` | `.style` 外框、`.field_style` 输入框、`.button_style` 按钮、`.panel_style` 面板，加日历的部位 | 外框：焦点、打开、禁用 |
| 时间选择 | `time_picker(信号)` 或 `TimePicker::new(信号)`：`.range(a, b)`、`.minute_step(n)`、`.seconds(true)`、`.twelve_hour(true)` | `.style` 外框、`.field_style`、`.button_style`、`.panel_style`、`.column_style` 列、`.item_style` 项、`.action_style` 下面的按钮、`.footer_style` 那一行 | 项：悬停、按下、焦点、选中、禁用（范围外的） |
| 颜色面板 | `color_panel_view(信号)` 或 `ColorPanel::new(信号)`：`.alpha(false)` 不要透明度、`.swatches([颜色..])`、`.format(ColorFormat::Rgb)`、`.formats([..])` | `.style` 面板、`.area_style` 色板、`.thumb_style` 圆钮、`.hue_style` `.alpha_style` `.slider_track_style` `.slider_thumb_style` 滑块、`.value_field_style` 输入框、`.format_style` 编码类型、`.preview_style` 预览、`.swatch_style` 常用颜色；`.tile_radius(..)` 色块的圆角 | 色板：悬停、按下、焦点；常用颜色多一个选中 |
| 颜色选择 | `color_picker(信号)` 或 `ColorPicker::new(信号)`，还有面板的那些设置 | `.style` 外框、`.field_style`、`.button_style`、`.panel_style`，加面板的部位 | 外框：焦点、打开、禁用 |
| 文件选择 | `file_picker(信号)` 或 `FilePicker::new(信号)`：`.kind(..)`、`.file_filter(名字, 扩展名)`、`.droppable(..)` | `.style` 外壳、`.button_style`、`.label_style` 文字、`.clear_style` 清除按钮 | 外壳：打开（文件拖到上面了）、禁用 |

复选框、开关、单选组、下拉选择、滑块、数字输入的构建器上还有 `.disabled(..)`（变淡、不响应、Tab 跳过）和 `.focus_handle(句柄)`；按钮、输入框用元素的 `.disabled(..)`、`.focus_handle(..)`。

## 日期、时间、颜色、文件

```rust
pub fn pickers() -> Element {
    use std::path::PathBuf;
    let (day, due) = (signal(Date::new(2026, 11, 5)), signal(None::<Date>));
    let at = signal(Time::new(14, 30));
    let color = signal(Color::hex(0x2563eb));
    let (file, photos) = (signal(None::<PathBuf>), signal(Vec::<PathBuf>::new()));
    column()
        .gap(12)
        // 日期：能直接打字，右边的按钮或 ↓ 弹出日历
        .child(date_picker(day))
        // 绑定 Option 时能清除；范围外的、周末不能选
        .child(
            DatePicker::new(due)
                .placeholder("截止日期")
                .range(today(), today().add_years(1))
                .disabled_dates(|d| matches!(d.weekday(), Weekday::Saturday | Weekday::Sunday)),
        )
        // 时间：五分钟一档
        .child(TimePicker::new(at).minute_step(5))
        // 颜色：弹出色板、透明度、色相，能选编码类型，有几个常用颜色
        .child(ColorPicker::new(color).format(ColorFormat::Rgb).swatches([Color::hex(0xef4444), Color::hex(0x22c55e), Color::hex(0x2563eb)]))
        // 文件：系统的对话框，也能把文件拖进来。绑定 Vec 时选多个
        .child(FilePicker::new(file).file_filter("图片", &["png", "jpg", "webp"]))
        .child(file_picker(photos))
}
```

**值的类型**：日期是 `Date`，时间是 `Time`，都不带时区。框架不在公开接口里绑定第三方的日期库，用哪个都行，用 `year()`、`month()`、`day()` 和 `Date::new` 互相转换。`today()` 是今天的本地日期。写死的日期用 `Date::new(2026, 11, 5)`（没有这一天时 panic），来自用户、文件的用 `Date::checked(..)` 或 `"2026-11-05".parse()`。

**能不能为空看绑定的类型**：绑定 `Date` 总是有值；绑定 `Option<Date>` 时多一个"清除"按钮，把输入框清空也是清除。时间一样。文件选择绑定 `Option<PathBuf>` 选一个，绑定 `Vec<PathBuf>` 选多个。

**改了、改完了**：日期、文件每次选都是改完了。时间、颜色弹出的面板开着时，每动一下都调用 `on_change`，关上面板时才调用 `on_commit`（值变了才调用）；Esc 恢复打开时的值。

**颜色的编码类型**：颜色面板和颜色选择的输入框能选 HEX、RGB、HSL、HSV，默认是 HEX。输入框按现在选的编码读，带名字的写法（`#…`、`rgb(…)`、`hsl(…)`、`hsv(…)`）不管选的是哪种都认。不写透明度就是不透明。`.formats([ColorFormat::Rgb])` 只有一种时不显示下拉框，`.format_signal(信号)` 记住用户的选择。

**换写法**：日期、时间选择都有 `.format(..)` 和 `.parse(..)`，一起换。界面文字默认中文，`.texts(CalendarTexts::english())` 换成英文，也可以只改其中几项（`CalendarTexts { today: "回到今天".into(), ..CalendarTexts::chinese() }`；时间是 `TimeTexts`，颜色是 `ColorTexts`，文件是 `FileTexts`）。

日历和颜色面板也能直接放进界面：


换一套样子只用样式对象，默认的样子就是先用上的样式对象。深色、圆形的日子、标记有事的日子都是这样写的：

```rust
/// 日历和颜色面板换一套样子：只用样式对象
pub fn restyled_pickers() -> Element {
    const MINT: Color = Color::hex(0x34d399);
    let (day, color) = (signal(today()), signal(Color::hex(0x2563eb)));
    let panel = Style::new().background(Color::hex(0x1b2129)).border(1, Color::hex(0x2f3844)).radius(18).padding(14).color(Color::hex(0xe7eaf0));
    let round_day = Style::new()
        .size(36, 36)
        .radius(18)
        // 要写：默认的样子里选中时有自己的文字颜色，平时就不从面板继承了
        .color(Color::hex(0xe7eaf0))
        .hovered(|s| s.background(Color::hex(0x2a323d)))
        .selected(|s| s.background(MINT).border_color(MINT).color(Color::hex(0x10141a)).hovered(|s| s.background(MINT)))
        .disabled(|s| s.color(Color::hex(0x4a5462)).background(Color::TRANSPARENT));
    row()
        .gap(16)
        .align(Align::Start)
        .child(
            Calendar::new(day)
                .style(&panel)
                .day_style(&round_day)
                // 一天里面放什么也可以自己决定：翻页时格子不重建，在绑定里读这一格现在是哪天
                .day_content(|date: Memo<Date>| {
                    column()
                        .align(Align::Center)
                        .child(text(move || date.get().day().to_string()).font_size(13))
                        .child(rect().size(4, 4).radius(2).background(MINT).opacity(move || if date.get().day() % 10 == 8 { 1.0 } else { 0.0 }))
                }),
        )
        .child(
            ColorPanel::new(color)
                .tile_radius(11.0)
                .swatches([Color::hex(0xf87171), Color::hex(0x34d399), Color::hex(0x38bdf8)])
                .style(&panel.clone().width(300))
                .area_style(&Style::new().height(120).radius(12))
                .hue_style(&Style::new().height(14))
                .slider_track_style(&Style::new().radius(7))
                .swatch_style(&Style::new().size(30, 30).radius(15).selected(|s| s.border_color(MINT))),
        )
}
```

### 完全重做界面

**规则：有值的控件，都有状态类型和 `.view(..)`。**按钮、标签、进度条没有用户能改的值，不需要。

改样子有两条路，按要改的是什么选：

| 要改的 | 用什么 |
|---|---|
| 颜色、大小、圆角、间距 | 样式对象（`.style(..)`、`.day_style(..)`……） |
| 结构、排布 | `.view(\|state\| ..)` 完全重做 |

`.view` 不用默认的样子，界面全是自己写的，**逻辑和事件都留着**：绑定的信号、`on_change`、`on_commit`、范围、禁用照常工作，方向键那套规则也是现成的（`state.handle_key(..)`）。默认的界面也只用这些方法搭，所以它做到的你都能做到。

```rust
/// 完全重做日历的界面：只留日历的逻辑和事件，样子全是自己的
pub fn custom_calendar() -> Element {
    let day = signal(today());
    Calendar::new(day)
        // 范围、禁用的日期、事件都写在这里，和用默认的界面时一样
        .range(today(), today().add_months(3))
        .on_commit(|d: Date| println!("选了 {d}"))
        .view(|state: CalendarState| {
            // 一页 CalendarState::CELLS 格，第 i 格是哪天问 state.day(i)
            let cells = (0..CalendarState::CELLS).map(move |i| {
                let date = move || state.day(i);
                let usable = move || state.in_month(date()) && state.is_allowed(date());
                text(move || date().day().to_string())
                    .size(40, 40)
                    .text_align(TextAlign::Center)
                    .opacity(move || if usable() { 1.0 } else { 0.3 })
                    .color(move || if state.selected() == Some(date()) { ACCENT } else { Color::hex(0x1f2328) })
                    // state.pick 会检查能不能选，写回信号，调用 on_change、on_commit
                    .on_click(move |e: &ClickEvent| state.pick(date(), e.source.into()))
            });
            column()
                .gap(8)
                .focusable(true)
                // 方向键、翻页键的那套规则也是现成的：跳过不能选的，走到别的月时翻页
                .on_key_down(move |e: &KeyEvent| {
                    if state.handle_key(e) {
                        e.stop_propagation();
                    }
                })
                .child(
                    row()
                        .gap(8)
                        .align(Align::Center)
                        .child(button("上个月").disabled(move || !state.can_shift_months(-1)).on_click(move || {
                            state.shift_months(-1);
                        }))
                        .child(text(move || state.title()))
                        .child(button("下个月").disabled(move || !state.can_shift_months(1)).on_click(move || {
                            state.shift_months(1);
                        })),
                )
                .child(grid().columns(Tracks::repeat(7, px(40))).children(cells))
        })
        .build()
}
```

| 控件 | 状态类型 | 读 | 改 |
|---|---|---|---|
| 复选框 | `CheckboxState` | `checked()`、`indeterminate()`、`label()` | `toggle(..)`、`set(..)` |
| 开关 | `SwitchState` | `is_on()`、`label()` | `toggle(..)`、`set(..)` |
| 单选组 | `RadioState<V>` | `count()`、`label(i)`、`value()`、`selected_index()`、`is_selected(i)` | `choose(i, ..)`、`move_by(..)`、`handle_key(..)` |
| 下拉选择 | `SelectState<V>` | `count()`、`label(i)`、`value()`、`selected_index()`、`shown_text()`、`is_open()` | `choose(i, ..)`、`open()`、`close(..)`、`toggle_open()`、`type_ahead(..)` |
| 滑块 | `SliderState` | `value()`、`ratio()`、`min()`、`max()`、`step()`、`unit()` | `set_value(..)`、`set_ratio(..)`、`step_to(..)`、`nudge(..)`、`commit(..)`、`handle_key(..)` |
| 数字输入 | `NumberState` | `value()`、`draft_signal()`、`can_increase()`、`can_decrease()` | `set_value(..)`、`step_by(..)`、`commit_text(..)`、`handle_key(..)` |
| 日历、日期选择 | `CalendarState` | `month()`、`day(i)`、`cursor()`、`selected()`、`in_month(..)`、`is_allowed(..)`、`title()`、`weekdays()` | `pick(..)`、`clear(..)`、`move_cursor(..)`、`shift_months(..)`、`handle_key(..)` |
| 时间选择 | `TimeState` | `value()`、`current()`、`is_allowed(..)` | `pick(..)`、`pick_now(..)`、`clear(..)`、`done()`、`cancel()` |
| 颜色面板、颜色选择 | `ColorState` | `color()`、`hue()`、`saturation()`、`brightness()`、`alpha()`、`text()` | `set_hue(..)`、`set_saturation_brightness(..)`、`set_alpha(..)`、`set_color(..)`、`set_text(..)`、`commit(..)` |
| 文件选择 | `FileState<V>` | `paths()`、`label()`、`is_waiting()`、`is_hovering()`、`accepts(..)` | `choose(..)`、`set_paths(..)`、`clear(..)`、`handle_drop(..)` |

每种都有 `is_disabled()`（选择类弹出的除外）和焦点句柄 `focus_handle()`：用了 `.focus_handle(..)`、标签的话，把句柄放到自己的元素上。

- **弹出的控件换的是弹出的内容**：`DatePicker`、`TimePicker`、`ColorPicker` 的 `.view(..)` 换弹出层里面，外框的输入框、弹出、关上、Esc 恢复还是它们的。其余控件换的是整个控件。
- **用了 `.view` 就只看自己的代码**：样式对象的那些方法（`.day_style(..)` 等）这时不起作用。
- **留下的是逻辑和事件，不是无障碍**：角色、名字、焦点、键盘的绑定在界面这一侧，要自己写（`.accessibility_role(..)`、`.focusable(true)`、`.on_key_down(..)` 里调用 `state.handle_key(..)`），否则辅助技术念不出来，键盘也用不了。

少见的需求：选一段日期用两个日期选择（或者 `.view(..)` 里自己算范围）；取色器接在 `ColorPanel` 旁边，改同一个信号就行。

**测试**：测试工具里不弹系统的对话框：`h.file_dialogs()` 看请求，`h.respond_file_dialog(路径)` 给结果。今天固定是 2026-01-15，用 `h.set_local_time(..)` 换。

## 表格

`table(数据, 每行的 key)` 加几列。数据可以是信号、派生值，或者返回 `Vec` 的闭包；十万行也只挂载看得见的部分：

```rust
#[derive(Clone, PartialEq)]
struct Person {
    id: u32,
    name: String,
    city: &'static str,
    age: u32,
}

/// 十万行也只挂载看得见的部分。数据由应用自己排，表格只告诉你按哪一列、什么方向
pub fn people_table() -> Element {
    let cities = ["北京", "上海", "杭州", "深圳"];
    let people = signal((0..100_000u32).map(|id| Person { id, name: format!("用户 {id}"), city: cities[id as usize % 4], age: 18 + id % 50 }).collect::<Vec<_>>());
    let picked = signal(Vec::<u32>::new()); // `Option<u32>` 就只能选一行
    let sort = signal(None::<TableSort>);
    let shown = memo(move || {
        let mut rows = people.get();
        if let Some(s) = sort.get() {
            match s.key {
                "age" => rows.sort_by_key(|p| p.age),
                _ => rows.sort_by_key(|p| p.id),
            }
            if s.order == SortOrder::Descending {
                rows.reverse();
            }
        }
        rows
    });
    table(shown, |p: &Person| p.id)
        .column(TableColumn::new("编号", |p: &Person| p.id.to_string()).width(90.0).align(TextAlign::End).sort_key("id"))
        .column(TableColumn::new("姓名", |p: &Person| p.name.clone())) // 没给宽度的平分剩下的
        .column(TableColumn::new("城市", |p: &Person| p.city).width(100.0))
        .column(TableColumn::new("年龄", |p: &Person| p.age.to_string()).width(80.0).sort_key("age"))
        .column(TableColumn::view("操作", |p: Signal<Person>| button("查看").on_click(move || println!("查看 {}", p.with(|p| p.id)))).width(90.0).resizable(false))
        .selection(picked)
        .sort(sort)
        .on_row_activate(|p: &Person| println!("打开 {}", p.name)) // 双击、回车
        .height(360)
        .build()
}
```

- **列宽**：`.width(..)` 固定，`.grow(..)` 按比例分剩下的（默认平分），`.min_width(..)` 是下限（默认 48）。列加起来比表格宽时横着滚，表头跟着一起走。拖表头右边能调宽，`.resizable(false)` 关掉，`.on_column_resize(..)` 收新的宽度。
- **key 认出每一行**：选中放的是 key，排序、插入之后行还是那一行。数据里同一个 key 的内容变了，这一行原地更新，不重建。
- **单元格**：`TableColumn::new(标题, 取文字)` 放文字，放不下时末尾省略；`TableColumn::view(标题, 建内容)` 放自己搭的元素，建的时候拿到这一行的信号，数据变了要跟着变的地方读它。
- **选中**：`.selection(信号)`，`Signal<Option<K>>` 选一行，`Signal<Vec<K>>` 选多行；不调用时行不能选中。`.on_change(..)` 收用户的改动，参数总是 `Vec<K>`。
- **排序**：列上写 `.sort_key("名字")`，点表头在升序、降序、不排序之间轮流，新的状态写进 `.sort(信号)`，`.on_sort(..)` 也收得到。表格只画箭头，数据由应用自己排。
- **给行加东西**：`.row_element(|元素, 这一行| ..)`，比如右键菜单。部位的样式对象：`.style`、`.header_style`、`.header_cell_style`、`.row_style`、`.cell_style`、`.resizer_style`，行有悬停、按下、选中、焦点（键盘走到的那一行）四种状态。

## 改了、改完了

有值的控件都有 `.on_change(|值| ..)`（用户每改一次）和 `.on_commit(|值| ..)`（改完了）。**代码里改绑定的信号时都不调用**，只有用户（指针、键盘、标签、辅助技术）改的才算：

只收值的闭包一般不用写类型。要知道怎么改的，收整个事件对象 `ChangeEvent`（`value`、`source`，来源是 `aureole::ChangeSource`），这时要写出类型：

```rust
/// 要知道怎么改的：收整个事件对象，写出类型
pub fn change_source() -> Element {
    let (volume, last) = (signal(0.5f32), signal(String::new()));
    column()
        .gap(8)
        .child(Slider::new(volume).on_change(move |e: &ChangeEvent<f32>| {
            let how = match e.source {
                ChangeSource::Pointer => "指针",
                ChangeSource::Keyboard => "键盘",
                _ => "别的",
            };
            last.set(format!("{how}改成 {:.2}", e.value));
        }))
        .child(text(move || last.get()))
}
```

只收值的写法，`on_change` 和 `on_commit` 的区别：

```rust
/// on_change：用户每改一次；on_commit：改完了。代码里改信号时都不调用
pub fn volume_setting() -> Element {
    let volume = signal(0.5f32);
    let saved = signal(0.5f32);
    column()
        .gap(8)
        .child(
            Slider::new(volume)
                .on_change(|v| println!("拖动中 {v:.2}")) // 拖动时每次移动
                .on_commit(move |v| saved.set(v)), // 松手时、按键的每一步
        )
        .child(text(move || format!("已保存 {:.0}%", saved.get() * 100.0)))
        .child(button("恢复默认").on_click(move || volume.set(0.5))) // 代码里改：两个都不调用
}
```

| 控件 | `on_change` | `on_commit` |
|---|---|---|
| 输入框 | 每次编辑（打字、删除、粘贴、撤销、输入法提交） | 回车，或者失去焦点，而且内容和获得焦点时不一样 |
| 滑块 | 拖动中每次移动、点轨道、按键 | 松开指针（值变了才调用）、按键的每一步之后 |
| 数字输入 | 回车、失去焦点、点按钮、按 ↑ ↓ 之后值变了 | 同时，参数是夹进范围之后的值 |
| 复选框、开关、单选组、下拉选择 | 每次改 | 每次改都是改完了，和 `on_change` 同时 |

要"不管谁改都做点什么"，用副作用读信号（第 [3](03-状态.md) 章）。

## 表单：一处收到所有控件的改动

`on_change` 只发给控件自己。一个表单要知道"里面有东西被用户改了"（显示未保存、启用保存按钮、自动保存），在外面的容器上用 `.on_field_change(..)`：里面任何控件被用户改了值，都从控件往外冒泡一次 `FieldChangeEvent`。

```rust
/// 表单：容器上的 on_field_change 收到里面任何控件被用户改了值（代码里改信号时不算）
pub fn profile_form() -> Element {
    let (nickname, weekly, plan) = (signal(String::new()), signal(false), signal("free"));
    let (dirty, last) = (signal(false), signal(String::new()));
    column()
        .gap(8)
        .on_field_change(move |e: &FieldChangeEvent| {
            dirty.set(true);
            last.set(format!("{} 改成了 {}", e.name.as_deref().unwrap_or("?"), e.value));
        })
        .child(text_field(nickname).name("昵称").placeholder("昵称"))
        .child(checkbox(weekly).label("订阅周报").name("订阅"))
        .child(select(plan, [("free", "免费版"), ("pro", "专业版")]).name("套餐"))
        .child(text(move || last.get()))
        .child(button("保存").disabled(move || !dirty.get()).on_click(move || dirty.set(false)))
}
```

- 事件里有哪个控件（`name` 是控件的 `.name(..)`，`focus_handle` 是交给控件、或者控件里面的输入框的焦点句柄）、新值的描述 `value`、怎么改的 `source`。`FieldValue` 有五种：`Bool`（复选框、开关）、`Number`（滑块、数字输入）、`Text`（输入框）、`Secret`（密码框，不带内容，要内容用它自己的 `on_change`）、`Choice { index, text }`（单选组、下拉选择）；`{}` 显示成值本身的文字。
- 输入框每次编辑报告一次；数字输入只报告夹进范围之后的数，中间输入框里打的字不报告；别的控件和 `on_change` 同时报告。
- 按冒泡走：控件自己先收到（目标阶段），再往外；中间的容器 `e.stop_propagation()` 外面就收不到。浮层里的控件报告到声明浮层的元素外面，模态浮层到此为止。
- 自己做的控件用 `FieldHandle` 加入：`let h = FieldHandle::new();`，元素上 `.field_handle(h)`，用户改了值时 `h.notify(FieldValue::Number(..), ChangeSource::Pointer)`。复合的控件可以在 `on_field_change_capture` 里把里面控件的改动截下来，只报告自己的值。
- 自己做的控件的行为写在 `.builtin_handlers(|el| el.on_click(..))` 里：同一个元素上排在使用的人挂的处理器之后，使用的人能先 `prevent_builtin(Builtin::ACTIVATE)` 取消，内置处理器查 `is_builtin_prevented`，处理完 `stop_propagation()`。基础控件都是这样写的。

## 标签

```rust
/// 标签放在哪都行：和控件用同一个焦点句柄
pub fn settings_form() -> Element {
    let (name, sync, city) = (signal(String::new()), signal(true), signal("hz"));
    let [name_focus, sync_focus, city_focus] = [FocusHandle::new(), FocusHandle::new(), FocusHandle::new()];
    grid()
        .columns([px(72), fr(1)])
        .gap(10)
        .align(Align::Center)
        .child(label("昵称").target(name_focus)) // 点它：输入框获得焦点
        .child(text_field(name).focus_handle(name_focus))
        .child(label("自动同步").target(sync_focus)) // 点它：开关切换
        .child(switch(sync).focus_handle(sync_focus))
        .child(label("城市").target(city_focus)) // 点它：下拉框打开
        .child(select(city, [("bj", "北京"), ("hz", "杭州")]).focus_handle(city_focus))
}
```

- 标签和控件用同一个焦点句柄连起来：控件 `.focus_handle(句柄)`，标签 `.target(句柄)`。标签放在哪里都行（表格的另一列、上面一行、离得很远），不用包着控件。
- 点标签时作用到控件上：输入框、滑块、数字输入获得焦点；复选框、开关切换；单选组获得焦点；下拉框打开；按钮被点了。控件禁用时什么都不做。
- 对辅助技术，控件"由这个标签命名"：控件自己没有名字时，标签的文字就是它的名字。
- 复选框、开关的 `.label(..)`、单选组每一项的文字是它们自己带的，点它也切换，不用另外加标签。
- 标签默认是正文颜色、14 号字，`.style(&s)` 改。它的构建器是 `Label`（`aureole::Label`、`aureole::controls::Label`）。

## 改样子

控件默认的样子是先用上的样式对象（按钮：高 30、左右 12、圆角 4，白底加 1 像素灰色描边，悬停、按下时底色变灰，禁用时变淡）。后面用的样式对象**按状态合进去**：写了平时的底色，悬停、按下时也是它（默认的悬停色是配着默认底色的，一起让掉），勾选、禁用时还是默认的样子；写了"勾选"，勾上以后悬停、按下也是它。链式方法在所有状态下都盖过它。

**强调色实底的按钮**：没有 primary、danger 这些变体，要强调就写一个样式对象，到处用：

```rust
/// 强调色实底：悬停、按下深一点
pub fn primary() -> Style {
    Style::new()
        .background(ACCENT)
        .border_color(ACCENT)

}

pub fn buttons() -> Element {

        .child(button("删除").style(&danger))
```

**胶囊开关，圆钮滑过去**：轨道和圆钮各一个样式对象；打开时圆钮的位置是"勾选"状态下的 `translation_x`，在上面声明平移的过渡就滑过去了：

```rust
/// 大一号的胶囊开关，打开时绿色，圆钮滑过去
pub fn pill_switch() -> Element {
    let on = signal(false);
    let track = Style::new()
        .size(44, 24)
        .radius(12)
        .transition(Property::Background, Tween::new(ms(150)).ease_out())

            s.background(SUCCESS)
                .hovered(|s| s.background(Color::hex(0x1a8a5f))) // 悬停、按下时深一点。不写的话一直是这个绿：
                .pressed(|s| s.background(Color::hex(0x167a54))) // 默认的"打开并且悬停"已经让给了上面的"打开"

        .radius(10)

    switch(on).label("自动保存").track_style(&track).thumb_style(&thumb).build()

```

**下拉选择**：按钮、弹出的列表、选项各改一点：

**复选框**：圆形的框、绿色，勾弹出来：

```rust
/// 圆形的框，勾上时绿色；勾从小弹到原来的大小
pub fn round_checkbox() -> Element {
    let done = signal(true);
    let green = Color::hex(0x1f9a6b);
    let indicator = Style::new().radius(8).checked(|s| {
        s.background(green)
            .border_color(green)
            .hovered(|s| s.background(Color::hex(0x1a8a5f)).border_color(Color::hex(0x1a8a5f)))
            .pressed(|s| s.background(Color::hex(0x167a54)).border_color(Color::hex(0x167a54)))
```

**不确定的进度条动起来**：默认是轨道中间静止的一段（30% 到 70%），框架不自己动它。要动就在填充的样式对象里放平移和循环的过渡，挂载后改一下信号让它开始：

```rust
/// 不确定的进度：填充来回扫
pub fn busy_bar() -> Element {
    let moving = signal(false);
    let sweep = Style::new()
        .translation_x(move || if moving.get() { 70.0 } else { -70.0 })
        .transition(Property::TranslationX, Tween::new(ms(900)).ease_in_out().alternate(true).forever());
    ProgressBar::indeterminate().fill_style(&sweep).on_mount(move || moving.set(true)).build()
}
```

确定的进度改变时填充的长度也是立即变；要平滑地长，在填充上声明宽度的过渡：`progress_bar(done).fill_style(&Style::new().transition(Property::Width, Spring::smooth()))`。

## 坑

- 表格默认高 320，用 `.height(..)` 或 `.grow(1)` 改；行高是固定的（`.row_height(..)`，默认 32）。行离开视口就卸载，单元格里要保留的状态放进数据里。
- **只改平时的颜色时，悬停、按下也没有变化了**：默认的悬停色、按下色是配着默认底色的，跟着一起让给你写的底色（勾选、禁用时的样子不受影响）。要悬停时有变化，在样式对象里把悬停、按下也写上（上面强调色按钮的例子）。
- **构建器和元素的 `.label(..)` 不一样**：`checkbox(s).label("文字")` 是显示出来的文字；`checkbox(s).accessibility_name("文字")` 是 `Element::accessibility_name`，只给辅助技术一个名字（第 [19](19-无障碍.md) 章），界面上看不到，用来给只有方框的复选框起名字。`Switch` 同理。
- 开关打开时圆钮的位置是"勾选"状态下的 `translation_x(..)`：改了轨道、圆钮的大小，平移也要跟着改。滑块的圆钮、已填部分的位置由滑块按值算出来，样式对象里的平移不用在它们上面。
- 下拉选择改选项样子的方法叫 `.option_style(..)`（`.option(..)` 是加一个选项）。
- `on_change`、`on_commit` 只管用户改的；同一个信号绑在两个控件上时，在一个控件里改了，另一个控件的处理器不调用。
- 深色只是中性色换一套；要别的配色给部位写样式对象。样式对象里写死的颜色不会跟着深浅变，要跟着变就写成读 `aureole::defaults::palette()` 的闭包：`Style::new().background(|| palette().fill)`。
- 进度条没有状态，不确定的进度条默认不动。
- **换深色时，日历的一天要自己写文字颜色**：默认的样子在选中时有自己的文字颜色，平时就用默认的深色，不从面板继承（[样式对象的规则](13-样式对象.md)）。只给面板写 `.color(..)` 时数字看不见。
- 日历翻页不重建格子，格子的名字是 `day-0` 到 `day-41`（第几格，不是几号）：测试里按日期找格子要自己算。
- 时间面板只有打开时才建，分钟一档时打字仍然能打别的分钟（`.minute_step(5)` 时打 `14:32` 是 14:32）。
- 文件选择拖进来的文件也按 `.file_filter(..)` 过滤，名字没有扩展名的不收。
