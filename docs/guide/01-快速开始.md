# 1. 快速开始

## 新建项目

需要 Rust 1.90 以上。现在是测试版，依赖要写全版本号。

```bash
cargo new hello
```

`hello/Cargo.toml`：

```toml
[package]
name = "hello"
version = "0.1.0"
edition = "2024"

[dependencies]
aureole = "0.0.1-beta.3"

# 渲染用的 wgpu 不优化时非常慢：开发时也把依赖编成优化版，自己的代码照常增量编译
[profile.dev.package."*"]
opt-level = 3

# 发布构建：一个代码生成单元加 thin LTO（框架工作区的配置不会被应用继承，要自己写）
[profile.release]
codegen-units = 1
lto = "thin"
```

## 第一个窗口

`hello/src/main.rs`：

```rust
use aureole::prelude::*;

pub fn main() {
    App::new(app).title("你好").size(480, 320).run();
}

pub fn app() -> impl View {
    let count = signal(0);
    column()
        .padding(32)
        .gap(16)
        .align(Align::Start)
        .child(text("第一个窗口").font_size(24).font_weight(700))
        .child(text(move || format!("点了 {} 次", count.get())).color(Color::hex(0x5c6570)))
        .child(button("点我").on_click(move || count.update(|n| *n += 1)))
}
```

```bash
cargo run
```

几件事一次看清：

- `App::new(app)` 描述主窗口，`app` 在主窗口创建后调用一次，返回根视图。`.run()` 进入事件循环，直到应用退出，必须在主线程调用。
- 界面是链式调用搭出来的：`column()` 是竖排的容器，`.child(..)` 加子元素，`.padding(32)`、`.gap(16)` 是属性。根元素默认占满窗口。
- `signal(0)` 是一个可读写的状态。`text(move || format!(.., count.get()))` 把文字**绑定**到信号上：信号变了，只更新这一段文字，别的绑定都不重新执行。
- `button(..)` 是基础控件之一（按钮、输入框、复选框、下拉选择……，第 [14](14-基础控件.md) 章）：点击、键盘、焦点、无障碍都做好了，样子朴素，改样子用链式方法和样式对象（第 [13](13-样式对象.md) 章）。
- `use aureole::prelude::*` 导入了常用的一切。不在里面的（`aureole::Menu`、`aureole::FileDialog`、`aureole::Scope`……）用到时单独导入。

## 注意

- **默认的样子跟着系统的深浅色**：浅色时窗口底色是浅灰（`#f6f7f9`），没指定颜色的文字是深灰（`#1f2328`），控件是白底细线框；深色时换成深灰的底、浅灰的字、深色的表面；强调色都是同一个偏蓝的。`App::appearance_mode(AppearanceMode::Light)`（或 `Dark`）固定成一种（第 [17](17-系统集成.md) 章）。要别的样子就自己设：`App::background(颜色)` 改窗口底色，文字颜色设在根元素上会继承，控件用样式对象改。
- 框架的控件没有内置动画：悬停、按下、勾选时立即换样子。要动画自己声明（第 [8](08-动画.md)、[13](13-样式对象.md) 章）。
- 调试构建可以直接用来开发（依赖已经优化）。看性能、录屏时用 `cargo run --release`。
- 苹果电脑开着**低电量模式**时，系统会把窗口限制在 60 帧，显示器仍然报告 120Hz；框架这时也只按每秒 60 帧出，省电。框架启动时会记一条警告，看到帧率只有 60 先检查这个（系统设置 → 电池）。
- 框架运行中发现的问题和提示（快捷键写错了、滚动视口的高度是 0、GPU 出错、低电量模式……）都通过 `tracing` 记录。调试构建里应用没装订阅者时，框架自己的警告和错误直接打在终端（标准错误）；发布构建什么都不打。要看更多（提示、调试级别）、要发布构建也打、要换格式，就自己装一个：加上 `tracing-subscriber` 依赖，在 `main` 开头（`App::run` 之前）调用 `tracing_subscriber::fmt::init()`，装了以后框架不再自己打。
