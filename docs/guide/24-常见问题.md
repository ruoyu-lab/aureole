# 24. 常见问题

## 写代码时

**编译器报 `type annotations needed`，指着处理器的参数。**
收事件对象的闭包要写出参数的类型：`.on_click(|e: &ClickEvent| ..)`。同一个方法接受不带参数和带事件对象两种闭包，编译器推断不出来。用不到事件对象时写 `|| ..`（第 [11](11-交互.md) 章）。

**按键处理器返回 `true` 编译不过。**
处理了一个键不是靠返回值，是调用 `e.stop_propagation()`。不让关窗口同理：`e.prevent_builtin(Builtin::CLOSE)`（第 [11](11-交互.md)、[18](18-多窗口菜单栏托盘.md) 章）。

**`.rotation(45)`、`Tween::new(300)` 编译不过。**
角度和时长都要写单位：`deg(45)`、`rad(1.0)`、`turns(0.25)`，`ms(300)`、`secs(0.5)`。裸的数字不会被当成哪一种（第 [5](05-样式与视觉.md) 章）。

**`text(name.get())` 的文字不跟着变。**
传进去的是那一刻的值。要绑定，写 `text(move || name.get())` 或者直接 `text(name)`（第 [2](02-元素和链式写法.md) 章）。

**程序 panic：读了已释放的信号。**
信号所在的作用域释放了：常见于在浮层、对话框、列表项、`child_when` 的内容里创建、却在外面用的信号。要活得久的状态在外面创建（第 [3](03-状态.md) 章）。

**在后台线程里怎么更新界面？**
不能直接改：信号不是 `Send`。用 `aureole::spawn(..).then(|结果| ..)`，或者在 `aureole::spawn_local` 里 `.await` 后台任务，回到主线程再写信号（第 [16](16-异步任务与数据资源.md) 章）。第三方库的回调线程上用 `MainThreadSender`（第 [26](26-插件和扩展点.md) 章）。

**用 reqwest、sqlx 时报"there is no reactor running"。**
这些库要 tokio 的运行时。打开 `aureole` 的 `tokio` 特性，用 `aureole::spawn_tokio(..)` / `aureole::resource_tokio(..)` 代替 `spawn` / `resource`，或者整个应用换成 `TokioPlugin`（第 [16](16-异步任务与数据资源.md) 章）。

**定时器不触发了 / 定时器一直跑。**
定时器归创建时的作用域：元素卸载、窗口关闭时取消，丢掉句柄不影响它。在 `main`、插件、库的结构体里创建的没有作用域，要让它跟着一个值走用 `.guard()`（第 [26](26-插件和扩展点.md) 章）。

## 界面的样子

**系统切到深色了，窗口还是浅色的。**
框架默认的样子只有一套固定的浅色，也不跟着系统变。要深色就自己定颜色：`App::background(颜色)` 改窗口底色，文字颜色设在根元素上会继承，控件的每个部位写样式对象（第 [13](13-样式对象.md)、[14](14-基础控件.md) 章）；要跟着系统切换，就在绑定里读 `system_appearance()`（第 [17](17-系统集成.md) 章），样式对象里的值也能绑定。

**控件悬停、勾选的时候没有动画。**
基础控件没有内置动画，状态一变立即换。要过渡就在样式对象里声明 `.transition(..)`（第 [13](13-样式对象.md) 章），控件的部位也一样（第 [14](14-基础控件.md) 章的胶囊开关）。

**改了控件的颜色，悬停、按下时又变回原来的。**
样式对象按状态合进默认的样子：只写了平时的值，悬停、按下还是默认的；默认的样子里还有嵌套的"勾选并且悬停"，它优先于只写了"勾选"的。把这些状态一起写上（第 [14](14-基础控件.md) 章的坑）。反过来，链式方法（`.background(..)`）在所有状态下都是它，悬停也不变了（第 [13](13-样式对象.md) 章）。

**滚动列表是空的。**
`scroll_y` 在滚动方向上不会被内容撑大，给它 `.height(..)` 或 `.grow(1)`（第 [10](10-滚动.md) 章），调试构建里会记一条警告。虚拟列表也一样。要跟着内容长高（下拉、建议列表）用 `scroll_y_fit(..).max_height(..)`。

**自己拼的按钮被拉满了整行。**
竖排的交叉轴默认拉伸。给容器 `.align(Align::Start)`，或者给按钮 `.align_self(Align::Start)`（第 [4](04-布局.md) 章）。基础控件按内容的宽度，不会这样。

**固定了宽度，元素还是被压窄了。**
放不下时默认可以收缩，加 `.shrink(0)`。

**属性设了 `.transition(..)` 却没有动画。**
动画只在绑定的值变化时发生：属性要绑定信号（闭包），而且挂载时的初始值不做动画，入场动画要在 `on_mount` 里改目标（第 [8](08-动画.md) 章）。宽高切到百分比、`auto` 时也会直接跳过去。

**设了属性却什么都没变。**
有些属性只对某几种元素有用（`max_lines` 对文字，`placeholder` 对输入框，`scrollbar_color` 对滚动视口）。调试构建里每个属性用 `tracing` 提示一次，装上订阅者才看得到（第 [1](01-快速开始.md) 章）。

## 交互

**子元素和父元素都有 `on_click`，点子元素时父元素的会触发吗？**
会，点击默认往外冒泡。不想让外面收到，在里面的处理器里调用 `e.stop_propagation()`（第 [11](11-交互.md) 章）。基础控件替你停了，所以点卡片里的按钮不会触发卡片。

**点工具栏的按钮时输入框丢了焦点。**
按下时拿焦点是内置行为，在按钮的 `on_pointer_down` 里 `e.prevent_builtin(Builtin::FOCUS)`（第 [11](11-交互.md) 章）。

**列表里能拖的卡片挡住了列表的滚动。**
拖动开始时决定谁拿到：卡片在 `Start` 里 `e.decline_gesture()` 让给外面，或者外面的元素用 `on_drag_capture` 在捕获阶段 `e.claim_gesture()` 抢走（第 [11](11-交互.md) 章的"手势的仲裁"）。

**快捷键不触发 / 快捷键抢不过输入框。**
快捷键排在元素之后，焦点上的元素处理了这个键就收不到。要抢在所有元素之前写 `.preemptive(true)`（第 [11](11-交互.md) 章）。

**快捷键 ⌘C 不起作用了 / 输入框不能复制了。**
别用 `CmdOrCtrl+C/V/X/A/Z` 注册菜单快捷键，菜单先于窗口收到按键，会抢走输入框的复制、粘贴、全选、撤销。

**点菜单项时，打开菜单的按钮又把菜单打开了。**
不会：浮层里的点击只在浮层里传播，不传回打开它的按钮，菜单项点完不用停止传播（第 [12](12-浮层.md) 章）。按键、滚轮、指针按下照常沿声明浮层的元素往外走。

**双击中文时只选中一个字。**
默认按词典分词：双击"我们今天去公园"里的"今"选中"今天"，Option+方向键、Option+退格也按词走（第 [6](06-文字与字体.md)、[7](07-输入框和多行编辑.md) 章）。只选中一个字，多半是依赖里写了 `default-features = false`，把带词典的 `cjk-words` 特性一起关掉了，在 `features` 里加回 `"cjk-words"` 就好。词典里没有的词（人名、新造的词）会被分成更短的词或单字。

## 运行和发布

**启动时提示"没有可用的 GPU"。**
显卡驱动没装好，或者在没有 GPU 的远程桌面、虚拟机里，而且没有软件渲染可用。错误日志里列出了试过的 GPU 和原因（要装 `tracing` 的订阅者才看得到，第 [1](01-快速开始.md) 章）；Windows、Linux 上可以 `AUREOLE_GPU=software` 试试软件渲染（第 [23](23-打包与发布.md) 章）。

**帧率只有 60。**
先检查低电量模式（系统设置 → 电池 → 能耗模式）；窗口被别的窗口完全挡住时系统也会降低刷新。

**系统通知没有弹出来。**
macOS 上要打包成 .app（`cargo bundle`）才能发通知，第一次发时要在系统的权限请求里点"允许"；没打包时通知的内容记在日志里（`tracing` 的 info）。

**能在 Windows、Linux 上用吗？**
能编译，系统集成（文件对话框、通知、外观、托盘、打开网址和文件、单实例）也写好了，但还没在真机上运行过；Linux 上不显示菜单栏，菜单项的快捷键照样起作用。各项的状态见 [README 的平台表](../../README.md#平台支持)，应用要准备的东西见第 [23](23-打包与发布.md) 章。

**怎么调界面更快？**
颜色、间距、文案放进文件用 `aureole::watch_file` 热加载；`App::restarts_on_rebuild(true)` 让 `cargo build` 后原地重启、保留状态（第 [21](21-开发工具.md) 章）。
