# 20. 测试

测试工具在 `testing` 特性后面，只在开发依赖里打开，应用本身不带：

```toml
[dependencies]
aureole = "0.0.1-beta.1"

[dev-dependencies]
aureole = { version = "0.0.1-beta.1", features = ["testing"] }
```

## 测试工具 `Harness`

`aureole::testing::Harness` 不开窗口、不用 GPU 地挂载视图：手动推进帧（虚拟时间）、模拟指针和键盘、按名字找元素。写在普通的 `#[test]` 里，`cargo test` 就能跑。本章的导入：

```rust
use aureole::prelude::*;
use aureole::testing::Harness;
```

```rust
fn counter(count: Signal<i32>) -> Element {
    column()
        .gap(8)
        .align(Align::Start)
        .child(text(move || format!("点了 {} 次", count.get())).name("label"))
        .child(button("+1").name("plus").on_click(move || count.update(|n| *n += 1)))
}

pub fn click_test() {
    let count = signal(0);
    let h = Harness::new(400.0, 300.0, counter(count)); // 虚拟窗口，没有 GPU
    h.frame(); // 第一帧：布局
    h.click_named("plus"); // 点名字是 plus 的元素的中心
    h.click_named("plus");
    assert_eq!(count.get(), 2);
    let label = h.bounds("label").expect("有这个元素"); // 布局位置
    assert_eq!((label.x, label.y), (0.0, 0.0));
}

pub fn keyboard_test() {
    let name = signal(String::new());
    let submitted = signal(String::new());
    let field = text_field(name).name("name").on_submit(move |t| submitted.set(t));
    let h = Harness::new(400.0, 200.0, column().child(field).child(button("确定").name("ok")));
    h.frame();
    h.click_named("name");
    h.type_text("小梨");
    h.key_down(NamedKey::Enter);
    assert_eq!(name.get(), "小梨");
    assert_eq!(submitted.get(), "小梨");
    h.tab(); // Tab 移到下一个能获得焦点的元素
    assert_eq!(h.focused_name().as_deref(), Some("ok"));
    assert!(h.is_focus_ring_visible()); // 键盘带来的焦点画焦点环
}
```

常用方法：

| 方法 | |
|---|---|
| `frame()` / `advance(时长)` | 推进一帧 / 连续推进（每帧 1/120 秒的虚拟时间，`testing::FRAME`），返回 `FrameStats` |
| `bounds(名字)` / `window_bounds(名字)` | 布局位置 / 算上变换、滚动、浮层位置后在窗口里的外接矩形 |
| `text(名字)` | 元素现在显示的文字（输入框是它的内容） |
| `screenshot()` / `screenshot_with(底色)` | 离屏截图（要 GPU），`save_png(路径)` 存成图片 |
| `click_named(名字)`、`click(x, y)`、`double_click`、`right_click`、`mouse_move`、`drag(from, to)`、`wheel`、`swipe`、`pinch`、`rotate` | 指针和触控板 |
| `touch_down(手指, x, y)`、`touch_move`、`touch_up`、`touch_cancel`，简写 `touch_tap(x, y)`、`touch_swipe(from, to, 帧数)` | 触摸屏的手指，第一个参数是手指的编号（见第 [11](11-交互.md#触摸屏) 章） |
| `type_text(..)`、`key_down(NamedKey::..)`、`chord("CmdOrCtrl+K")`、`tab()`、`ime_preedit` / `ime_commit` | 键盘和输入法 |
| `focused_name()`、`is_focus_ring_visible()`、`cursor()` | 焦点、焦点环、指针形状 |
| `set_conventions(Conventions::WINDOWS)` | 换成别的平台的惯例（测试工具里固定是 macOS 的：`CmdOrCtrl` 是 Command） |
| `record(..)`、`replay(..)` | 录下、回放输入，得到处理器、焦点、输入框内容的快照 |
| `settle()`、`wait_images()` | 等后台任务 / 图片解码做完 |
| `resize(w, h)`、`set_system_appearance(..)`、`set_motion_reduced(..)`、`set_scale_factor(..)` | 改窗口大小、模拟系统切换深浅色（`system_appearance()` 读到的）和"减少动态效果"、缩放 |
| `image_frame(名字)`、`set_occluded(..)` | 动图此刻显示第几帧、模拟窗口被挡住 |
| `stall(时长)`、`stall_without_resuming(时长)` + `resume()` | 模拟主线程卡住：只有渲染线程在推进合成层动画和滚动；`layers()`、`composited_quads()` 是屏幕上的样子。`stall` 结束时主线程恢复（收回渲染线程推进到的滚动状态） |
| `wants_frames()`、`next_frame()` | 界面还要每帧推进吗；为假时窗口暂停帧时钟（画面静止时进程不被唤醒）。`next_frame()` 还说出只要某个时刻的一帧（插入点下一次换亮灭），窗口睡到那一刻 |
| `accessibility()`、`accessibility_id(名字)`、`accessibility_action(..)` | 无障碍树和辅助技术的操作 |
| `element_tree()`、`element_info(名字)` | 元素树的快照（种类、名字、文字、布局位置，`to_string()` 一行一个元素）、元素此刻的详细信息（外边距、内边距、绘制属性、属性动画） |

动画、定时器、异步任务都能测，时间是虚拟的，不用真的等：

```rust
pub fn animation_test() {
    let open = signal(false);
    let panel = rect().name("panel").size(100, 100).opacity(move || if open.get() { 1.0 } else { 0.0 }).transition(Property::Opacity, Tween::new(ms(200)));
    let h = Harness::new(400.0, 300.0, panel);
    h.frame();
    open.set(true);
    assert!(h.frame().animations > 0); // 在动
    let stats = h.advance(ms(500)); // 虚拟时间：不用真的等半秒
    assert_eq!(stats.animations, 0); // 停稳了
    assert!(!stats.laid_out); // 透明度动画不触发布局
}

pub fn async_test() {
    let result = signal(0);
    let h = Harness::new(200.0, 100.0, text(move || result.get().to_string())); // 虚拟时钟从 0 开始
    aureole::spawn_blocking(|| 6 * 7).then(move |n| result.set(n));
    h.settle(); // 等后台任务做完、结果交回主线程
    assert_eq!(result.get(), 42);
    let fired = signal(false);
    aureole::after(secs(5), move || fired.set(true));
    h.advance(ms(5100)); // 定时器按虚拟时间走
    assert!(fired.get());
}
```

界面上显示的文字用 `h.text(名字)` 读（完整的内容；名字起在容器上时取里面的第一段文字）；无障碍树按辅助技术的方式检查：

```rust
/// 读界面上的文字：按名字取元素现在显示的文字
pub fn read_text() {
    let count = signal(3);
    let h = Harness::new(400.0, 300.0, counter(count));
    h.frame();
    assert_eq!(h.text("label").as_deref(), Some("点了 3 次"));
    h.click_named("plus"); // 绑定的文字跟着信号马上变
    assert_eq!(h.text("label").as_deref(), Some("点了 4 次"));
}

pub fn accessibility_test() {
    let h = Harness::new(400.0, 300.0, crate::accessibility::labels());
    h.frame();
    let tree = h.accessibility(); // 像辅助技术那样要一棵整树（AccessKit 的格式）
    let title = h.accessibility_id("title").expect("标题在树里");
    let (_, node) = tree.nodes.iter().find(|(id, _)| *id == title).expect("标题节点");
    assert_eq!(node.role(), Role::Heading);
}
```

按窗口大小切换的界面用 `h.resize(..)` 测；动图用 `encode_animation` 在代码里生成，`h.image_frame(名字)` 看播到第几帧：

```rust
/// 改虚拟窗口的大小看尺寸档；动图按虚拟时间换帧
pub fn adaptive_test() {
    let h = Harness::new(500.0, 300.0, column().child(text(move || format!("{:?}", window_size_class())).name("class")));
    h.frame();
    assert_eq!(h.text("class").as_deref(), Some("Compact"));
    h.resize(1100.0, 300.0); // 下一帧按新大小：读尺寸档的绑定先执行，再布局
    h.frame();
    assert_eq!(h.text("class").as_deref(), Some("Wide"));

    let frames = [[255, 0, 0, 255], [0, 0, 255, 255]].map(|c| c.repeat(16 * 16)); // 红、蓝两帧
    let gif = aureole::testing::encode_animation(aureole::testing::AnimationFormat::Gif, 16, 16, &frames, &[ms(100), ms(100)], 0);
    let h = Harness::new(100.0, 100.0, column().child(image(ImageSource::bytes(gif)).size(16, 16).name("gif")));
    h.frame();
    h.wait_images();
    assert_eq!(h.image_frame("gif"), Some(0));
    h.advance(ms(150)); // 第一帧显示 100 毫秒
    assert_eq!(h.image_frame("gif"), Some(1));
}
```

## 离屏截图和像素测试

测试工具推进好帧后，`h.screenshot()` 把显示列表画成像素（要 GPU，不用另外加依赖），`save_png(路径)` 存成图片：

```rust
/// 离屏截图：测试工具推进好帧，画成像素，存成 PNG
pub fn screenshot(view: Element, path: &str) {
    let h = Harness::new(480.0, 320.0, view);
    h.set_scale_factor(2.0); // 按 2 倍分辨率栅格化文字：截图是 960x640
    h.frame();
    h.wait_images(); // 等图片解码完
    h.screenshot().save_png(path).expect("写 PNG 失败"); // 底色和窗口一样是浅灰
}

pub fn pixel_test() {
    let red = Color::rgb(255, 0, 0);
    let h = Harness::new(100.0, 100.0, column().child(rect().size(50, 50).background(red)));
    h.frame();
    let shot = h.screenshot_with(Color::BLACK); // 指定底色
    assert_eq!((shot.width, shot.height), (100, 100));
    assert_eq!(shot.pixel(25, 25), red);
    assert_eq!(shot.pixel(75, 75), Color::BLACK);
    // 顺便检查教程里的效果在真的渲染器上能画（自定义着色器在这里编译）
    screenshot(crate::style::gallery(), &std::env::temp_dir().join("guide-style.png").to_string_lossy());
}
```

截图是 `Screenshot`：`width`、`height` 是物理像素（虚拟窗口乘上 `set_scale_factor` 的缩放），`pixels` 是 RGBA、sRGB 编码，`pixel(x, y)` 取一个点的颜色（物理像素坐标）。截图里的合成层按渲染线程此刻的状态（`h.layers()`）画，所以动画中途的样子也能截；连续截几帧拼起来就是动画的"胶片"。要自己控制渲染时，`h.display_list()`、`h.layers()`、`h.atlas()` 交给渲染器（`aureole-render`）的 `render_to_image`。

## 坑

- `Harness::new` 之后、第一次 `frame()` 之前元素还没有布局，`bounds` 是 `None`；**先 `frame()` 再操作**。每个 `Harness` 的虚拟时钟从 0 开始，同一个线程里先后建几个也互不影响。
- `click_named` 按布局位置点；浮层里的、被变换过的元素用 `window_bounds` 算位置再 `click(x, y)`。
- `settle()` 不推进虚拟时间：防抖、定时器、`aureole::sleep` 都跟着虚拟时间走，用 `advance(..)` 推进；后台任务在等 `sleep` 时只调 `settle()` 会等到超时。
- 测试工具里没有窗口，`current_window()` 是 `None`；文件对话框、系统通知的样子这些要在真实应用里试。
- 离屏截图要 GPU；没有 GPU 的机器（部分 CI）上只跑不截图的测试。
