# 12. 浮层：下拉、弹出、对话框、提示

浮层声明在元素上：`.overlay(条件, Overlay::new(内容))`，条件为真时打开、变假时关闭。浮层画在所有内容之上，不受祖先的裁剪和滚动视口限制；内容每次打开时构建，挂在自己的作用域里。菜单、对话框、弹出面板都是浮层加几个元素，框架不另外带这些东西；下拉选择的列表也是浮层（第 [14](14-基础控件.md) 章）。

## 浮层里的事件怎么走

浮层画在窗口最上面，事件却沿**逻辑上的父元素**走（第 [11](11-交互.md) 章讲了三段传播）：

| 事件 | 怎么走 |
|---|---|
| 按键、滚轮、指针按下 / 松开 / 移动、手势、改值汇总 | 从浮层里往外冒泡到**声明浮层的元素**，再接着往外：下拉列表里的按键能传回下拉框，浮层里的控件能报告给外面的表单 |
| 点击（左键、右键、中键、双击）和按压反馈 | **只在浮层里传播**，到浮层的根为止，不传回打开它的按钮和外面：菜单项点完不用停止传播，按钮也不会把刚关上的菜单又打开 |
| 模态浮层（`.modal(true)`）里的一切 | 到浮层的根为止，不出去 |
| Esc | 最上面能关的浮层在按键的捕获阶段处理（请求关闭），里面的输入框收不到 |

```rust
/// 浮层里的事件怎么走：按键回到声明它的元素，点击留在浮层里
pub fn overlay_events() -> Element {
    let (open, clicks, keys) = (signal(false), signal(0), signal(0));
    column()
        .gap(8)
        .on_click(move || clicks.update(|n| *n += 1)) // 浮层里点击，这里收不到
        .on_key_down(move |_| keys.update(|n| *n += 1)) // 浮层里按键，冒泡到这里
        .child(
            button("打开")
                .name("open")
                .on_click(move || open.set(true))
                .overlay(
                    open,
                    Overlay::new(move || {
                        column()
                            .padding(8)
                            .background(SURFACE)
                            .border(1, LINE)
                            .child(rect().name("item").size(120, 28).focusable(true).on_click(move || open.set(false)))
                    })
                    .auto_focus(true)
                    .on_dismiss(move |_| open.set(false)),
                ),
        )
        .child(text(move || format!("点击 {}，按键 {}", clicks.get(), keys.get())).name("counts"))
}
```

点外面请求关闭是内置行为，能取消：按在工具栏上不想关面板，在工具栏的 `on_pointer_down` 里取消 `Builtin::DISMISS`。Esc 不想关时最简单的办法是 `on_dismiss` 里按原因决定（`Dismiss::Escape`）；也能在捕获阶段取消 `DISMISS`：焦点在浮层里时在声明浮层的元素的 `on_key_down_capture` 里，焦点在浮层外面时在焦点和它的祖先的 `on_key_down_capture` 里。下面是第一种：

```rust
/// 查找面板：点工具栏不关它（取消"按在外面请求关闭"）；Esc、点别处照常关
pub fn keep_open() -> Element {
    let (open, bold) = (signal(false), signal(false));
    column()
        .gap(8)
        .child(
            text("粗体（点它面板不关）")
                .name("tool")
                .padding(6)
                .background(move || if bold.get() { ACCENT_SOFT } else { FILL })
                .on_pointer_down(|e: &PointerEvent| e.prevent_builtin(Builtin::DISMISS))
                .on_click(move || bold.update(|b| *b = !*b)),
        )
        .child(button("查找").name("find").on_click(move || open.set(true)).overlay(
            open,
            Overlay::new(|| column().padding(8).background(SURFACE).border(1, LINE).name("panel").child("查找面板")).on_dismiss(move |_| open.set(false)),
        ))
}
```

## 下拉菜单

```rust
/// 浮层内容的入场、退场：挂载后改目标，退场用 .exit
fn pop_in(content: Element) -> Element {
    let shown = signal(false);
    content
        .opacity(move || if shown.get() { 1.0 } else { 0.0 })
        .transition(Property::Opacity, Tween::new(ms(140)))
        .scale(move || if shown.get() { 1.0 } else { 0.96 })
        .transition(Property::Scale, Spring::snappy())
        .on_mount(move || shown.set(true))
        .exit(Property::Opacity, 0.0)
        .exit(Property::Scale, 0.96)
}

/// 菜单项：悬停、键盘焦点所在时浅灰底
fn menu_item() -> Style {
    Style::new().height(28).padding_x(10).radius(4).align(Align::Center).hovered(|s| s.background(FILL)).focused(|s| s.background(FILL))
}

fn menu(open: Signal<bool>) -> Element {
    let item = menu_item();
    let panel = column()
        .padding(4)
        .width(180)
        .radius(6)
        .background(SURFACE)
        .border(1, LINE)
        .shadow(Shadow::new(0.0, 4.0, 12.0, Color::rgba(16, 24, 32, 0.18)))
        .focus_arrows(Direction::Column) // ↑ ↓ 在菜单项之间移动
        .children(["新建", "打开…", "另存为…"].map(move |label| {
            row()
                .style(&item)
                .accessibility_role(Role::MenuItem)
                .focusable(true) // 能获得焦点：方向键、回车
                .focus_ring(FocusRing::NONE) // 焦点用底色表现
                .child(text(label))
                .on_click(move || {
                    println!("{label}");
                    open.set(false); // 浮层里的点击不传回打开菜单的按钮，不用停止传播
                })
        }));
    pop_in(panel)
}

pub fn dropdown() -> Element {
    let open = signal(false);
    button("文件")
        .on_click(move || open.update(|o| *o = !*o))
        .overlay(
            open,
            Overlay::new(move || menu(open))
                .placement(Placement::bottom().start()) // 按钮下方、左边对齐；放不下时翻到上方
                .offset(4)
                .auto_focus(true) // 打开时焦点移进来，关闭时还回去
                .on_dismiss(move |_| open.set(false)), // Esc、点外面时请求关闭
        )
}
```

- 菜单项是普通的横排加一个样式对象（第 [13](13-样式对象.md) 章）：`.focused(..)` 是键盘焦点，用 ↑ ↓ 走到时亮起来，指针点的不算。
- 只是在几个选项里选一个时，用基础控件的下拉选择 `select(..)`（第 [14](14-基础控件.md) 章），键盘、打字跳转、弹出的列表都做好了。

## 对话框

```rust
/// 对话框：放在窗口正中的模态浮层，带遮罩
pub fn modal() -> Element {
    let open = signal(false);
    button("删除项目…").on_click(move || open.set(true)).overlay(
        open,
        Overlay::new(move || {
            pop_in(
                column()
                    .width(360)
                    .padding(20)
                    .gap(12)
                    .radius(8)
                    .background(SURFACE)
                    .shadow(Shadow::new(0.0, 8.0, 24.0, Color::BLACK.with_alpha(0.2)))
                    .child(text("删除这个项目？").font_size(16).font_weight(600))
                    .child(text("删除后不能恢复。").color(MUTED))
                    .child(
                        row()
                            .gap(8)
                            .justify(Justify::End)
                            .child(button("取消").on_click(move || open.set(false))) // 打开时焦点在第一个按钮上
                            .child(button("删除").color(DANGER).on_click(move || {
                                println!("删了");
                                open.set(false);
                            })),
                    ),
            )
        })
        .centered(true)
        .modal(true) // 挡住下面、Tab 困在里面、打开时焦点移进来、关闭后还回去
        .backdrop(Color::BLACK.with_alpha(0.3))
        .backdrop_transition(Tween::new(ms(150)).ease_out()) // 遮罩淡入淡出；不写时立即出现、消失
        .on_dismiss(move |_| open.set(false)), // Esc、点遮罩
    )
}
```

- 遮罩（`.backdrop(颜色)`、`.backdrop_blur(σ)`）默认打开时立即出现、关闭时立即消失；`.backdrop_transition(曲线)` 让它按曲线淡入淡出，浮层等它淡完才卸载。
- 不想让点遮罩关掉（"一定要选一个"的确认）：在 `on_dismiss` 里只处理 `Dismiss::Escape`，或者什么都不做。按原因决定时用它最简单，`Builtin::DISMISS` 留给"这次按下不算"的情况。
- `button("删除").color(DANGER)`：链式方法盖过按钮默认的文字颜色，悬停、按下的底色照样是默认的（第 [13](13-样式对象.md) 章）。

## 提示

```rust
pub fn tooltip() -> Element {
    let copy = VectorPath::svg("M9 9 H19 V19 H9 Z M5 15 V5 H15").view_box(0.0, 0.0, 24.0, 24.0);
    button(path(copy).size(16, 16).stroke(Stroke::new(1.5).round()))
        .accessibility_name("复制链接") // 只有图标：给辅助技术起名字
        .tooltip("复制链接")
        .on_click(|| println!("复制"))
}
```

指针停 0.5 秒后在上方出现（深灰底、白字、12 号字），移开或按下时消失；出现、消失都是立即的，不挡指针。提示的文字也交给辅助技术当描述。

## `Overlay` 的选项

| 方法 | |
|---|---|
| `.placement(Placement::bottom().start())` | 放在锚点的哪一边（`top` / `bottom` / `left` / `right`）、怎么对齐（`start` / `center` / `end`）；那一边放不下时翻过去，最后挪进窗口 |
| `.offset(n)`、`.margin(n)` | 离锚点的距离；离窗口边缘至少多远（默认 8） |
| `.at(点)` | 锚定在窗口里的一点（右键菜单），可以绑定信号 |
| `.centered(true)` | 放在窗口正中（对话框） |
| `.modal(true)` | 模态：挡住下面的指针，Tab 只在里面转，打开时焦点移进来，关闭时还给打开前的元素 |
| `.backdrop(颜色)`、`.backdrop_blur(σ)` | 遮罩的颜色和背景模糊，默认立即出现、消失 |
| `.backdrop_transition(曲线)` | 遮罩按曲线淡入淡出 |
| `.auto_focus(true)` | 普通浮层（菜单）也在打开时把焦点移进来 |
| `.passthrough(true)` | 不接收指针（提示） |
| `.on_dismiss(\|原因\| ..)` | 按 Esc（`Dismiss::Escape`）、在浮层外面按下（`Dismiss::Outside`）时调用 |
| `.report_placement(信号)` | 实际放在哪一边写进信号，内容可以按它决定从哪边滑入、箭头朝哪 |

入场动画在内容的 `on_mount` 里触发，退场动画写在内容根元素的 `.exit(..)` 上：关闭后先播完退场动画再卸载，期间浮层不再响应指针。不写时浮层立即出现、消失。

## 比窗口还高的浮层

```rust
pub fn font_sizes() -> Element {
    let (open, size) = (signal(false), signal(14));
    let item = menu_item();
    button(text(move || format!("字号 {}", size.get()))) // 文字会变：放一个绑定的 text
        .on_click(move || open.update(|o| *o = !*o))
        .overlay(
            open,
            Overlay::new(move || {
                column()
                    .padding(4)
                    .width(160)
                    .radius(6)
                    .background(SURFACE)
                    .border(1, LINE)
                    .focus_arrows(Direction::Column)
                    .children((8..=72).map(|n| {
                        row().style(&item).accessibility_role(Role::MenuItem).focusable(true).focus_ring(FocusRing::NONE).child(format!("{n} 号")).on_click(move || {
                            size.set(n);
                            open.set(false);
                        })
                    })) // 65 项，比窗口还高：限制在放得下的高度里，在面板里滚动
            })
            .placement(Placement::bottom().start())
            .offset(4)
            .auto_focus(true)
            .on_dismiss(move |_| open.set(false)),
        )
}
```

- 浮层（菜单、下拉选择的列表、右键菜单、对话框和任何 `Overlay`）放不下时，高度限制在放的那一边能用的空间里（离窗口边缘留 `margin`），**在内容的根元素里滚动**：根元素的背景、圆角、描边、投影照常画在外面，子元素在里面滚。两边都放不下时放在宽敞的一边；窗口变大变小时跟着重新算。
- 用方向键移动焦点时，焦点所在的项立即滚进来；下拉选择打开时，选中的那一项已经在列表里。
- 放得下时和以前一样：不裁剪（伸出去的投影、角标照常画出来），滚轮不会把它拉出橡皮筋。

## 坑

- **关不关由你决定**：`on_dismiss` 只是"请求关闭"，要在处理器里把控制它的信号改成 `false`，否则 Esc、点外面都关不掉。
- **点击不出浮层，按键出得去**：浮层里按键时外面的 `on_key_down` 收到，处理了要 `e.stop_propagation()`；外面的 `on_click` 收不到浮层里的点击。
- 按在锚点元素自己上不算"外面"（锚点通常自己切换开关，否则会先关再开）。普通浮层外面的这次按下照常落到下面的元素上；模态浮层的遮罩会吃掉它。
- **浮层里创建的信号随浮层关闭释放**。对话框"创建"出来、要留下的数据（比如新建的一条记录里的信号）要在外面的作用域里创建。
- 浮层内容的根元素就是滚动的面板：它的内边距、间距、对齐挪到里面跟着滚的那一层，所以一直钉在面板顶上的标题这类要放在浮层外面，或者接受它跟着一起滚。不要在根元素里面再放一个 `scroll_y_fit` 来滚动（空间不够时会两层一起滚），让根元素自己滚。
- 菜单项要 `.focusable(true)` 才能被方向键走到、按回车触发；`on_click` 本身不让元素获得焦点。
- 提示（`.passthrough(true)`）不限制高度，也不滚动。
- 锚点滚出视口时浮层不会自动隐藏。
