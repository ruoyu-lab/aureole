# 4. 布局

布局是弹性布局和网格布局（用 taffy 实现）。根元素默认占满窗口。

## 横排、竖排、对齐

```rust
/// 侧栏固定宽度，主区吃掉剩下的宽度
pub fn page() -> Element {
    row()
        .child(column().width(220).padding(16).gap(8).background(SURFACE).child(text("侧栏")))
        .child(
            column()
                .grow(1)
                .padding(24)
                .gap(16)
                .child(
                    row()
                        .justify(Justify::SpaceBetween) // 主轴（横排时是水平方向）：两端对齐
                        .align(Align::Center) // 交叉轴（横排时是竖直方向）：居中
                        .child(text("标题").font_size(22).font_weight(700))
                        .child(button("新建")),
                )
                .child(text("正文……")),
        )
}
```

- `.gap(n)` 子元素之间的间距；`.padding(n)` 四边内边距，`.padding_x` / `.padding_y` 覆盖左右 / 上下，`.padding_left` / `.padding_right` / `.padding_top` / `.padding_bottom` 再覆盖单边（不管调用的先后，越具体的越优先）。
- `.justify(..)` 主轴上的分布：`Start`（默认）、`Center`、`End`、`SpaceBetween`、`SpaceAround`、`SpaceEvenly`。
- `.align(..)` 交叉轴上的对齐：`Stretch`（默认）、`Start`、`Center`、`End`、`Baseline`（按第一行文字的基线）。单个子元素用 `.align_self(..)` 覆盖。
- `.grow(1)` 分走主轴上的剩余空间，几个元素都设了时按比例分；`.shrink(..)`、`.basis(..)` 控制放不下时怎么压缩。
- `.direction(Direction::Row)` 可以改排列方向（也能绑定信号）。

```rust
pub fn alignment() -> Element {
    column()
        .gap(12)
        .child(text("被拉满整行").padding(8).background(SURFACE)) // 竖排默认 Align::Stretch：子元素横向拉满
        .child(text("保持自己的宽度").padding(8).background(SURFACE).align_self(Align::Start))
        .child(button("基础控件按内容的宽度")) // 不被拉宽（第 14 章）
        .child(button("要占满时给宽度").full_width(true))
        .child(row().gap(8).justify(Justify::End).child(button("取消")).child(button("确定")))
        .child(
            row()
                .gap(8)
                .align(Align::Baseline) // 大字和小字坐在同一条基线上
                .child(text("128").font_size(32).font_weight(700))
                .child(text("个项目").color(MUTED)),
        )
}
```

## 尺寸和长度

```rust
pub fn sizes() -> Element {
    column()
        .gap(12)
        .child(rect().width(pct(50)).height(40).background(Color::hex(0x0a84ff))) // 父元素宽度的一半
        .child(rect().full_width(true).max_width(480).aspect_ratio(16.0 / 9.0).background(Color::hex(0x30d158))) // 宽高比
        .child(row().child(text("左边")).child(text("推到最右").margin_left(auto()))) // auto 外边距吃掉剩余空间
        .child(row().wrap(true).gap(6).children((1..=12).map(|i| text(format!("标签 {i}")).padding_x(8).padding_y(2).radius(4).background(FILL)))) // 放不下就换行
}
```

- 长度 `Length`：数字就是逻辑像素；`px(200)`、`pct(50)`（父元素的百分比，0～100）、`auto()`、`fr(1)`（网格里的份数）、`min_content()`、`max_content()`。
- `.size(w, h)`、`.width` / `.height`、`.min_width` / `.max_width` / `.min_height` / `.max_height`、`.aspect_ratio(宽 / 高)`；`.full_width(true)`、`.full_height(true)`、`.full_size(true)` 是 `pct(100)` 的简写。同一个尺寸设了几次时后调用的算数：控件默认跟着内容宽，接着写 `.full_width(true)` 或 `.width(..)` 就改掉了。
- 外边距 `.margin`、`.margin_x` / `.margin_y`、`.margin_left` 等；`auto()` 的外边距吃掉剩余空间，用来把元素推到一边或居中（`.margin_x(auto())`）。
- `.wrap(true)` 放不下时换行，`.gap_x` / `.gap_y` 分别设横竖间距，`.align_content(..)` 决定多行之间怎么分布。

## 网格

```rust
/// 按宽度放下尽可能多的列，窗口变窄自动重排
pub fn cards() -> Element {
    let card = |label: String| column().padding(16).radius(8).background(SURFACE).border(1, LINE).child(text(label)); // 卡片就是带底色、描边的竖排
    grid()
        .columns(auto_fill(Track::min_max(200, fr(1))))
        .gap(16)
        .child(card("推荐（跨两列）".into()).grid_column(Place::span(2)))
        .children((1..=6).map(move |i| card(format!("卡片 {i}"))))
}

pub fn dashboard() -> Element {
    grid()
        .columns([px(220), fr(1)])
        .rows([px(56), fr(1)])
        .child(row().grid_column(..).padding(16).child(text("页眉（占满整行）")))
        .child(column().grid_row(2..).padding(16).child(text("侧栏（从第 2 条线到最后）")))
        .child(column().padding(16).child(text("内容（自动放进空格子）")))
}
```

- 轨道：单个长度、`Track::min_max(下限, 上限)`、`Tracks::repeat(n, 轨道)`、`auto_fill(..)`、`auto_fit(..)`；`.columns(..)` / `.rows(..)` 接受数组（`[fr(1); 3]`）、`Vec`、单个轨道、元组（混用长度和轨道），也能绑定信号（闭包返回 `Tracks`）。
- 位置：`.grid_column(1..3)` 按分隔线（第一条线是 1），`2..` 到最后一条线，`..` 占满整行，`Place::span(2)` 自动找位置跨两条轨道。没指定位置的子元素按行自动放进空格子。
- `.auto_rows(..)` / `.auto_columns(..)` 是自动加出来的行列的尺寸；`.justify_items(..)` / `.justify_self(..)` 是格子里的横向对齐。

## 绝对定位

设了 `inset_left` / `inset_right` / `inset_top` / `inset_bottom` 中任何一边的元素就是绝对定位：不参与父元素的排列，相对父元素的内边距框放置。每个元素都是它的子元素绝对定位的参照。

```rust
pub fn icon_with_badge() -> Element {
    rect()
        .size(44, 44)
        .radius(8)
        .background(FILL)
        .child(text("3").font_size(11).color(Color::WHITE).padding_x(5).radius(8).background(DANGER).inset_right(-6).inset_top(-6)) // 钉在右上角
}
```

`.position(x, y)` 是 `.inset_left(x).inset_top(y)` 的简写；`.inset(0)` 盖满父元素。后面的兄弟画在上面，兄弟之间的叠放次序用 `.stack_order(..)`（第 [11](11-交互.md) 章）；要盖住整个窗口用浮层（第 [12](12-浮层.md) 章）。

## 测量

`.report_bounds(信号)` 在每次重新布局之后把元素的位置（窗口坐标）和大小写进信号，界面可以按它摆别的东西。下面的指示条跟着选中的标签滑过去：

```rust
/// 测量：布局之后把位置和大小写进信号，指示条跟着选中项滑过去
pub fn measured() -> Element {
    let selected = signal(0usize);
    let bar = signal(Rect::default());
    let rects = [signal(Rect::default()), signal(Rect::default()), signal(Rect::default())];
    let at = move || rects[selected.get()].get();
    row()
        .gap(16)
        .padding_y(8)
        .report_bounds(bar)
        .children(["概览", "成员", "设置"].into_iter().enumerate().map(move |(i, label)| {
            text(label).report_bounds(rects[i]).on_click(move || selected.set(i))
        }))
        .child(
            rect()
                .inset_bottom(0)
                .inset_left(0)
                .height(2)
                .background(ACCENT)
                .width(move || at().width)
                .translation_x(move || at().x - bar.get().x)
                .transition(Property::TranslationX, Spring::snappy())
                .transition(Property::Width, Spring::snappy()),
        )
}
```

写回在同一帧里生效（画出来之前绑定已经更新）；第一次写入不做动画，所以挂载时不会从 0 滑过来。量到的是布局位置，不算平移、缩放这些变换和滚动偏移。

## 按窗口大小切换

窗口宽度分三档（`SizeClass`）：`Compact`（窄，默认小于 640）、`Regular`（640 到 1024）、`Wide`（1024 及以上）。`window_size_class()` 在绑定里读当前窗口的档位：拖动窗口边缘时它每帧重算一次（比较一个数），只有跨过分档宽度时值才变，读它的绑定只在这时重新执行。

```rust
/// 窄窗口竖排、宽了横排；换位置时两块从原来的地方滑过去
pub fn adaptive() -> Element {
    let slide = Spring::smooth();
    row()
        .direction(responsive(Direction::Column, Direction::Row, Direction::Row)) // 按档取值，跨过分界时才重新取
        .gap(responsive(12.0, 16.0, 24.0))
        .child(column().padding(16).background(SURFACE).grow(1).child(text("正文")).transition(Property::LayoutPosition, slide))
        .child(
            column()
                .padding(16)
                .background(SURFACE)
                .width(move || if window_size_class() == SizeClass::Compact { pct(100) } else { px(280) })
                .child(text("侧栏"))
                .transition(Property::LayoutPosition, slide), // 布局位置变了时滑过去（合成层上，不重新布局）
        )
        .child_when(move || is_window_at_least(1280.0), || column().padding(16).background(SURFACE).width(200).child(text("很宽的窗口才有第三栏")))
}
```

- `window_size_class()`、`is_window_at_least(宽度)`（窗口宽度不小于它）、`window_size()` 都是响应式的，读的是**调用它的绑定所在的窗口**：多个窗口各算各的，测试工具里是它的虚拟窗口（`h.resize(..)` 之后的下一帧生效）。要在绑定里调用；在构建视图的函数体里直接调用只读一次，不会跟着变。
- `responsive(窄, 中等, 宽)` 是 `move || window_size_class().pick(窄, 中等, 宽)` 的简写，直接传给属性。`is_window_at_least(..)` 同一个宽度在一个窗口里共用一个派生值；`window_size()` 每次变化都通知，只关心档位时不要用它。`set_size_class_widths(中等, 宽)` 改分界，全应用一份。
- `.transition(Property::LayoutPosition, 曲线)`：重新布局让元素换了位置（横排竖排切换、列表插入删除、网格换列数）时，从原来在屏幕上的位置滑到新位置。按相对父元素的位置算，父元素滑动时子元素跟着它走；只是窗口大小变了（拖动窗口边缘）时直接跟上，不滑；系统打开"减少动态效果"时直接到位。元素是一个合成层，滑动时只更新层的偏移。

也可以按**容器**的宽度分档：`.report_bounds(信号)` 量到容器的大小，过一个派生值，只在跨过分界时变：

```rust
/// 按容器的宽度分档：量到的宽度过一个派生值，跨过分界时才变
pub fn container_classes() -> Element {
    let size = signal(Rect::default());
    let class = memo(move || SizeClass::from_width(size.get().width));
    column()
        .width(pct(50)) // 容器的宽度不能取决于里面要切换的内容
        .report_bounds(size)
        .child(
            row()
                .direction(move || if class.get() == SizeClass::Compact { Direction::Column } else { Direction::Row })
                .gap(12)
                .child(text("标题"))
                .child(text("说明")),
        )
}
```

量到的是这一帧布局的结果：跨过分界时同一帧里再布局一次，画出来的已经是新的样子。

## 坑

- **竖排里的子元素默认被拉满整行**：交叉轴默认 `Align::Stretch`，没有固定宽度的子元素会被拉伸。不想拉伸时给容器 `.align(Align::Start)`，或者给子元素 `.align_self(Align::Start)`。基础控件（按钮、复选框、开关……）按内容的宽度，不会被拉伸；要占满时 `.full_width(true)` 或 `.width(pct(100))`。
- **固定宽度的元素放不下时也会被压窄**：默认可以收缩。不想被压时加 `.shrink(0)`（或者给父元素 `.wrap(true)`、改用滚动视口）。
- 网格里 `fr(1)` 等于 `Track::min_max(auto(), fr(1))`，不会比内容的最小宽度还窄，一个很长的词会把列撑开；要严格等分用 `Track::min_max(0, fr(1))`。
- 百分比按父元素算；父元素自己的大小由内容决定时，百分比可能没有参照。
- 外边距、最小最大尺寸、`gap_x` / `gap_y` 不能做动画；宽、高、内边距、间距可以（见第 [8](08-动画.md) 章），但它们是布局属性，动画期间每帧重新布局。
- 滚动视口在滚动方向上**不会被内容撑大**，要给它高度或 `grow`（见第 [10](10-滚动.md) 章）。
- 按容器宽度分档时，容器的宽度不能由里面要切换的内容决定（比如跟着内容宽），否则切换以后宽度变了又切回去。
- `Property::LayoutPosition` 只过渡位置，大小直接跳到新的（要过渡的话给像素宽高，配 `Property::Width` / `Height`）；滑动中元素会盖住别的元素，后面的兄弟在上面。
