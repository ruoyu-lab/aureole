# 2. 元素和链式写法

## 元素

只有一种元素类型 `Element`，由几个函数创建：

| 函数 | 是什么 |
|---|---|
| `row()` / `column()` | 横排 / 竖排的容器 |
| `rect()` | 矩形，也可以有子元素（默认横排） |
| `grid()` | 网格容器（见第 [4](04-布局.md) 章） |
| `text(内容)` | 文字（第 [6](06-文字与字体.md) 章） |
| `text_field(信号)` / `text_area(信号)` | 单行 / 多行输入框（第 [7](07-输入框和多行编辑.md) 章） |
| `button(内容)`、`checkbox(信号)`、`select(信号, 选项)`…… | 基础控件（第 [14](14-基础控件.md) 章） |
| `path(路径)` / `image(来源)` | 矢量路径、图片（第 [15](15-图片与矢量图标.md) 章） |
| `scroll_x` / `scroll_y` / `scroll_y_fit` / `scroll` / `virtual_list` | 滚动视口、虚拟列表（第 [9](09-列表.md)、[10](10-滚动.md) 章） |

每个属性方法都拿走元素、改完再还回来，所以能一直链下去。**自己的界面块就是返回 `Element`（或 `impl View`）的普通函数**，叫视图函数，没有别的概念：

> 带内容的元素（文字、输入框、画布……）背后是一个实现了 `ElementKind` 的种类对象，也可以自己定义一种，见第 [25](25-自定义元素.md) 章。平时用不着。

```rust
/// 视图函数就是普通函数；返回 Element，调用的地方还能接着链式修改
pub fn profile(name: &str, role: &str) -> Element {
    let initial: String = name.chars().take(1).collect(); // 头像：名字的第一个字
    row()
        .gap(12)
        .padding(12)
        .radius(8)
        .align(Align::Center)
        .background(SURFACE)
        .border(1, LINE)
        .child(row().size(36, 36).radius(18).align(Align::Center).justify(Justify::Center).background(ACCENT_SOFT).color(ACCENT).child(text(initial)))
        .child(
            column()
                .gap(2)
                .child(text(name).font_weight(600)) // 借来的 &str 直接传，复制一份
                .child(text(role).font_size(12).color(MUTED)),
        )
}

pub fn team() -> Element {
    column()
        .gap(8)
        .child(profile("林小梨", "设计师"))
        .child(profile("周一", "工程师").opacity(0.6).name("zhou")) // 接着改：变淡、起名字
        .children(["甲", "乙", "丙"].map(text)) // 一组固定的子元素
}
```

- 视图函数返回 `Element` 时，调用的地方还能接着改属性、加处理器；返回 `impl View` 则把实现藏起来。基础控件里有几个部位的（复选框、滑块、下拉选择……）是构建器（`Slider::new(v).range(..)`），它们也实现了 `View`，能直接放进 `.child(..)`，元素的方法也能直接接着用；要 `Element` 类型时（比如函数的返回类型）`.build()`。`&str`、`String` 也是 `View`：`.child("说明")` 就是一段文字。
- `.name("zhou")` 给元素起名字：测试工具按名字找元素，辅助技术也能按它找到元素。
- `.children(..)` 接受任何迭代器，用于固定的一组子元素；会随数据增删的列表用 `.each(..)`（第 [9](09-列表.md) 章）。
- `SURFACE`、`LINE` 这些是下面"颜色"一节里定义的几个颜色常量，后面各章的代码都直接用。
- 同一组样式要在几处用，或者要按悬停、按下换值时，放进样式对象（`Style`，第 [13](13-样式对象.md) 章）。

## 静态值和绑定

每个属性方法都接受静态值、闭包、`Signal` 或 `Memo`：

```rust
pub fn bindings() -> Element {
    let wide = signal(false);
    let width = memo(move || if wide.get() { 240.0 } else { 120.0 });
    rect()
        .height(48) // 静态值；整数直接当像素
        .opacity(0.9) // 静态值：没有任何响应式开销
        .width(width) // 派生值
        .radius(move || if wide.get() { 24.0 } else { 8.0 }) // 闭包：读到的信号变了才重新求值
        .background(Color::hex(0x0a84ff))
        .on_click(move || wide.update(|w| *w = !*w))
}
```

- 静态值直接写进元素，没有任何额外开销；闭包（**绑定**）在一个副作用里求值，读到的信号变了只重新求这一个属性。
- **每个属性都能绑定**，不只是颜色和大小：开关（`.clip(信号)`）、文字的设置（`.max_lines(闭包)`）、占位文字都一样（第 [5](05-样式与视觉.md) 章）。
- 属性分两类：**布局属性**（宽高、内边距、间距、对齐、`grow`……）变了要重新布局；**绘制属性**（颜色、圆角、边框、投影、透明度、平移、缩放、旋转）变了只改绘制数据，不碰布局。写入和原来相同的值什么都不做。各自的开销见第 [22](22-性能指南.md) 章。
- 整数、浮点数都能当像素：`.padding(24)`、`.width(120.5)`。

## 颜色

```rust
pub fn colors() -> Element {
    row().gap(8).children(
        [
            Color::hex(0x0a84ff),         // 十六进制
            Color::rgb(52, 199, 89),      // 0..=255
            Color::rgba(255, 69, 58, 0.78), // 带透明度，0..=1
            Color::hsv(turns(0.78), 0.6, 0.9),   // 色相（一圈是 turns(1)）、饱和度、明度（0..=1）
            Color::WHITE.with_alpha(0.3), // 换透明度，0..=1
        ]
        .map(|c| rect().size(32, 32).radius(8).background(c)),
    )
}
```

数值的约定：按 8 位值构造用 0..=255 的整数（`rgb`、`rgba` 的三个通道、`hex`），透明度和别的分量一律是 0..=1 的小数（`rgba` 的透明度、`with_alpha`、`hsv`）。所以半透明的白色是 `Color::rgba(255, 255, 255, 0.5)`，也是 `Color::WHITE.with_alpha(0.5)`。

还有 `Color::TRANSPARENT`、`Color::BLACK`。颜色在线性空间混合、动画在 OKLab 里插值，所以渐变和过渡不发灰。

框架默认的样子用的是几种固定的浅色。自己的界面要和它协调，就把常用的几种写成常量（`Color::hex` 是 `const fn`），本教程后面的代码都用这几个：

```rust
// 和框架默认的样子一样的浅色
pub const BACKGROUND: Color = Color::hex(0xf6f7f9); // 窗口底色
pub const SURFACE: Color = Color::WHITE; // 卡片、面板、浮层
pub const TEXT: Color = Color::hex(0x1f2328); // 正文
pub const MUTED: Color = Color::hex(0x5c6570); // 次要文字
pub const LINE: Color = Color::hex(0xd9dde3); // 细线、分隔线、卡片的描边
pub const FILL: Color = Color::hex(0xf0f2f5); // 浅灰底：悬停
pub const ACCENT: Color = Color::hex(0x2563eb); // 强调色
pub const ACCENT_SOFT: Color = Color::hex(0xe7effd); // 强调色的浅底：选中
pub const SUCCESS: Color = Color::hex(0x1f9a6b);
pub const DANGER: Color = Color::hex(0xd6455a);
```

控件的描边是 `#c4cad2`（悬停 `#98a1ac`），按下的底色 `#e3e7ec`，强调色悬停 `#1f55d0`、按下 `#1b48b0`，浮层的投影 `Shadow::new(0.0, 4.0, 12.0, Color::rgba(16, 24, 32, 0.18))`。

## 坑

- **`text(name.get())` 不会跟着变**：`text()` 接受字面量、`String`、借来的 `&str` / `&String`（复制一份），这些都是固定的文字，只取传进去那一刻的值。要跟着信号变，传闭包 `text(move || name.get())` 或者信号本身 `text(name)`：

```rust
pub fn greeting(name: &str) -> Element {
    // 固定的文字：字面量、String、借来的 &str 都行；这里拼接出一个 String
    text(format!("你好，{name}"))
}
```

- 绑定的闭包要 `move`，并且是 `'static` 的：捕获信号（它们是 `Copy` 的句柄），不要捕获引用。
- 处理器（`on_click`、`on_hover`、`on_press`、`on_change`……）的返回值不用：`aureole::spawn_local(..)`、`aureole::open_url(..)` 有返回值也可以直接写 `.on_click(|| aureole::open_url("https://www.rust-lang.org"))`；`shortcut`、`aureole::after` 的闭包也一样。
- 处理器可以不带参数（`.on_click(|| ..)`），也可以收事件对象；收事件对象的闭包要写出参数的类型：`.on_drag(|e: &DragEvent| ..)`。同一个方法接受两种闭包，编译器推断不出来，忘了写时报 `type annotations needed`。完整的规则见第 [11](11-交互.md) 章的"处理器的写法"。
- 同一个事件可以加多个处理器，按添加顺序调用；控件内部的处理器排在你加的后面。
