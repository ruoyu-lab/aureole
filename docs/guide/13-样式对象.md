# 13. 样式对象

一组样式要在几处用、要按悬停、按下、焦点这些状态换值时，放进**样式对象**（`Style`）：定义一次，`.style(&s)` 用到任何元素上，基础控件的每个部位也收样式对象（第 [14](14-基础控件.md) 章）。没有状态时，用它就是按顺序调用对应的链式方法；有状态的属性多一个按状态选值的绑定。

## 定义一次，到处用

```rust
pub fn chips() -> Element {
    let chip = Style::new()
        .height(28)
        .padding_x(10)
        .radius(14)
        .align(Align::Center)
        .background(SURFACE)
        .border(1, Color::hex(0xc4cad2))
        .cursor(Cursor::Pointer)
        .hovered(|s| s.background(FILL))
        .pressed(|s| s.background(Color::hex(0xe3e7ec)));
    let active = chip.clone() + &Style::new().color(ACCENT).border_color(ACCENT); // 合起来：再改两个属性
    row()
        .gap(8)
        .child(row().style(&active).child("全部"))
        .child(row().style(&chip).child("未读"))
        .child(row().style(&chip).child("已归档"))
}
```

- `Style::new()` 之后链式地设属性，方法名和参数都和元素的一样：布局（尺寸、内边距、外边距、间距、方向、对齐、伸缩）、绘制（背景和渐变、边框和渐变边框、圆角、投影、透明度、滤镜、平移缩放旋转）、文字（字号、字重、行高、颜色、字距、对齐、下划线……，照常继承）、指针形状、过渡。
- 值和链式方法一样：静态值、信号、派生值、闭包。`Style::new().radius(move || size.get())` 用到几个元素上，每个元素各建一个绑定。
- 克隆只加引用计数：放进函数（`fn card() -> Style`）、自己的结构体、闭包里都行。
- 用到元素上：`.style(&s)`。之后照常接着写链式方法、事件。

## 状态

```rust
/// 状态：悬停、按下、键盘焦点、禁用。元素自己记，只在样式对象用到时才记
pub fn tiles() -> Element {
    let off = signal(false);
    let tile = Style::new()
        .size(120, 64)
        .padding(12)
        .radius(8)
        .background(SURFACE)
        .border(1, LINE)
        .hovered(|s| s.border_color(Color::hex(0x98a1ac)))
        .pressed(|s| s.background(FILL))
        .focused(|s| s.border_color(ACCENT)) // 用 Tab 走到时（同时画焦点环）
        .disabled(|s| s.opacity(0.5));
    row()
        .gap(12)
        .align(Align::Center)
        .child(column().style(&tile).focusable(true).on_click(|| println!("打开")).child("文档"))
        .child(column().style(&tile).focusable(true).disabled(off).child("回收站")) // 禁用状态来自元素的 .disabled(..)
        .child(checkbox(off).label("禁用回收站"))
}
```

| 状态 | 什么时候 |
|---|---|
| `.hovered(..)` | 指针在上面（含子元素）；禁用时不算 |
| `.focused(..)` | **显示焦点的时候**：用键盘（Tab、方向键）得到焦点、画焦点环时，指针点的不算；输入框例外，有焦点就算（插入点在里面） |
| `.pressed(..)` | 指针按着；禁用时不算 |
| `.disabled(..)` | 禁用：元素自己的 `.disabled(..)`（控件的是构建器上的） |
| `.selected(..)`、`.checked(..)`、`.open(..)` | 选中、勾选、展开：控件的部位给出（下拉列表里当前的值、勾上的复选框、打开的下拉框），自己的元素用下面的 `style_with` 给出 |

- 每个状态收一个闭包：它拿到一个空的样式对象，在里面设这个状态下的值。**状态可以嵌套**：`.checked(|s| s.background(绿).hovered(|s| s.background(深绿)))` 里的 `hovered` 是"勾选并且悬停"。
- 悬停、按下、焦点、禁用由元素自己记：样式对象用到哪个才记哪个，和自己加的 `on_hover`、`on_press` 同时生效。
- **几个状态同时成立时按固定的优先级**，和写的先后无关：悬停 < 焦点 < 按下 < 选中 < 勾选 < 打开 < 禁用。嵌套的先比其中最靠后的那个、一样时再比下一个，所以"勾选并且悬停"优先于只写了"勾选"的，"勾选并且按下"又优先于"勾选并且悬停"。
- 只在某个状态下设、平时没设的属性，平时用元素上原来的值：`.style(&Style::new().hovered(|s| s.background(FILL)))` 加在任何元素上，平时还是它自己的底色。

自己的元素有"选中""勾选""展开"时，用 `.style_with(&样式, &States)` 交给样式对象；`States` 里每种状态一个响应式的读取（信号、派生值、闭包）或者固定的 `true` / `false`，没给的悬停、焦点、按下、禁用照样由元素自己记：

```rust
/// 自己的列表行有"选中"：用 style_with 把状态交给样式对象
pub fn mailboxes() -> Element {
    let picked = signal(0usize);
    let item = Style::new()
        .height(32)
        .padding_x(10)
        .radius(6)
        .align(Align::Center)
        .hovered(|s| s.background(FILL))
        .selected(|s| s.background(ACCENT_SOFT).color(ACCENT).hovered(|s| s.background(Color::hex(0xdbe6fc))));
    column().width(200).gap(2).children(["收件箱", "已发送", "草稿"].into_iter().enumerate().map(move |(i, name)| {
        row()
            .style_with(&item, &States::new().selected(move || picked.get() == i))
            .on_click(move || picked.set(i))
            .child(name)
    }))
}
```

标签页、分段控件就是一排这样的按钮，页面用 `child_when` 切换：

```rust
/// 一排按钮切换页面：选中的那个用"选中"状态；每一页选中时才构建，切走时连同里面的状态一起释放
pub fn pages() -> Element {
    let page = signal(0usize);
    let tab = Style::new()
        .background(Color::TRANSPARENT)
        .border_color(Color::TRANSPARENT)
        .selected(|s| s.background(ACCENT_SOFT).color(ACCENT));
    let names = ["概览", "成员", "设置"];
    column()
        .gap(12)
        .child(row().gap(4).children(names.into_iter().enumerate().map(move |(i, name)| {
            let on = move || page.get() == i;
            button(name).style_with(&tab, &States::new().selected(on)).accessibility_role(Role::Tab).accessibility_selected(on).on_click(move || page.set(i))
        })))
        .child_when(move || page.get() == 0, || text("项目概览"))
        .child_when(move || page.get() == 1, || text("成员列表"))
        .child_when(move || page.get() == 2, || text("项目设置"))
}
```

按钮自己记的悬停、按下、焦点照样在：没选中的按钮悬停时还是默认的浅灰底，选中的（优先级更高）一直是浅蓝底。

## 合起来、先后

`a + &b`（或者 `a.extend(&b)`）把两个样式对象合起来：**按属性、按状态逐个合**，`b` 设了的值盖过 `a` 在同一个状态下的值，`a` 别的状态下的值留着；`a` 本身不变。

用到元素上也是这样，和别的链式方法一样**后调用的算数**，一种属性一种属性地看：

```rust
/// 先后：后调用的算数，一种属性一种属性地看
pub fn precedence() -> Element {
    let base = Style::new().background(SURFACE).border(1, LINE).hovered(|s| s.background(FILL)).pressed(|s| s.background(Color::hex(0xe3e7ec)));
    let tint = Style::new().background(ACCENT_SOFT).hovered(|s| s.background(Color::hex(0xdbe6fc)));
    let tile = || rect().size(96, 48).radius(6);
    row()
        .gap(8)
        .child(tile().style(&base).style(&tint)) // 平时、悬停是 tint 的，按下还是 base 的
        .child(tile().style(&(base.clone() + &tint))) // 和上一个一样
        .child(tile().style(&base).background(ACCENT_SOFT)) // 链式方法：所有状态下都是它，悬停、按下不再变
        .child(tile().background(ACCENT_SOFT).style(&base)) // 样式对象在后：平时的值换成 base 的，悬停、按下照常
}
```

- **链式方法**（`.background(..)`）设的值在所有状态下都是它：换掉前面样式对象给这个属性的平时的值和各状态下的值。
- **样式对象**设的值按状态合：它给了平时的值就换掉前面的平时的值（链式方法设的也算平时的值）；它给了某个状态下的值就换掉前面同一个状态下的值；前面别的状态下的值留着。
- 所以 `.style(&a).style(&b)` 和 `.style(&(a + &b))` 一样。
- 基础控件默认的样子就是先用上的样式对象：后面的样式对象按状态合进去，链式方法盖过它（第 [14](14-基础控件.md) 章）。

## 过渡

状态一变属性立即换成新值，没有内置的动画。要平滑地变就在样式对象里声明过渡，和元素的 `.transition(..)` 一样：

```rust
/// 状态一变立即换；声明了过渡就按曲线变过去
pub fn soft_button() -> Element {
    let soft = Style::new()
        .transition(Property::Background, Tween::new(ms(120)).ease_out())
        .transition(Property::Scale, Spring::snappy())
        .pressed(|s| s.scale(0.97));
    button("轻轻按下").style(&soft)
}
```

按钮默认的悬停、按下底色还在（样式对象没碰底色），现在按过渡变过去，按下时还缩小一点。写在某个状态里的 `.transition(..)`（`.checked(|s| s.transition(..))`）只在这个状态会出现的元素上声明。

## 其他元素方法：`chain`

大多数属性都能直接写在样式对象上（`max_lines`、`tabular_numbers`、`clip`……）。事件、提示这些不是属性的元素方法，和一些不算样式的属性（`name`、无障碍），用 `.chain(..)`：用到元素上时调用，在属性之后。

```rust
/// 样式对象能设大多数属性；事件、提示这些不是属性的元素方法用 chain
pub fn captions() -> Element {
    let caption = Style::new().font_size(12).color(MUTED).max_lines(1).tabular_numbers(true).chain(|el| el.tooltip("完整的说明"));
    column()
        .width(160)
        .gap(4)
        .child(text("很长很长的一段说明文字，超过一行就截断").style(&caption))
        .child(text("用时 12.50 秒").style(&caption))
}
```

`.chain(..)` 只能放在平时的值里，不能放进状态。

## 开销

- **没有状态的样式对象没有额外开销**：和直接调用链式方法一样多的响应式节点（静态值还是静态值，绑定还是绑定）。
- 有状态的：每个元素多一个记状态的信号，每个按状态换值的属性一个绑定。不会出现的状态（`States` 里固定为 `false` 的）不建绑定，也不记。一千个默认样子的按钮，每个最多 4 个响应式节点（一个记状态的信号，背景、描边颜色、透明度三个绑定）。
- 控件默认的样子每个线程只建一次，所有控件共用；部位的默认样子合进自己给的样式对象的结果也缓存着，一千个控件只合一次。

## 坑

- **链式方法写在样式对象后面，这个属性就不再随状态变**：`.style(&s).background(X)` 悬停时也是 `X`。只想换平时的颜色、保留悬停的，用样式对象：`.style(&s).style(&Style::new().background(X))`。
- **只在状态里设的继承属性**（文字颜色、字号……），平时的值不是继承来的，而是元素上原来的值，没有时是默认值（文字颜色是 `#1f2328`）。要继承父元素的，就把平时的值也设上。
- `focused` 是"显示焦点"：指针点的按钮不算，用 Tab 走到才算；输入框里有插入点就算。要"有焦点就变"的普通元素，自己用 `on_focus` 记。
- 只改了"勾选"、没改"勾选并且悬停"时，悬停在勾上的控件上用的还是前面（默认的样子）嵌套的那个值：嵌套的优先（第 [14](14-基础控件.md) 章的例子）。
- `States` 里给出的状态盖过元素自己记的：`States::new().hovered(信号)` 之后悬停由你的信号决定。
- `.chain(..)` 不能放进状态（调试构建里断言）。
