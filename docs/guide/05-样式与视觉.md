# 5. 样式与视觉

## 每个属性都能绑定

属性方法都收同一种东西：静态值、信号、派生值或闭包（第 [2](02-元素和链式写法.md) 章）。不只是颜色和大小，开关、文字的设置、遮罩也一样：

```rust
/// 每个属性都收静态值、信号、派生值或闭包：不只是颜色和大小，开关、文字设置、遮罩也一样
pub fn bound_properties() -> Element {
    let compact = signal(false);
    let query = signal(String::new());
    column()
        .gap(8)
        .clip(compact) // 开关绑定信号
        .child(text("一段很长的说明文字，紧凑模式下只显示一行。").max_lines(move || if compact.get() { 1 } else { 3 })) // 文字的设置
        .child(text("强调").italic(compact).tabular_numbers(compact))
        .child(text_field(query).placeholder(move || if compact.get() { "搜索".to_string() } else { "输入要搜索的内容".to_string() })) // 占位文字
        .child(checkbox(compact).label("紧凑"))
}
```

设在不适用的元素上的属性（`max_lines` 设在没有文字的元素上）什么都不做，调试构建里每个属性用 `tracing` 提示一次。

## 角度和时长写单位

角度是 `Angle`，时长是 `std::time::Duration`，都不从裸的数字转换，写的人必须写出单位，读的人一眼看得出：

```rust
/// 角度和时长都写单位：`Angle` 和 `Duration` 不从裸的数字转换，写错单位编译不过
pub fn units() -> Element {
    let turned = signal(false);
    row()
        .gap(16)
        .child(rect().size(40, 40).background(ACCENT_SOFT).rotation(deg(45))) // 度
        .child(rect().size(40, 40).background(ACCENT_SOFT).rotation(rad(std::f32::consts::FRAC_PI_4))) // 弧度
        .child(rect().size(40, 40).background(ACCENT_SOFT).rotation(turns(0.125))) // 圈
        .child(
            rect()
                .size(40, 40)
                .background(ACCENT)
                .rotation(move || if turned.get() { deg(180) } else { deg(0) })
                .transition(Property::Rotation, Tween::new(ms(300)).ease_out()) // 毫秒
                .transition(Property::Scale, Spring::new(secs(0.4), 0.8)) // 秒，也能写小数
                .on_click(move || turned.update(|t| *t = !*t)),
        )
}
```

| 单位函数 | 是什么 | 用在 |
|---|---|---|
| `deg(45)`、`rad(1.0)`、`turns(0.25)` | 度、弧度、圈，整数和小数都行 | `.rotation(..)`、`.rotation_x(..)`、`Gradient::linear(..)`、`Color::hsv(..)`、`Color::oklch(..)`、`Filter::hue_rotation(..)`、`Canvas::rotate(..)` |
| `ms(300)`、`secs(0.5)` | 毫秒、秒，返回 `Duration` | `Tween::new(..)`、`Spring::new(..)`、`Keyframes::at(..)`、`.delay(..)`、`aureole::after(..)`、`aureole::sleep(..)`、测试工具的 `advance(..)` |
| `px(200)`、`pct(50)`、`fr(1)` | 长度（第 [4](04-布局.md) 章）；数字直接当逻辑像素 | 宽高、内边距…… |

透明度和别的比例是 0..=1 的小数，颜色的通道是 0..=255（第 [2](02-元素和链式写法.md) 章）。

写工具、读配置时按名字找属性：键在 `aureole::property` 里，每个属性一个（`property::BACKGROUND`），`Element::set(键, 值)`、`Style::set(键, 值)` 和链式方法设的是同一个属性。`property::PropId::from_name("radius")` 按名字找，`.metadata()` 读它的说明、值的类型、适用的元素、能不能做动画，`parse`、`format` 按文字解析和格式化：

```rust
/// 写工具、读配置时按名字找属性：键在 `aureole::property` 里，`set` 和链式方法设的是同一个属性
pub fn by_key() -> Element {
    let radius = property::PropId::from_name("radius").expect("有这个属性");
    println!("属性 {}", radius.name());
    rect().size(80, 48).set(property::BACKGROUND, ACCENT).set(property::RADIUS, 8.0)
}
```

## 圆角、边框、投影、透明度

```rust
pub fn boxes() -> Element {
    row()
        .gap(16)
        .child(rect().size(120, 80).radius(16).background(Color::hex(0x2c2c2e)).border(1, Color::WHITE.with_alpha(0.15)))
        .child(rect().size(120, 80).radius(16).background(Color::WHITE).shadow(Shadow::new(0.0, 8.0, 24.0, Color::BLACK.with_alpha(0.25))))
        .child(rect().size(80, 80).radius(40).background(Color::hex(0x0a84ff)).opacity(0.5))
}
```

- `.border(宽度, 颜色)` 向内画，不改变元素大小。
- `Shadow::new(x, y, 模糊半径, 颜色)`：模糊半径是高斯模糊标准差的 2 倍，只画在形状外面；`Shadow::NONE` 是没有投影。
- `.opacity(..)` 是**分组透明度**：作用于整棵子树，重叠的子元素不会互相透出来。完全透明的元素不产生任何图元。
- 平移 `.translation(x, y)` / `.translation_x` / `.translation_y`、缩放 `.scale(..)`、旋转 `.rotation(角度)` 绕中心作用于整棵子树，不影响布局。
- 这些属性都能放进样式对象，在几处共用、按悬停、按下、焦点换值（第 [13](13-样式对象.md) 章）。
- 角度带单位：`.rotation(deg(45))`。

## 渐变

```rust
pub fn gradients() -> Element {
    let sunset = Gradient::linear(deg(135.0), [(0.0, Color::hex(0xff5f6d)), (0.55, Color::hex(0xff9966)), (1.0, Color::hex(0xffc371))]);
    let glow = Gradient::radial([(0.0, Color::hex(0x64d2ff)), (1.0, Color::hex(0x0b1a3a))]).center(0.2, 0.2).radius(0.9);
    let ring = Gradient::conic(deg(0.0), [(0.0, Color::hex(0xff375f)), (0.5, Color::hex(0x5e5ce6)), (1.0, Color::hex(0xff375f))]);
    let srgb = Gradient::linear(deg(90.0), [(0.0, Color::hex(0xff0000)), (1.0, Color::hex(0x00ffff))]).color_space(ColorSpace::Srgb);
    row()
        .gap(16)
        .align(Align::Center)
        .child(rect().size(160, 100).radius(20).background(sunset.clone()))
        .child(rect().size(160, 100).radius(20).background(glow))
        .child(rect().size(100, 100).radius(50).background(ring))
        .child(rect().size(160, 100).radius(20).background(srgb))
        .child(text("渐变文字").font_size(28).font_weight(800).color(sunset))
}
```

- `Gradient::linear(角度, 色标)`：`deg(0)` 朝上，顺时针，`deg(90)` 是从左到右；渐变线的长度让四个角正好落在两端。`radial(色标)` 是圆形，中心默认在正中（`.center(x, y)` 是元素框里的比例），半径默认到最远的角（`.radius(r)` 是它的倍数）。`conic(起始角, 色标)` 绕中心转一圈。
- 色标默认在 OKLab 里插值，互补色中间不发灰；`.color_space(ColorSpace::LinearRgb)` / `Srgb` 换插值空间。大面积的平滑渐变带抖动，看不到色带。
- `.background(..)` 和 `.color(..)`（文字、路径的颜色）都接受颜色或渐变。克隆渐变只是加引用计数。
- 同一个绑定要在纯色和渐变之间切换时，让闭包返回 `Fill`；渐变之间、纯色和渐变之间都能做动画：

```rust
/// 同一个绑定在纯色和渐变之间切换：闭包返回 Fill
pub fn fill_switch() -> Element {
    let on = signal(false);
    let glow = Gradient::linear(deg(90.0), [(0.0, Color::hex(0x5e5ce6)), (1.0, Color::hex(0xbf5af2))]);
    rect()
        .size(160, 44)
        .radius(22)
        .background(move || if on.get() { Fill::from(glow.clone()) } else { Fill::from(Color::hex(0x3a3a3c)) })
        .transition(Property::Background, Spring::smooth())
        .on_click(move || on.update(|v| *v = !*v))
}
```

```rust
pub fn glass() -> Element {
    column()
        .size(360, 200)
        .radius(24)
        .clip(true)
        .background(Gradient::linear(deg(120.0), [(0.0, Color::hex(0xff375f)), (1.0, Color::hex(0x0a84ff))]))
        .child(rect().size(140, 140).radius(70).background(Color::hex(0xffd60a)).position(30, 20))
        .child(
            column()
                .position(80, 50)
                .size(240, 110)
                .radius(18)
                .padding(18)
                .backdrop_blur(20) // 背景模糊
                .backdrop_saturation(1.6) // 颜色更鲜艳
                .background(Color::WHITE.with_alpha(0.14)) // 玻璃本身的颜色
                .border(1, Color::WHITE.with_alpha(0.3))
                .child(text("毛玻璃").font_size(22).font_weight(700).color(Color::WHITE)),
        )
}
```

- `.clip(true)`：子孙（和自己的文字）只在自己的圆角矩形里可见，跟着旋转、缩放和动画走，边缘抗锯齿。自己的背景、边框、投影不被裁。
- `.blur(σ)`：把自己连同子元素模糊，σ 是逻辑像素，可以做动画。
- `.backdrop_blur(σ)` + `.backdrop_saturation(s)`：显示后面内容模糊后的样子，再配一个半透明的背景色当玻璃的颜色。饱和度 1 不变，常用 1.5～1.8。后面的内容在动时每帧重新模糊。

## 自定义着色器

特殊效果直接写 WGSL：实现 `fn shade(in: ShaderInput) -> vec4<f32>`，返回 sRGB、未预乘的颜色。`in.uv` 是元素里的位置（0..1），`in.size` 是元素大小，`in.time` 是动画时间的秒数（暂停、慢放动画时它也跟着，第 [8](08-动画.md) 章），`in.params` 是元素上传进来的 4 个数，`in.color` 是元素的背景色。圆角、边框、投影、透明度、裁剪照常生效。

```rust
const PLASMA: &str = r#"
fn shade(in: ShaderInput) -> vec4<f32> {
    let p = in.uv * 3.0;
    let v = sin(p.x + in.time) + sin(p.y * 1.3 - in.time * 0.8) + in.params.x;
    let c = 0.5 + 0.5 * cos(vec3(0.0, 2.1, 4.2) + v);
    return vec4(c, 1.0);
}
"#;

pub fn shader() -> Element {
    let hue = signal(0.0f32);
    let plasma = Shader::new(PLASMA).animated(true); // 用到了 in.time：标记成随时间变化
    rect()
        .size(200, 120)
        .radius(20)
        .shader(&plasma, move || [hue.get(), 0.0, 0.0, 0.0]) // 4 个参数，可以绑定
        .on_click(move || hue.update(|h| *h += 1.0))
}
```

着色器在渲染线程第一次用到时编译，按源码缓存，所以每个元素各自 `Shader::new` 也没关系。

## 坑

- **半透明（或透明度在动）的容器、模糊的元素会先画进离屏纹理再合成**，比直接画贵。只有一个图元时不离屏。不要给一大片列表的外层容器设 0.99 这种透明度。
- 背景模糊只能看到它所在分组里、它后面的内容：半透明或模糊的祖先是边界。
- 用到 `in.time` 的着色器一定要 `.animated(true)`，否则画面不会动。WGSL 写错时记一条错误（`tracing`）、这个元素不画，程序不会崩溃。
- 点击按矩形判断，`.clip(true)` 的圆角外面也能点到。

## 广色域和 HDR 的颜色

```rust
pub fn wide_colors() -> Element {
    let accent = Color::p3(0.0, 0.72, 0.62); // Display P3：比 sRGB 能写出的更饱和
    let vivid = Color::oklch(0.7, 0.16, deg(180.0)); // OKLCh：明度、彩度、色相（度）
    let glow = Color::hex(0xffd27a).brightness(3.0); // HDR：SDR 白的 3 倍亮
    let ramp = Gradient::linear(deg(90.0), [(0.0, Color::p3(1.0, 0.2, 0.3)), (1.0, Color::p3(0.2, 0.4, 1.0))]);
    row()
        .gap(12)
        .align(Align::Center)
        .child(rect().size(48, 48).radius(10).background(accent))
        .child(rect().size(48, 48).radius(10).background(vivid))
        .child(rect().size(120, 48).radius(10).background(ramp))
        .child(text("亮").font_size(32).font_weight(700).color(glow))
        .child(text(move || {
            let display = aureole::display_color(); // 这个窗口所在的显示器，响应式
            format!("余量 {:.1}，{}", display.headroom, if display.extended { "扩展范围" } else { "8 位 sRGB" })
        }))
}
```

- `Color::p3(r, g, b)` / `Color::p3_hex(0x..)`（Display P3 的编码值）、`Color::oklch(明度, 彩度, 色相)`、`Color::hdr(r, g, b, 倍数)` / `颜色.brightness(倍数)` 返回 `WideColor`。`.background(..)`、`.color(..)`、渐变的色标都接受它（同一个渐变里的色标写成同一种），能做动画。边框、投影的颜色仍是 `Color`（sRGB）。
- 广色域、HDR 的显示器上原样显示：画面里有这样的颜色（或者带色彩配置的、HDR 的图片）时，窗口换成扩展范围的表面（半精度浮点，带宽是 8 位的两倍；内容没了 2 秒后换回来）。普通显示器和截图里，sRGB 色域外的颜色截到 sRGB，比白亮的按最大的分量压到白（色相不变）。
- 比显示器此刻的余量还亮的颜色等比压到余量。`aureole::display_color()`、`WindowHandle::display_color()` 是显示器的能力（广色域、此刻和最多的余量）和窗口的输出方式，响应式；`Window::color_output(ColorOutput::Srgb)` 固定用 8 位。
- 界面里的白还是 SDR 白：HDR 只留给要特别亮的地方，大面积用会刺眼。

## 滤镜、混合模式、遮罩、缓存成纹理

```rust
pub fn desaturated() -> Element {
    let hovered = signal(false);
    let sunset = Gradient::linear(deg(135.0), [(0.0, Color::hex(0xff5f6d)), (1.0, Color::hex(0xffc371))]);
    rect()
        .size(160, 100)
        .radius(16)
        .background(sunset)
        .filter(move || if hovered.get() { Filter::NONE } else { Filter::grayscale(1.0).contrast(1.1) })
        .transition(Property::Filter, Tween::new(ms(200))) // 从灰过渡到彩色
        .on_hover(move |inside| hovered.set(inside))
}
```

- `Filter::grayscale(1.0).contrast(1.2)`：亮度 `brightness`、对比度 `contrast`、灰度 `grayscale`、饱和度 `saturation`、色相 `hue_rotation`（带单位的角度）、反相 `inversion`、褐色调 `sepia`、不透明度 `opacity`、模糊 `blur`，按写的顺序组合，每一种都能开头、也能接在后面。颜色的操作在 sRGB 编码的颜色上算（对比度绕中灰，反相后中灰不变）；模糊总是先做，和 `.blur(σ)` 叠加。`Filter::NONE` 是没有滤镜。
- `.transition(Property::Filter, ..)`：滤镜变化时过渡。两边操作的种类和顺序相同（或者一边是另一边的开头）时逐个插值参数，否则混合两个颜色矩阵。
- 只有一个图元（一张图片、一块颜色）时直接在那个图元上算，不离屏；否则整个元素先画进离屏纹理，合成时算。

```rust
pub fn inks() -> Element {
    let ink = |color: u32, x: f32, y: f32| {
        rect().size(80, 80).radius(40).position(x, y).background(Color::hex(color)).blend(BlendMode::Multiply)
    };
    rect()
        .size(200, 150)
        .radius(16)
        .background(Color::hex(0xf4f1ea))
        .child(ink(0x3fd0e0, 30.0, 15.0))
        .child(ink(0xe85fb4, 90.0, 15.0))
        .child(ink(0xf2d43a, 60.0, 60.0))
}
```

- `.blend(BlendMode::Multiply)`：元素连同子孙和**后面已经画好的内容**混合。有正片叠底 `Multiply`、滤色 `Screen`、叠加 `Overlay`、变暗 `Darken`、变亮 `Lighten`、颜色减淡 `ColorDodge`、颜色加深 `ColorBurn`、强光 `HardLight`、柔光 `SoftLight`、差值 `Difference`、排除 `Exclusion`，以及色相 `Hue`、饱和度 `Saturation`、颜色 `Color`、亮度 `Luminosity`。在线性空间里算（和其他混合一样），所以同样的模式比按 sRGB 数值算的更亮一些。

```rust
pub fn faded_list() -> Element {
    let fade = Gradient::linear(deg(180.0), [(0.0, Color::TRANSPARENT), (0.15, Color::WHITE), (0.85, Color::WHITE), (1.0, Color::TRANSPARENT)]);
    scroll_y(column().gap(8).children((1..=30).map(|i| text(format!("第 {i} 行")))))
        .width(200)
        .height(160)

}

pub fn star_window() -> Element {
    let star = VectorPath::svg("M50 4 L62 38 L97 38 L69 59 L80 94 L50 73 L20 94 L31 59 L3 38 L38 38 Z").view_box(0.0, 0.0, 100.0, 100.0);
    let glow = Gradient::radial([(0.0, Color::hex(0xffd60a)), (1.0, Color::hex(0xff375f))]);
    rect().size(120, 120).background(glow).mask(Mask::path(star))
}
```

- `.mask(Mask::gradient(g))`、`Mask::image(src)`、`Mask::path(p)`：元素连同子孙只在遮罩不透明的地方显示。遮罩铺满元素，图片拉伸，路径按画布缩放；`.luminance(true)` 改用明度（白显示、黑隐藏）。`Mask::element(view)` 用任意元素当遮罩，它可以绑定信号、做动画。
- 遮罩元素参与布局（铺满）、不参与排列，点不到，也不进无障碍树。

```rust
pub fn lifted_card() -> Element {
    let hovered = signal(false);
    column()
        .size(220, 120)
        .radius(16)
        .padding(16)
        .gap(6)
        .background(Color::hex(0x1c2326))
        .shadow(Shadow::new(0.0, 12.0, 32.0, Color::BLACK.with_alpha(0.35)))
        .child(text("缓存成纹理").font_size(18).color(Color::WHITE))
        .child(text("放大时只合成这张纹理，不重画里面的文字和投影").font_size(13).color(Color::hex(0x93a3a8)))
        .group_cache(true)
        .scale(move || if hovered.get() { 1.04 } else { 1.0 })
        .transition(Property::Scale, Spring::smooth())
        .on_hover(move |inside| hovered.set(inside))
}
```

- 半透明、有模糊、滤镜、遮罩、混合模式的元素画进离屏纹理，渲染线程把画好的纹理**缓存**下来：里面的内容没变、只有这个元素的平移、缩放、旋转、倾斜、透明度、滤镜在变时，直接合成这张纹理，不重画里面的内容。在动的时候纹理按此刻的变换贴上去，停下以后重画一次，回到逐像素清晰。
- `.group_cache(true)`：不透明、没有效果的元素也这样缓存。适合里面东西多（文字、投影、模糊）又要整体动的卡片。
- 缓存占显存，每个窗口默认最多 64 MB，超出时最久没用的先赶出去：`aureole::set_group_cache_budget(字节)` 改预算，`aureole::group_cache_stats()` 看用了多少、命中多少次。
- 坑：混合模式和背景模糊一样，只能看到最近的离屏祖先（半透明、有效果的祖先）里面、它后面的内容。遮罩、滤镜、混合模式都让元素离屏，大片的列表外层不要随手加。

## 几层投影、内阴影、渐变边框

```rust
/// 两层投影、内阴影、按下时外投影换成内阴影
pub fn layered_shadows() -> Element {
    let ink = Color::hex(0x0b1e24);
    let raised = Shadows::new([
        Shadow::new(0.0, 1.0, 2.0, ink.with_alpha(0.12)),                // 接触投影：贴得近
        Shadow::new(0.0, 8.0, 24.0, ink.with_alpha(0.08)).spread(-4.0), // 柔和投影：铺得开，往里缩一点
    ]);
    let pressed = signal(false);
    row()
        .gap(24)
        .child(rect().size(160, 100).radius(10).background(Color::WHITE).shadow(raised.clone()))
        .child(rect().size(160, 100).radius(10).background(Color::hex(0xeef2f3)).shadow(Shadow::inner(0.0, 3.0, 8.0, ink.with_alpha(0.14))))
        .child(
            rect()
                .size(160, 100)
                .radius(10)
                .background(Color::WHITE)
                .shadow(move || if pressed.get() { Shadows::from(Shadow::inner(0.0, 2.0, 6.0, ink.with_alpha(0.16))) } else { raised.clone() })
                .transition(Property::Shadow, Tween::new(ms(160)).ease_out()) // 外投影收起、内阴影出现
                .on_press(move |down| pressed.set(down)),
        )
}
```

- `.shadow(..)` 是一层（再调用一次是换掉它），`.shadow([..])` 是几层，第一层画在最上面；接受数组、`Vec`、`Shadows` 或返回它们的闭包。
- `Shadow::inner(x, y, 模糊, 颜色)` 是内阴影：画在边框以内、背景上面、子元素下面；偏移向下时阴影在上边，像压进去的凹槽。外投影和内阴影可以放在同一组里。
- `.spread(扩展)`：外投影的形状先往外扩再模糊（负值往里缩，贴近的接触投影和大范围的柔和投影常用）；内阴影往里多铺这么宽。圆角跟着加减，直角保持直角。
- 动画（`Property::Shadow`）：一层外投影按偏移、模糊、扩展、颜色过渡；几层或者有内阴影时，同一位置、同一种的两层逐层插值，其余的交叉淡化（上面按下的例子：外投影淡出、内阴影淡入）。

```rust
/// 渐变边框：悬停时从中性色过渡到强调色的渐变
pub fn gradient_border() -> Element {
    let hovered = signal(false);
    let accent = Gradient::linear(deg(135.0), [(0.0, Color::hex(0x138a84)), (1.0, Color::hex(0x4a6fa5))]);
    rect()
        .size(200, 120)
        .radius(12)
        .background(Color::WHITE)
        .border(1.5, move || if hovered.get() { Fill::from(accent.clone()) } else { Fill::from(Color::hex(0xdfe6e8)) })
        .transition(Property::BorderColor, Spring::smooth())
        .on_hover(move |inside| hovered.set(inside))
}
```

- `.border(宽度, 颜色)` 的颜色可以是渐变（线性、径向、锥形），铺满元素的框，沿圆角一圈都对；`Property::BorderColor` 在纯色和渐变、渐变和渐变之间过渡，和背景一样（角度从 0 到 360 配 `Tween::forever()` 就是一直转的边框）。图片元素的边框画在图片上面，也可以是渐变。
- 开销：最常见的"一层不带扩展的外投影 + 纯色边框"还是一个图元，和以前一样；每多一层投影、每层内阴影多一个图元，渐变边框不多图元。都在同一次绘制调用里，不多渲染通道。

## 坑（投影和边框）

- 关键帧时间线只能动一层外投影；内阴影、几层投影用 `.transition(Property::Shadow, ..)` 的过渡。
- 图片元素的内阴影被图片盖住（图片是内容，画在内阴影上面）。
- 投影、内阴影的模糊按距离场近似：模糊很大、圆角很小时，转角处和真正的高斯模糊略有不同。
