## 属性绑定 + 声明过渡

框架没有内置动画：控件、样式对象的状态一变立即换成新值。要动画就声明它：属性照常绑定，再用 `.transition(属性, 曲线)` 声明"这个属性变化时怎么过渡"（样式对象里也能写，第 [13](13-样式对象.md) 章）：

```rust
pub fn switch(on: Signal<bool>) -> Element {
    row()
        .size(52, 32)
        .padding(4)
        .radius(16)
        .background(move || if on.get() { Color::hex(0x34c759) } else { Color::hex(0x3a3a3c) })
        .transition(Property::Background, Tween::new(ms(200)).ease_out())
        .on_click(move || on.update(|v| *v = !*v))
        .child(
            rect()
                .size(24, 24)
                .radius(12)
                .background(Color::WHITE)
                .translation_x(move || if on.get() { 20.0 } else { 0.0 })
                .transition(Property::TranslationX, Spring::snappy()),
        )
}

pub fn hover_card() -> Element {
    let hovered = signal(false);
    column()
        .size(200, 120)
        .radius(16)
        .padding(16)
        .background(move || if hovered.get() { FILL } else { SURFACE })
        .transition(Property::Background, Tween::new(ms(150)).ease_out())
        .scale(move || if hovered.get() { 1.04 } else { 1.0 })
        .transition(Property::Scale, Spring::snappy())
        .shadow(move || {
            let alpha = if hovered.get() { 0.3 } else { 0.12 };
            Shadow::new(0.0, if hovered.get() { 12.0 } else { 2.0 }, 28.0, Color::BLACK.with_alpha(alpha))
        })
        .transition(Property::Shadow, Spring::smooth())
        .on_hover(move |inside| hovered.set(inside))
        .child(text("悬停放大"))
}
```

能做动画的属性（`Property`）：`Background`、`BorderColor`、`BorderWidth`、`Radius`、`Shadow`、`Opacity`、`Scale`、`Rotation`、`TranslationX`、`TranslationY`、`RotationX`、`RotationY`、`Perspective`、`Color`、`Blur`、`BackdropBlur`、`BackdropSaturation`、`Filter`、`StrokeStart`、`StrokeEnd`，以及布局属性 `Width`、`Height`、`Padding`、`Gap`，布局位置的滑动 `LayoutPosition`（第 [4](04-布局.md) 章），还有路径的形状 `Path`（见第 [15](15-图片与矢量图标.md) 章的路径变形）。颜色在预乘的 OKLab 里插值，从透明淡入时颜色不发黑；渐变之间也能过渡。

## 弹簧和补间

```rust
pub fn curves() -> Element {
    let moved = signal(false);
    let curves: [(&str, Curve); 6] = [
        ("smooth", Spring::smooth().into()),                        // 平滑，不回弹
        ("snappy", Spring::snappy().into()),                        // 快、跟手
        ("bouncy", Spring::bouncy().into()),                        // 明显回弹
        ("自定义弹簧", Spring::new(ms(400), 0.7).into()),               // 响应时间 0.4 秒，阻尼比 0.7
        ("补间", Tween::new(ms(240)).ease_in_out().into()),              // 固定 240 毫秒
        ("贝塞尔", Tween::new(ms(300)).easing(Easing::CubicBezier(0.2, 0.9, 0.3, 1.2)).into()), // y 超过 1：过冲
    ];
    column().gap(8).on_click(move || moved.update(|m| *m = !*m)).children(curves.map(|(name, curve)| {
        row().gap(12).align(Align::Center).child(text(name).width(96)).child(
            rect()
                .size(20, 20)
                .radius(10)
                .background(ACCENT)
                .translation_x(move || if moved.get() { 220.0 } else { 0.0 })
                .transition(Property::TranslationX, curve),
        )
    }))
}
```

- **弹簧** `Spring::new(响应时间, 阻尼比)`（`Spring::new(ms(400), 0.7)`）：阻尼比 1 不回弹，越小回弹越多。预设 `smooth()`、`snappy()`（悬停、按压）、`bouncy()`。弹簧**可打断**：目标中途改变时从当前位置和速度出发，运动连续，这是"手感"的关键。值是时刻的纯函数，掉帧、卡顿也不会发散。
- **补间** `Tween::new(时长)`（`Tween::new(ms(300))`），默认缓动 `ease`；`.linear()`、`.ease_in()`、`.ease_out()`、`.ease_in_out()`、`.easing(Easing::CubicBezier(..))`。被打断时从当前值重新开始。`.forever()` 一直重复，`.alternate(true)` 来回往复。

## 入场、循环、退场

**挂载时的初始值不做动画**，只有之后的变化才做。入场动画的写法是：初始值设成"进场前"，挂载后在 `on_mount` 里改目标：

```rust
pub fn fade_in(label: &str) -> Element {
    let shown = signal(false);
    row()
        .padding(12)
        .radius(6)
        .background(SURFACE)
        .border(1, LINE)
        .opacity(move || if shown.get() { 1.0 } else { 0.0 })
        .transition(Property::Opacity, Tween::new(ms(220)).ease_out())
        .translation_y(move || if shown.get() { 0.0 } else { -8.0 })
        .transition(Property::TranslationY, Spring::snappy())
        .on_mount(move || shown.set(true)) // 挂载时的初始值不做动画，挂载后改目标才有入场动画
        .child(text(label))
}
```

一直循环的动画同理：挂载后把目标切过去，补间带上 `.forever()` 或 `.alternate(true)`：

```rust
pub fn spinning() -> Element {
    let spinning = signal(false);
    path(VectorPath::svg("M12 3 A9 9 0 1 1 3 12").view_box(0.0, 0.0, 24.0, 24.0))
        .size(24, 24)
        .stroke(Stroke::new(2.4).round())
        .rotation(move || rad(if spinning.get() { TAU } else { 0.0 })) // 弧度，正值顺时针
        .transition(Property::Rotation, Tween::new(ms(800)).linear().forever()) // 一直重复
        .on_mount(move || spinning.set(true))
}

pub fn breathing() -> Element {
    let on = signal(false);
    rect()
        .size(48, 48)
        .radius(24)
        .background(Color::hex(0x30d158))
        .scale(move || if on.get() { 1.15 } else { 1.0 })
        .transition(Property::Scale, Tween::new(ms(900)).ease_in_out().alternate(true)) // 来回往复
        .on_mount(move || on.set(true))
}
```

**退场动画** `.exit(属性, 值)`：元素被 `each` / `child_when` 移除（或浮层关闭）时，先过渡到退场值，动画结束后才卸载，见第 [9](09-列表.md) 章的待办清单。

## 合成层：主线程卡住也不掉帧

声明了**透明度、缩放、旋转、平移**动画（包括这些属性的退场动画）的元素自动成为一个**合成层**：这些动画由渲染线程推进，不经过主线程的布局和生成图元。主线程卡在同步读文件、大量计算上时，它们照样流畅。不用手动标记。

所有动画都按时间求值：每个在动的值是一条轨道，值是时刻的纯函数。主线程和渲染线程按同一个动画时钟、同一个时刻采样同一条轨道，算出同一个值，卡顿、合并帧都不影响。

其他属性（颜色、圆角、投影、模糊……）的动画在主线程上推进：颜色、圆角、边框、一层投影每帧只修补那几个图元，别的每帧重新生成图元；**宽、高、内边距、间距**是布局属性，动画期间每帧重新布局：

```rust
pub fn sidebar() -> Element {
    let open = signal(true);
    row()
        .height(200)
        .child(
            column()
                .width(move || if open.get() { 220.0 } else { 64.0 })
                .transition(Property::Width, Spring::smooth()) // 布局属性：动画期间每帧重新布局
                .clip(true)
                .padding(16)
                .background(SURFACE)
                .child(text("侧栏")),
        )
        .child(column().grow(1).padding(16).align(Align::Start).child(button("收起 / 展开").on_click(move || open.update(|o| *o = !*o))))
}
```

能用平移、缩放表达的，就别用宽高、位置做动画。

## `without_animation`：跟手和"先复位再播放"

`aureole::without_animation(|| ..)` 里引起的属性变化不做动画、直接跳到新值（渲染线程的合成层也一起跳），即使在处理器的批量更新里也立即生效。两个典型用法：

拖动时跟手，松手后再用弹簧：

```rust
pub fn draggable() -> Element {
    let (x, y) = (signal(0.0f32), signal(0.0f32));
    rect()
        .size(80, 80)
        .radius(16)
        .background(Color::hex(0xff9f0a))
        .translation(x, y)
        .transition(Property::TranslationX, Spring::bouncy())
        .transition(Property::TranslationY, Spring::bouncy())
        .cursor(Cursor::Grab)
        .on_drag(move |e: &DragEvent| match e.phase {
            GesturePhase::End | GesturePhase::Cancel => {
                // 松手：弹簧带回原位
                x.set(0.0);
                y.set(0.0);
            }
            _ => aureole::without_animation(|| {
                // 拖的时候跟手：直接跳到新位置，不做动画
                x.update(|x| *x += e.delta[0]);
                y.update(|y| *y += e.delta[1]);
            }),
        })
}
```

先复位、再播放（每次点击都从头描一遍对勾）：

```rust
pub fn redraw_check() -> Element {
    let drawn = signal(false);
    let check = VectorPath::svg("M5 12.5 L10 17.5 L19 7").view_box(0.0, 0.0, 24.0, 24.0);
    path(check)
        .size(48, 48)
        .stroke(Stroke::new(2.0).round())
        .stroke_range(0.0, move || if drawn.get() { 1.0 } else { 0.0 })
        .transition(Property::StrokeEnd, Spring::new(ms(450), 0.85))
        .on_mount(move || drawn.set(true))
        .on_click(move || {
            aureole::without_animation(|| drawn.set(false)); // 先直接回到 0
            drawn.set(true); // 再从 0 描到 1
        })
}
```

## 3D：翻转、倾斜、透视

`rotation_x`、`rotation_y` 让元素绕水平、竖直的轴转（上边、右边转向远处为正），按透视画：近大远小。两个面都设成 `backface_hidden(true)`、背面先转半圈叠在正面后面，就是能翻过来的卡片：

```rust
pub fn turn_card() -> Element {
    let turned = signal(false);
    let face = |label: &str, color: Color| {
        column().size(200, 130).radius(10).padding(16).background(color).color(Color::WHITE).backface_hidden(true).child(text(label))
    };
    column()
        .size(200, 130)
        .rotation_y(move || rad(if turned.get() { std::f32::consts::PI } else { 0.0 })) // 绕竖直的轴转，右边转向远处为正
        .transition(Property::RotationY, Spring::new(ms(550), 1.0)) // 渲染线程推进，主线程卡住也照样翻
        .on_click(move || turned.update(|f| *f = !*f))
        .child(face("正面", Color::hex(0x138a84)))
        .child(face("背面", Color::hex(0x4a6fa5)).rotation_y(rad(std::f32::consts::PI)).position(0, 0)) // 先转半圈，叠在正面后面
}

pub fn tilted_row() -> Element {
    row()
        .gap(24)
        .padding(24)
        .child_perspective(800) // 子元素都从这一行中心的正前方 800 处看过去：共用一个消失点
        .children((0..3).map(|i| {
            rect().size(120, 80).radius(10).background(ACCENT_SOFT).rotation_x(rad(0.5)).rotation_y(rad(i as f32 * 0.3 - 0.3))
        }))
}

pub fn door() -> Element {
    let open = signal(false);
    rect()
        .size(120, 180)
        .radius(6)
        .background(SURFACE)
        .border(1, LINE)
        .transform_origin(0.0, 0.5) // 绕左边转
        .perspective(600) // 观察距离：越小透视越强
        .rotation_y(move || rad(if open.get() { -1.2 } else { 0.0 }))
        .transition(Property::RotationY, Spring::new(ms(500), 1.0))
        .on_click(move || open.update(|o| *o = !*o))
}
```

- **透视**：`perspective(距离)` 是自己的观察距离，视点在变换中心的正前方，越小透视越强，`f32::INFINITY` 是没有透视；没设时用父元素的 `child_perspective(距离)`（视点在父元素中心，一排卡片共用一个消失点，离中心越远的看起来越斜），都没设时是 1000。
- **变换中心** `transform_origin(x, y)`：占宽高的比例，默认 `(0.5, 0.5)`，缩放和各个方向的旋转都绕它。
- `RotationX`、`RotationY`、`Perspective` 和平移、缩放一样是合成层的属性：动画由渲染线程推进，不重新布局、不重建图元，主线程卡住时照样翻。也能当关键帧时间线的轨道（`handle.animate(Property::RotationY, Keyframes::new(..))`），同样由渲染线程按播放头推进。转过的元素点击照样准（按投影的逆变换算），背朝屏幕的面点不到。
- 系统打开"减少动态效果"时，绕 x、y 轴的旋转和透视直接到位，不做动画。

## 共享元素：从一处飞到另一处

列表里的缩略图点开变成大图、关上时飞回去：两个元素带同一个标签 `.shared(标签)`，新的那个从旧的此刻在屏幕上的位置和大小飞到自己的位置（临界阻尼的弹簧，不回弹）：

```rust
pub fn album() -> Element {
    let open = signal(None::<usize>);
    let colors = [0x138a84, 0x4a6fa5, 0x3d9a5b, 0x7d6fb8];
    // 缩略图和大图带同一个标签：同一张"照片"
    let photo = move |i: usize| rect().radius(8).background(Color::hex(colors[i])).shared(format!("photo-{i}"));
    column()
        .child(row().gap(12).children((0..4).map(move |i| photo(i).size(80, 60).on_click(move || open.set(Some(i))))))
        .each(
            move || open.get().into_iter().collect(),
            |&i| i,
            move |i| {
                column()
                    .position(0, 0)
                    .padding(16)
                    .background(BACKGROUND)
                    .child(photo(i).size(320, 240).on_click(move || open.set(None))) // 点大图飞回去
            },
        )
}
```

- 同一个标签同时只显示一个：最后挂载的那个。上面的缩略图一直挂着，大图打开时它藏起来（不画、点不到），大图关上后它从大图的位置飞回去。旧的卸载、新的挂载（比如 `child_when` 切换两个视图）也一样，在同一次更新里、或者下一帧之前接上就算。
- 飞行只动合成层的平移和缩放，由渲染线程推进；飞的时候画在起飞时已经在的东西上面，不被原来的滚动视口裁掉，也不跟着祖先淡入淡出。起飞之后才打开的（新的详情页、浮层）盖住它：关上一张、它还在飞回去时打开另一张，飞回去的缩略图在新的详情页下面。飞到一半再点回去，从此刻的位置和速度接着飞。
- 曲线默认是响应 0.4 秒的临界阻尼弹簧，`.shared_with(标签, 曲线)` 换一条。
- 系统打开"减少动态效果"时不飞：新的在自己的位置淡入，旧的（还挂着的话）淡出。
- 标签只在一个窗口里有效。

## 坑

- 只写 `.transition(..)`、属性本身不绑定信号，不会有任何动画：动画是"绑定的值变了"时才发生。样式对象里按状态换的值也是绑定，所以样式对象里的 `.transition(..)` 能让悬停、按下、勾选平滑地变（第 [13](13-样式对象.md) 章）。
- 基础控件默认没有动画（开关的圆钮直接到位、复选框的勾直接出现）；要动画就在部位的样式对象里声明过渡（第 [14](14-基础控件.md) 章）。
- 同一属性多次 `.transition(..)` 以最后一次为准。
- 挂载时的值不做动画：入场动画一定要在 `on_mount` 里改目标（或者在挂载后的任何时候）。
- 宽高从百分比、`auto` 切到像素值时会从当前宽度过渡过去；切到百分比或 `auto` 则直接跳过去（停下进行中的动画）。
- `without_animation` 放在副作用里不能立即生效（副作用执行期间不能先执行排队的副作用）；需要时放进 0 延迟的 `aureole::after`。
- 角度都带单位写：`deg(90)`、`rad(PI)`、`turns(0.25)`（`Angle` 不从裸数转换）；旋转正值顺时针，`turns(1)` 是一整圈。
- 转过 x、y 轴的元素连同子孙"压平"在它自己的平面上：兄弟之间不按远近排序，后画的在上面；两个转过的平面相交时不处理。
- 共享元素的两端宽高比不同时，飞的时候内容会被拉伸（圆角也跟着缩放），两端用同样的宽高比最好看。

## 关键帧时间线：多步、多个元素编排在一起

`.transition` 管的是"值变了怎么过渡"。入场时一行接一行地出现、一直循环的脉冲、几个元素按顺序出场这类**事先编好的动画**用关键帧时间线：

- `Keyframes::new(起始值).at(时刻, 值)`（`.at(ms(120), 1.12)`）：一个属性的一串关键帧。每段默认按 `Easing::EASE` 走，`.easing(..)` 改刚加的那一段的缓动，`.spring(..)` 改成弹簧（带着上一段的速度出发，到那一帧的时刻正好到达）。值可以是数值、纯色、投影。
- `MotionHandle`：时间线要动的元素，用 `.motion_handle(句柄)` 交给一个或多个元素；`句柄.animate(属性, 关键帧)` 是时间线上的一段（`Motion`）。
- `sequence([..])` 一段接一段，`parallel([..])` 同时放；每段都能 `.delay(时长)`、`.stagger(时长)`（句柄交给了多个元素时按界面里的先后错开）、`.times(n)`、`.forever()`、`.alternate(true)`。
- `Timeline::new(段)` 创建时不放。`play`、`pause`、`reverse`、`seek(时刻)` / `seek_progress(进度)`、`restart`、`stop` 控制播放；`progress()`、`position()`、`is_playing()` 是响应式的；`on_finish(..)` 放完时调用，`finished().await` 等它放完。

```rust
pub fn staggered_list() -> Element {
    let rows = MotionHandle::new();
    let intro = Timeline::new(
        parallel([
            rows.animate(Property::Opacity, Keyframes::new(0.0).at(ms(240), 1.0).easing(Easing::EASE_OUT)),
            rows.animate(Property::TranslationY, Keyframes::new(12.0).at(ms(400), 0.0).spring(Spring::new(ms(300), 1.0))),
        ])
        .stagger(ms(50)), // 每行比上一行晚 50 毫秒
    );
    column()
        .gap(6)
        .on_mount(move || intro.play())
        .children(["收件箱", "已发送", "草稿", "归档"].map(|label| text(label).padding(8).motion_handle(rows)))
}
```

一直循环：

```rust
pub fn pulse() -> Element {
    let ring = MotionHandle::new();
    let pulse = Timeline::new(
        parallel([
            ring.animate(Property::Scale, Keyframes::new(1.0).at(ms(1600), 2.4).easing(Easing::EASE_OUT)),
            ring.animate(Property::Opacity, Keyframes::new(0.5).at(ms(1600), 0.0).easing(Easing::EASE_OUT)),
        ])
        .forever(), // 一直循环；.times(3) 放三轮，.alternate(true) 偶数轮倒着放
    );
    rect()
        .size(24, 24)
        .on_mount(move || pulse.play())
        .child(rect().position(2, 2).size(20, 20).radius(10).border(1.5, ACCENT).motion_handle(ring))
        .child(rect().position(7, 7).size(10, 10).radius(5).background(ACCENT))
}
```

几个元素按顺序出场，用代码控制：

```rust
pub fn choreography() -> Element {
    let (panel, title, chips) = (MotionHandle::new(), MotionHandle::new(), MotionHandle::new());
    let show = Timeline::new(sequence([
        // 先：面板淡入、轻轻放大到位
        parallel([
            panel.animate(Property::Opacity, Keyframes::new(0.0).at(ms(200), 1.0)),
            panel.animate(Property::Scale, Keyframes::new(0.96).at(ms(360), 1.0).spring(Spring::smooth())),
        ]),
        // 再：标题从左边滑进来（晚 40 毫秒）
        title.animate(Property::TranslationX, Keyframes::new(-12.0).at(ms(300), 0.0)).delay(ms(40)),
        // 最后：标签一个接一个出现
        chips.animate(Property::Opacity, Keyframes::new(0.0).at(ms(200), 1.0)).stagger(ms(60)),
    ]));
    show.on_finish(|| println!("放完了"));
    let control = |label: &'static str, f: fn(&Timeline)| button(label).on_click(move || f(&show));
    column()
        .gap(12)

                .gap(8)

                .child(control("播放", Timeline::play))
```

```rust
pub fn login_form() -> Element {
    let field = MotionHandle::new();
    // 输入有误时左右晃两下
    let shake = Timeline::new(field.animate(
        Property::TranslationX,
        Keyframes::new(0.0).at(ms(60), -6.0).at(ms(120), 6.0).at(ms(180), -4.0).at(ms(240), 4.0).at(ms(300), 0.0),
    ));
    let (name, hint) = (signal(String::new()), signal(false));
    column()
        .gap(8)
        .align(Align::Start)
        .child(text_field(name).motion_handle(field))
        .child(button("登录").on_click(move || {
            if name.with(String::is_empty) {
                shake.restart();
                aureole::spawn_local(async move {
                    shake.finished().await; // 晃完再提示
                    hint.set(true);
                });
            }
        }))
        .child_when(move || hint.get(), || text("请先填名字").color(DANGER))
}
```

**和 `.transition` 一起用**：

- 时间线开始后接管它动的属性，元素显示时间线算出的值；放完停在最后的值，不会自己跳回去。
- 属性绑定的值在这期间**变了**（比如悬停改了缩放），这个属性马上交还给绑定：声明了过渡的从此刻的值和速度接着过渡，不跳；时间线之后不再动它，直到 `restart`。绑定重新求值、但值没变时不算。
- `stop()` 把属性全部交还给绑定，同样按声明的过渡回去；时间线所在的作用域释放时自动停止。
- 同一个属性同一时刻只听一个来源：后开始的时间线接管前一条正在动的属性。想叠加（比如一直呼吸、悬停时再放大一点），套一层元素，各动一层。

**在哪个线程推进**：只动合成层的**透明度、缩放、旋转、平移**的那几段交给渲染线程：主线程只在开始、暂停、跳转时发一次，渲染线程按播放头求值，主线程卡住时它们照样流畅。其他属性（颜色、圆角、宽高……）在主线程上推进。

**减少动态效果**：系统打开时（开始播放那一刻读），时间线里的移动、缩放、旋转、尺寸、描线直接是最后的值，淡入淡出和颜色照常按时间走，放完的时刻和 `on_finish` 不变。

## 坑（时间线）

- 关键帧的时刻是从这一段开始算的，不是整条时间线上的时刻；整条的时长由 `sequence`、`delay`、`stagger`、轮数算出来。
- 错开的时长取决于句柄有几个元素：按开始播放时挂载的元素排期。之后才挂载的元素直接用时间线此刻的值（放完了就是最后的值），想让它们也动一遍就 `restart()`。
- 一直循环的时间线没有进度（`progress()` 是 0），也不能从结尾倒放。
- 弹簧段的时长最好不短于弹簧自己停稳的时间（临界阻尼约响应时间的 1.2 倍），否则末尾会收得急一些。
- 关键帧不支持渐变和路径；路径之间的变形见第 [15](15-图片与矢量图标.md) 章。

## 动画的时钟：暂停、慢放、拖动

`aureole::animation_clock()` 取 `AnimationClock`：所有窗口、主线程和渲染线程的动画都读它，调试动画时暂停、慢放，看清楚每一刻。

```rust
/// 动画的时钟：暂停、慢放所有窗口的动画，看清楚一段动画的每一刻
pub fn clock_panel() -> Element {
    let clock = aureole::animation_clock();
    let moved = signal(false);
    column()
        .gap(8)
        .child(
            rect()
                .size(48, 48)
                .radius(8)
                .background(ACCENT)
                .translation_x(move || if moved.get() { 240.0 } else { 0.0 })
                .transition(Property::TranslationX, Spring::smooth())
                .on_click(move || moved.update(|m| *m = !*m)),
        )
        .child(
            row()
                .gap(6)
                .child(button("暂停").on_click(move || clock.pause()))
                .child(button("继续").on_click(move || clock.resume()))
                .child(button("四分之一速").on_click(move || clock.set_speed(0.25)))
                .child(button("正常速度").on_click(move || clock.set_speed(1.0))),
        )
}
```

- `pause()`、`resume()`、`set_speed(倍速)`（1 是正常，小于 1 慢放，0 和暂停一样）、`seek(时刻)`；`time()`、`speed()`、`is_paused()` 读。
- 停着时窗口和渲染线程都不为动画出帧；停着时改的目标、发的时间线命令从停住的那一刻起算，继续以后才动。
- **跟它走的**：声明的过渡、退场、时间线、合成层动画、共享元素的飞行，自定义着色器收到的 `in.time`。**不跟它走的**：滚动（直接操作，暂停动画时滚动照常）、动图的播放、插入点闪烁。
- 只能拖到每条轨道最近一次改目标之后：轨道不记更早的轨迹，拖到那之前时停在那一刻的样子；已经放完的时间线停在结尾。
- 它是全局的：应用自己的界面里不要用它做"暂停这一个动画"，那是时间线的 `pause()`。
