# 7. 输入框和多行编辑

## 单行输入框

输入框是基础控件之一，和一个 `Signal<String>` 双向同步：打字时写回信号，外面改信号时输入框跟着变。

```rust
pub fn search_box() -> Element {
    let query = signal(String::new());
    column()
        .gap(8)
        .child(
            text_field(query)
                .placeholder("搜索…")
                .width(280) // 默认宽 200；输入框的宽度不随内容变
                .on_submit(move |q| println!("搜索 {q}")), // 回车
        )
        .child(text(move || format!("输入了 {} 个字", query.with(|q| q.chars().count()))))
}
```

**默认的样子**：宽 200、高 30、左右内边距 8、圆角 4，白底加 1 像素灰色描边，悬停时描边深一点，有焦点时描边变强调色（不另画焦点环），禁用（`.disabled(..)`）时变淡。这些是先用上的一个样式对象（第 [13](13-样式对象.md) 章），后面的链式方法、`.style(&s)` 照常盖过它：

```rust
/// 换个样子：胶囊形、浅灰底；有焦点时白底加强调色的描边
pub fn rounded_search() -> Element {
    let query = signal(String::new());
    let pill = Style::new()
        .height(36)
        .padding_x(14)
        .radius(18)
        .background(FILL)
        .border_color(Color::TRANSPARENT)
        .hovered(|s| s.border_color(Color::TRANSPARENT)) // 默认的样子悬停时描边变深：这里也换掉
        .focused(|s| s.background(Color::WHITE).border_color(ACCENT));
    text_field(query).placeholder("搜索…").width(280).style(&pill)
}
```

样式对象按状态合进默认的样子：它给了的状态换成它的，没给的（禁用时变淡）留着。要一个完全没有框的输入框：`.style(&Style::new().border(0, Color::TRANSPARENT).background(Color::TRANSPARENT).padding_x(0))`。

内置的编辑行为：方向键（Shift 扩展选区，Option 按词，Command 到行首行尾）、Home / End、⌘A / ⌘C / ⌘X / ⌘V、撤销重做（⌘Z / ⇧⌘Z）、点击放插入点、拖选、双击选词；回车调用 `on_submit`，Esc 失去焦点。按键照平台惯例：Windows、Linux 上按词看 Ctrl，Ctrl+Y 也是重做。

要在输入框之前截下按键（自动补全截下 ↑ ↓）用捕获阶段，要取消编辑用 `e.prevent_builtin(Builtin::EDIT)`（第 [11](11-交互.md) 章）。

`.accepted_chars(|c| ..)` 只收认的字：打字、粘贴、输入法和听写的提交、辅助技术改值都过滤。

**中文输入法**：组字期间的拼音带下划线显示在插入点处，**不写回信号**，提交后才写；候选框跟着插入点走。组字到一半换焦点、点到别处、输入框被禁用、切到别的应用时，没确定的拼音被放弃，不会留在输入框里，也不会落到新焦点上。

## 改了、改完了

```rust
/// on_change：用户每改一次；on_commit：回车或失去焦点，而且内容变了
pub fn nickname() -> Element {
    let name = signal(String::from("梨茶"));
    let saved = signal(String::from("梨茶"));
    column()
        .gap(8)
        .child(text_field(name).on_change(|t| println!("正在改：{t}")).on_commit(move |t| saved.set(t)))
        .child(text(move || format!("已保存：{}", saved.get())))
        .child(button("恢复").on_click(move || name.set(saved.get()))) // 代码里改信号：两个都不调用
}
```

- `.on_change(|内容| ..)`：用户每改一次（打字、删除、粘贴、剪切、撤销、输入法提交、辅助技术设置）。输入法组字期间不调用，提交时才调用。
- `.on_commit(|内容| ..)`：改完了：回车，或者失去焦点（点别处、Tab 走开、Esc）。内容和获得焦点时（或者上次改完时）一样就不调用，所以点进去又出来不算。多行输入框只在失去焦点和 `submit_key` 的键时调用。
- 两个都只管**用户**改的：代码里 `name.set(..)` 时都不调用。要不管谁改都做点什么，用副作用读信号。
- `.on_submit(|内容| ..)` 是另一回事：每次按回车都调用，不管内容变没变（搜索框"再搜一次"）。

## 密码

```rust
pub fn password() -> Element {
    let (secret, shown) = (signal(String::new()), signal(false));
    row()
        .gap(8)
        .align(Align::Center)
        .child(text_field(secret).placeholder("密码").password(move || !shown.get())) // 可以绑定
        .child(checkbox(shown).label("显示密码"))
}
```

`.password(true)`（或者绑定）是密码模式，只对单行输入框有效：每个字显示成一个圆点，不能复制、剪切，不用输入法，不记撤销；绑定的信号里照样是真的内容。对辅助技术是密码框，只念圆点。窗口在前面时请求系统的安全输入（macOS；别的平台只是不开输入法）。

## 多行输入框

```rust
pub fn notes() -> Element {
    let notes = signal(String::new());
    text_area(notes)
        .placeholder("写点什么…（⌘回车保存）")
        .width(420)
        .min_height(120) // 跟着内容长高，超过最大高度后在里面滚动
        .max_height(320)
        .padding(12)
        .submit_key(SubmitKey::PrimaryEnter)
        .on_submit(move |text| println!("保存 {} 个字", text.chars().count()))
}
```

- 默认的样子和单行的一样，宽 320、最小高 64、四边内边距 8。
- 回车换行；`.submit_key(SubmitKey::PrimaryEnter)` 让 ⌘回车提交，`SubmitKey::Enter` 是回车提交、Shift+回车换行。
- 它是**一个元素**，自己带滚动：背景、边框、圆角、内边距、大小、文字样式、`placeholder`、处理器、焦点都设在它上面；`scroll_handle`、`on_scroll`、`scrollbar_color` 照样能用，滚动在渲染线程上推进。
- 按段排版：打一个字只重排插入点所在的一段，别的段的字形整块拷贝；上万字不换行的一段再切成块，只重排一块，不用自己分段。撤销重做最多 500 步，连续打字合成一步。

## 用代码控制焦点

```rust
pub fn focus_by_shortcut() -> Element {
    let name = signal(String::new());
    let field = FocusHandle::new();
    aureole::shortcut("CmdOrCtrl+L", move || field.focus());
    text_field(name).focus_handle(field).placeholder("按 ⌘L 聚焦").width(240)
}
```

`FocusHandle` 像信号一样是 `Copy` 的：`focus()`、`unfocus()`，`is_focused()` 是响应式的。挂载之前发出的请求挂载后执行。

## 标签

输入框旁边的说明文字用标签 `label(文字)`：和输入框用同一个焦点句柄连起来，点标签时输入框获得焦点，辅助技术按标签念输入框的名字。

```rust
/// 标签：和输入框用同一个焦点句柄；点它输入框获得焦点
pub fn form() -> Element {
    let (email, bio) = (signal(String::new()), signal(String::new()));
    let (email_focus, bio_focus) = (FocusHandle::new(), FocusHandle::new());
    let invalid = move || email.with(|e| !e.is_empty() && !e.contains('@'));
    column()
        .gap(6)
        .width(360)
        .child(label("邮箱").target(email_focus))
        .child(text_field(email).focus_handle(email_focus).placeholder("name@example.com").full_width(true))
        .child_when(invalid, || text("格式不对").font_size(12).color(DANGER))
        .child(text("用来登录和找回密码").font_size(12).color(MUTED))
        .child(label("简介").target(bio_focus).margin_top(8))
        .child(text_area(bio).focus_handle(bio_focus).full_width(true))
}
```

- 控件 `.focus_handle(句柄)`，标签 `.target(句柄)`。标签放在哪里都行（上面一行、表格的另一列），不用包着输入框。
- 对辅助技术，输入框"由这个标签命名"：输入框自己没有 `.accessibility_name(..)` 时，标签的文字就是它的名字。
- 标签对别的控件也一样：复选框、开关的标签点了就切换，下拉框的点了就打开，按钮的点了就是点按钮（第 [14](14-基础控件.md) 章）。

## 坑

- **输入框的宽度不随内容变化**：默认宽 200（多行 320），要别的宽度给 `.width(..)`、`.full_width(true)` 或 `.grow(1)`。
- 样式对象里的焦点状态（`.focused(..)`）在输入框上是"有焦点"（插入点在里面），指针点进去也算；别的元素只在用键盘得到焦点时算（第 [13](13-样式对象.md) 章）。
- 外部改了绑定的信号时，撤销记录会清空（位置已经对不上）。
- Tab 默认留给焦点切换；多行输入框里要插入制表符时用 `.accepts_tab(true)`。
- 单行输入框粘贴多行文字时，换行变成空格。
- 输入框自己处理的组合键（⌘A、⌘C……）不会再触发同名的快捷键，所以不要用这些组合键注册快捷键。
- 双击选词、Option+方向键、Option+退格在中文、日文里按词典分的词走（"我们今天去公园"里双击"今"选中"今天"）；英文照常。失去焦点（点别处、Esc、Tab 走开）后选区还在，画成淡淡的灰，回来时还是这个选区。
