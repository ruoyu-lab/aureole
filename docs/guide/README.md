## 用词

文档、注释、API 用同一套词。容易混的几个：

| 词 | 意思 |
|---|---|
| 元素、节点 | 元素是链式调用搭出的界面描述，挂载以后在元素树里的实例叫节点 |
| 视图、视图函数 | 能变成元素的东西（`Element`、`&str`……）；返回 `impl View` 或 `Element` 的函数叫视图函数 |
| 控件、部位 | 框架带的基础控件；控件里能单独设样式的一块（滑轨、滑块、勾）叫部位 |
| 绑定 | 属性收的闭包、信号或派生值，信号变了只更新这一个属性 |
| 过渡、时间线 | 属性的值变了时按曲线走过去（`.transition`）；用代码控制的、编排好的多步动画（`Timeline`） |
| 合成层、分组 | 渲染线程上单独变换、单独动画的一块；先画进离屏纹理再整体合成的子树 |
| 指针、指针形状 | 鼠标、触控板、笔的统称；指针在元素上显示的样子（`Cursor`） |
| 插入点 | 输入框和字符网格里闪的竖线或方块 |
| 处理器 | `on_*` 收的函数 |
| 浮层 | 挂在窗口根上画、不受祖先裁剪的元素：菜单、下拉列表、提示、对话框 |
